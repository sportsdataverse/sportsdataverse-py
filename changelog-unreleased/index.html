Unreleased changes

Merged to main since 0.2.0b1 and not yet released. Released versions are on the Changelog.

Unreleased​

Breaking changes​

  • nfl_model_pbp / Shield play-by-play schema: drive_start_yard_line / drive_end_yard_line are nflverse's text ("BAL 20"; were Int64), drive transitions nflverse's codes, team columns name relocated clubs LV / LAC / LA in every season, playoff weeks run 18-22. Republish every season together; never mix them. (#1028)
  • Basketball: plain RAPM (nba_rapm, the player_impact RAPM and the factor split) fits at one ridge penalty per league in every season (RAPM_PENALTY: NBA 2,683, WNBA 1,931); RidgeCV's per-season pick made the RAPM scale jump between seasons, so values fit before are not comparable with these. (#1121)
  • CFB: cfb_playoff_seeds without season, and sim-keyed standings, use the 2026 CFP rule and the current conference tiebreakers (the 2026 ACC policy among them); pass season=2025 for the previous ones. (#1058)
  • CFB: CONFERENCE_TIEBREAKERS values are season-scoped epoch lists ({"from", "rungs", "pool"}), not rung lists, mirroring cfbseedR 0.2.0. (#1058)
  • MBB / NBA: espn_mbb_pbp() / espn_nba_pbp() return the release play-by-play frame (load_<lg>_pbp's columns and dtypes, athlete_name_*, score_source); the old dict is return_parsed=False. (#1045)
  • PWHL/HockeyTech: live pwhl_pbp and every <league>_pbp (AHL, OHL, WHL, QMJHL, ECHL and the other 14) return x_coord / y_coord in feet, as fastRhockey and load_pwhl_pbp do; they were the raw 600x300 canvas, which stays in x_coord_original / y_coord_original. Drop any manual /3 - 100 conversion you applied. (#1049)
  • WBB/WNBA: espn_wbb_pbp() / espn_wnba_pbp() return the release play-by-play frame (load_<lg>_pbp's columns, order and dtypes, athlete_name_*, score_source); the old dict is return_parsed=False. (#1048)

Changed​

  • Basketball: the college and NBA / WNBA season sims start from a preseason prior: last season's final ratings, regressed to the mean and faded by games played (fit in tools/fit_preseason_prior.py), and the college sim draws rating noise, so early-season odds are no longer one game's noise (West Florida 32-0 is now 15-17). (#1084)
  • CFB: cfb_simulations plays the fixed CFP bracket (12@5, 11@6, 10@7, 9@8; quarterfinals 1 v 8/9, 2 v 7/10, 3 v 6/11, 4 v 5/12; no reseeding) instead of reseeding every round. (#1058)
  • CFB: cfb_standings sov / sos pool the opponents' conference record (summed wins over summed games), as cfbseedR does, instead of averaging opponents' win pct per game; values change wherever opponents played unequal conference game counts, and with them generic-cascade SOV/SOS tiebreaks and the no-rankings CFP seed order.   • CFB: cfb_standings conference ranking is about 2x faster on large simulation stacks. (#1058)
