Unreleased changes

Merged to main since 0.2.0b1 and not yet released. Released versions are on the Changelog.

Unreleased​

Breaking changes​

  • nfl_model_pbp / Shield play-by-play schema: drive_start_yard_line / drive_end_yard_line are nflverse's text ("BAL 20"; were Int64), drive transitions nflverse's codes, team columns name relocated clubs LV / LAC / LA in every season, playoff weeks run 18-22. Republish every season together; never mix them. (#1028)

Added​

  • CFB: CFBPlayProcess(resolve_missing=...) is passed to espn_cfb_play_participants, so a caller serving requests can skip the up-to-50 per-athlete lookups for names the participants sidecar omits. (#1034)
  • Codegen: loader schemas accept a naive Datetime(time_unit=..., time_zone=None) column type. (#1043)
  • HTTP: SDV_PY_HTTP_MAX_WAIT (whole seconds) overrides download's 180 s total retry-wait budget, alongside SDV_PY_HTTP_TIMEOUT and SDV_PY_HTTP_RETRIES. (#1034)
  • NBA: load_nba_stats_injury_report(seasons) reads the official injury report from the nba_stats_injury_report release (2018-19 on): every published version, one row per listing, with game_id, team_id and person_id joined and match_method saying how each player was matched. (#1043)
  • NBA: nba_injury_report() fetches and parses the league's official pre-game injury report PDFs (2018-12-17 onward), with parse_nba_injury_report(), nba_injury_report_slots() and nba_injury_report_url(); needs the new [pdf] extra (pdfplumber). (#1024)
  • NFL play-by-play: enrich_nfl_pbp adds nflfastR's success and first_down columns when the frame lacks them. (#1037)

Changed​

  • Docs site: the home page's Data sources strip reads docs/src/data/providers.json, which codegen writes from sources.yaml (providers flagged featured, then a "+N more" link to the intro sources table). (#1021)
  • Exports: enrich_nfl_pbp is exported from sportsdataverse.nfl and the top-level package, and espn_injuries_snapshot / espn_depthcharts_snapshot from the top level, so the docs pages and the sdv-docs index now list them. (#1021)
  • NFL expected points: ep_model.ubj is refit on nflfastR's training rows and roof mapping, which EP now reads too (CP, xYAC and xpass keep theirs); ESPN games take their roof from the venue id, since ESPN never says a venue is indoors and every ESPN game was scored as outdoors, domes included. (#1027)
  • NFL Shield play-by-play (shield_pbp): drive_* come from Shield's drive records in each era's nflverse convention (1999-2000, 2001-2002, 2003+), qb_dropback follows nflfastR, and the new drive column switches Shield overtime win probability to nflfastR's rule-format branches. (#1028)
  • Packaging: the nflpro, pff, tests and all extras raise their floors to the versions the lock already resolves: playwright >= 1.61, mypy >= 2.1, pytest >= 9, pytest-cov >= 7 and pytest-xdist >= 3.8. (#1038)
  • README: the X follow badges are static shields badges; the twitter/follow endpoint renders no count since X's API change. (#1021)
  • WBB: the espn_wbb_schedule season example reads load_wbb_schedule; dates=<year> returns only ESPN's first scoreboard page. (#948, #1041)

Fixed​

  • Basketball schedules: load_{nba,wnba,mbb,wbb}_schedule describe home_score, away_score and the status_type_* columns as ESPN's values passed through unchanged, not as play-time scores. (#1042)
  • CFB box score: a player ESPN spells two ways in one game ("Noah Kim" / "N. Kim") is one passer, rusher or receiver row, with one xQBR, as the NFL box already does. (#1042)
  • CFB play-by-play: feeds that number every overtime 5 count timeouts per overtime period (from drive pairs), so a team's OT3 timeout no longer reads as already spent. (#1042)
  • CFB: CFBPlayProcess drops the copies a live ESPN feed's snapshots left inside a drive (the whole drive or one play refiled under new ids), before the corrupt-game check. Four 2009-2015 games over 500 rows came back unenriched, and 709 games carried 11,893 duplicate plays (302820058: 400 rows for 166 plays). (#1036)
  • CFB: CFBPlayProcess keeps the roster it fetches as game_roster, so the usage box gets positions and tacklers' teams from it. (#1034)
  • CFB: CFBPlayProcess reads its game roster from the competitors and team-roster pages (3 requests for a current game; an older game's unnamed entries fetch only those athletes) instead of espn_cfb_game_rosters' one Core v2 request per athlete (~230 a game), which held every worker of GOP's API under throttling. (#1034)
  • Crosswalk history: Fox CFB player names no longer take the team logo's alt text. (#1019)
  • Crosswalk history: Yahoo CFB listings are fetched one date at a time (dates=): leagueGameIdsByDate ignores startRange / endRange for ncaaf and answered every range with the season's first 1,000 games. (#1019)
  • Football sources: a CBS, Fox, NCAA or Yahoo game id missing from an id-map row (NaN or pandas.NA) falls through to the next source instead of fetching game "nan". (#1042)
  • NBA game page: team_game_rates returns a null orb_pct when either team's offensive plus defensive rebounds differ from its total, as ESPN's 2002-2012 NBA boxes do. (#757, #1041)
  • NCAA MBB/WBB: under errors="skip", a rejected 2018-format page is unsupported_layout: <format>, not empty. (#948, #1041)
  • NFL CPOE: completion probability is scored only on nflfastR's valid passes (no throwaways or spikes), and cp_model.ubj is refit from 2009; team-week CPOE bias vs nflverse goes from -3.0 (2024) and -9.2 (2013) to near 0. (#1037)
  • NFL play-by-play (ESPN): 2009-13 passes ESPN types plain "Pass" now count as completions when the text reads as a catch, a penalty-nullified pass is no attempt or target, fumble-typed runs are rushes, and the box score keeps one name per player. 2009-13 passer completions exact vs nflverse: 4% to 95%. (#1037)
  • NFL play-by-play: a fumble or interception ends where the next snap starts, and EP_end flips only when possession changed; a punt-return fumble credits the force to the punting team and fills kicking_team / return_team. Turnover plays off nflfastR by more than 0.5 EPA: 71 to 27 on 154 games (#1025)
  • NFL play-by-play: any play ends where the next snap starts when that spot agrees with the play's own yardage better than ESPN's end yard line, compared in the end team's frame; kicks are excluded, and a punt a flag retyped "Penalty" ends at the receiver's next snap. Summed |EPA - nflfastR| on 154 games: 3,296 to 2,881 (#1026)
  • NFL Shield play-by-play: a try after a defensive or return touchdown belongs to the team that scored, so the kickoff after it opens a new fixed_drive / series: 2015 agreement with nflverse 0.826 to 0.984. (#1028)
  • NFL win probability (ESPN): a game ESPN has no line for (most of 2009-2011) takes the nflverse schedule's spread and total instead of home by 2.5; a supplied summary still makes no request. (#1037)
  • NFL: an api.nfl.com 2xx answer that carries a GraphQL errors list raises AssetFetchError. (#948, #1041)
  • NFL: an ESPN game with no venue id (every game before 2006) or an unknown one takes its home team's roof that season (model_vars.home_team_roof), so 2002-2005 dome games no longer score EP/CP as outdoors; a neutral site stays outdoors. nfl_build.PIPELINE_VERSION is 3. (#1029)
  • NFL: the Shield source resolves its venue uuids to a roof (18 dome / retractable and 42 open-air venues), so a Super Bowl at a dome keeps its roof and a Wembley game stays outdoors whatever Shield's neutralSite says. (#1032)
  • NFL: the Shield source sets the header's neutralSite from the id map's neutral_site, so a London or Super Bowl game is not given the home team's dome. (#1029)
  • NHL: nhl_unit_ratings breaks unit_value ties by team and unit, so its row order is reproducible. (#948, #1041)
  • Notebooks: UFL and college softball game ids come from the scoreboard, the dead cricket calendar cell is gone, Torvik cells print one line on a 403, cells ending in if/else now show their frame or message, the college hockey player cell finds a working athlete, UFL says ESPN ships no plays, and no cell points at a private repository. (#1021)
  • Raw payload schemas: espn_summary accepts espnWP and teamInfo as either a dict or a list. NBA and WNBA summaries carry espnWP as an empty list (and WNBA raw captures teamInfo too), which validate_payload reported as a type error on every committed WNBA capture. (#1023)
  • stats.ncaa.org canary: the canary's patchright and managed-CDP transports stop at an Akamai session denial (HTTP 403, under 1 KB) instead of spending every solve attempt on it, as the production fetcher has since #1039. (#1040)
  • stats.ncaa.org: an Akamai HTTP 403 "Access Denied" in the browser transport now drops the session and rotates at once. It used to read as "bm-verify not passed" and spend three re-solve navigations on a refused session. (#1039)
  • stats.ncaa.org: the browser transport needs patchright >= 1.64.3. On 1.61.2 Akamai answered 403 "Access Denied" to every request after a Terms acceptance, so each acceptance captured one page. (#1038)
  • Validation: the nfl_model_pbp schema snapshot follows the current release (drive, string drive yard lines, tackle_with_assist_2_*), and kick_distance allows a backwards punt (-11 floor). (#415, #1041)
