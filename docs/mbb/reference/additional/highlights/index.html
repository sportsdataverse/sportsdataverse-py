espn_mbb_pbp​

espn_mbb_pbp(game_id: 'int', raw: 'bool' = False, return_parsed: 'bool' = True, return_as_pandas: 'bool' = False, **kwargs)

espn_mbb_pbp() - Pull one game's play-by-play from ESPN's mens-college-basketball/summary endpoint.

By default the plays come back as the frame the espn_mens_college_basketball_pbp release publishes (what ~sportsdataverse.mbb.load_mbb_pbp reads): snake_case columns, Int32 team / athlete / game ids, the Int64 play id, game_date / game_date_time, the hoopR shot coordinates, athlete_name_{1,2,3}, and home_score / away_score rebuilt from the scoring plays when that reproduces the final (score_source says which). The release's season-level pregame_home_prob / home_win_prob are not added.

Parameters

ParameterTypeDefaultDescription
game_idintUnique game_id, can be obtained from mbb_schedule().
rawboolFalseIf True, returns the raw json from the API endpoint (wins over return_parsed).
return_parsedboolTrueIf True (default), returns the release play-by-play frame. If False, returns the game dictionary (the shape before 0.2.0, which helper_mbb_play_by_play / helper_mbb_team_box / helper_mbb_player_box and game_page_frames read).
return_as_pandasboolFalseIf True, returns the frame as pandas instead of polars. Ignored with raw=True or return_parsed=False, which return a dict.

Returns

One row per play, columns (in order) and dtypes as the release (load_mbb_pbp) for that season; a pandas frame with return_as_pandas=True. Zero rows, with the release's columns, when ESPN has no play-by-play for the game (playByPlaySource == "none") or 10 or fewer plays (hoopR returns NULL). A game with no betting line has null spread, home-favorite and home-team-spread values on every play and the spread-available flag False (hoopR's NA), never a default line. With return_parsed=False, a dictionary of game data with keys: "gameId", "plays", "winprobability", "boxscore", "header", "format", "broadcasts", "videos", "playByPlaySource", "standings", "article", "leaders", "timeouts", "pickcenter", "againstTheSpread", "odds", "predictor", "espnWP", "gameInfo", "teamInfo", "season".

Example

from sportsdataverse.mbb import espn_mbb_pbp
plays = espn_mbb_pbp(game_id=401638637)
print(plays.shape)

# Filter shooting plays for a basic shot chart

import polars as pl
shots = plays.filter(pl.col("shooting_play") == True)
shots.select(
    [
        "period_number",
        "clock_display_value",
        "team_id",
        "coordinate_x",
        "coordinate_y",
        "score_value",
        "text",
    ]
).head()

# As pandas

plays_pd = espn_mbb_pbp(game_id=401638637, return_as_pandas=True)
plays_pd[plays_pd["shooting_play"] == True].head()

# The game dictionary (box score, header, pickcenter, ...)

game = espn_mbb_pbp(game_id=401638637, return_parsed=False)
print(game["gameId"], len(game["plays"]))

# Raw payload (skip the cleaning pipeline) for debugging

raw = espn_mbb_pbp(game_id=401638637, raw=True)
sorted(raw.keys())
