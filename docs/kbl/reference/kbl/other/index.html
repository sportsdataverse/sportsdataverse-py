KBL — KBL API (api.kbl.or.kr, Korea) — Other

kbl_seasons​

Every KBL regular season (1997 to the next one) with its competition key and date range, newest first.

Endpoint URL: GET https://api.kbl.or.kr/season/list

Valid URL: https://api.kbl.or.kr/season/list

API ParameterPythonPatternRequiredNullableDescription

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
seasonInt64Season END year (2026 = 2025-26), derived from season_code through the crosswalk (kbl_codes.SEASONS).
season_codeInt64KBL season code: sequential over every season and D-League edition (2 = 1997-98, 47 = 2025-26); the crosswalk to the sdv END year is in the README.
glkeyStringCompetition key S{seasonCode}G{gameCode} (e.g. S47G01 = 2025-26 regular season): the id of the /leagues and /league/rank routes.
season_nameStringSeason label: 'YYYY-YYYY' for a KBL season (e.g. '2025-2026'), '1997' for the inaugural season.
season_name_fullStringDivision label: '1군시즌' = first-team (top-division) season.
season_gradeInt64Division: 1 = the KBL itself, 2 = the KBL D-League (reserve league).
season_categoryStringCategory code of the competition: R regular season, PO playoffs, CP final, D1/D2 D-League stages, AS All-Star, EG/CU cups, EA EASL, OM Open Match Day (table below).
game_codeStringCompetition type within the season: 01 regular season (the only value the list returns).
start_dateDateFirst date of the season, YYYYMMDD.
end_dateDateLast date of the season, YYYYMMDD.

return_parsed=False — the raw JSON Dict payload, unparsed.

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. The API has nothing for the request (an empty list, a final game with no box score, no playoff bracket, no schedule rows in a window).
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. The fetch failed or the answer is unknown or partial: any non-2xx (an unknown id is the API's HTTP 500), the KBL error envelope, an empty or non-JSON body, a game that is not final, or a body for another game, season or window than the one asked for.
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help. A malformed gmkey, a season that is not an END year between 1997 and 2027, an unknown division or game_code, or bad schedule dates (raised before any request).

kbl_seasons()

kbl_schedule​

Every game (all competitions, KBL and D-League) of a season or of a date window, with scores and venue.

Endpoint URL: GET https://api.kbl.or.kr/match/list

Valid URL: https://api.kbl.or.kr/match/list?season=2026

API ParameterPythonPatternRequiredNullableDescription
seasonseasonYSeason END year (2026 = 2025-26): the window from the first to the last game of that END year's KBL and D-League editions, fetched as at most two requests (one per calendar year). Pass this or from_date and to_date.
fromDatefrom_dateYFirst date of a window, YYYYMMDD (KST). Needs to_date; inside one calendar year the API answers the whole window in one request (up to 396 games a year, no paging).
toDateto_dateYLast date of the window, YYYYMMDD (KST), not before from_date.

ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help. A malformed gmkey, a season that is not an END year between 1997 and 2027, an unknown division or game_code, or bad schedule dates (raised before any request).
