KBL — KBL API (api.kbl.or.kr, Korea) — Player

kbl_player_box​

Player box score of a final game with the vendor's advanced rates, one row per player of both teams.

Endpoint URL: GET https://api.kbl.or.kr/match/{gmkey}/player-stat

Valid URL: https://api.kbl.or.kr/match/S47G01N49/player-stat

API ParameterPythonPatternRequiredNullableDescription
gmkeygmkeyYGame key S{seasonCode}G{gameCode}N{gameNo}, e.g. 'S47G01N49' (the 2025-26 regular season's game 49): season_code, game_code and game_no of kbl_schedule. Only final games are served; a malformed key is a ValueError.

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
gmkeycharacterGame key S{seasonCode}G{gameCode}N{gameNo} (e.g. S47G01N49): the id of every game route and game frame.
season_codeintegerKBL season code: one sequential number over every season and D-League edition (47 = 2025-26, 48 = the 2025 D-League).
seasonintegerSeason END year (2026 = 2025-26), derived from season_code through the crosswalk (kbl_codes.SEASONS).
game_codecharacterCompetition inside the season, two digits: 01 regular season, 03 playoffs, 04 final, 07 EASL, 08 D-League stage 2, 10 All-Star, 11/13 cups, 14 Open Match Day.
game_nointegerGame number inside the competition (glkey): the N part of the gmkey.
team_codecharacterKBL team code (2-digit string, e.g. '50' = Changwon LG). Joins to /common/teamList teamCode, game tcodeH/tcodeA, t in text-cast. Not stable across ownership changes: the Anyang club is '40' (SBS) in 1997-98 and '70' today. D-League sides have their own codes (teamCodeD).
home_awaycharacterSide (string): '1' home, '2' away; '3' on both teams' rows in the 1997-98 sample, so join on player.tcode instead.
startedinteger1 when the player started the game, else 0.
pcodecharacterKBL player code (6-digit string). Joins to pcode on every route and to playerNo in /league/round-mvp.
player_namecharacterPlayer name in Korean (foreign players in Hangul transliteration).
player_name_encharacterPlayer name in English / romanized (sometimes Hangul for former players, e.g. 'CJ 레슬리').
team_namecharacterTeam short name (Korean, e.g. '창원 LG' = Changwon LG), as it was at the time. English names: /common/teamList teamNameEn / teamNameFullEn, joined on the team code.
back_numcharacterJersey number (string).
poscharacterPosition code (string): C center, FD forward, GD guard, FC forward-center, GF guard-forward; table in the returns md.
player_flagcharacterPlayer type (string): '0' domestic, '1' foreign import, '2' Asian-quota player.
scoreintegerPoints. This game.
fgintegerTwo-point field goals made, dunks included: 201 + 207 rows (score = 2fg + 3threep + ft holds on every sampled box). This game.
fg_aintegerTwo-point field-goal attempts, made + missed, dunks included: 201 + 202 + 207 + 208 rows (checked per team on S47G01N49). This game.
fgtintegerField goals made, two- and three-point (fg + threep). This game.
fgt_aintegerField-goal attempts, two- and three-point (fgA + threepA). This game.
threepintegerThree-point field goals made (action 205). This game.
threep_aintegerThree-point attempts, made + missed (205 + 206). This game.
ftintegerFree throws made (action 203). This game.
ft_aintegerFree-throw attempts, made + missed (203 + 204). This game.
dkintegerDunks made (action 207); included in fg. This game.
dk_aintegerDunk attempts (made + missed, actions 207 + 208). This game.
rbintegerTotal rebounds (offr + defr; team rebounds are teamR). This game.
offrintegerOffensive rebounds (action 209). This game.
defrintegerDefensive rebounds (action 210). This game.
astintegerAssists (action 211). This game.
stlintegerSteals (action 212). This game.
bsintegerBlocked shots (action 213). This game.
tointegerTurnovers (action 214). This game.
foulintegerPersonal fouls (wft + woft). This game.
wftintegerFouls that awarded free throws (action 215). This game.
woftintegerFouls that awarded no free throws (action 216). This game.
ppintegerField goals made in the paint. This game.
pp_aintegerField-goal attempts in the paint. This game.
pscoreintegerPoints in the paint (2 * pp). This game.
sastintegerScreen assists (action 226; tracked in recent seasons only, 0 before). This game.
dflintegerDeflections (action 227; tracked in recent seasons only, 0 before). This game.
gdintegerGood-defense plays (action 221). This game.
idfintegerIllegal-defense violations (action 219; an early-KBL rule, so non-zero only in old seasons). This game.
fbintegerFast breaks credited to the player (action 217 rows that name a player, as in 1997-98); 0 in recent seasons, where fast breaks are team rows (tfb). This game.
efintegerMeaning unverified (0 in every game sample; non-zero in some season totals). This game.
tfintegerProbably technical fouls (unverified; 0 in most rows). This game.
inoutintegerTimes the player entered the game, the start included (checked on the 2025-26 sample game); a team row sums its players. This game.
inout1integerTimes the player was substituted out before the end (checked on the 2025-26 sample game); a team row sums its players. This game.
play_minintegerMinutes of playing time; add playSec seconds. This game.
play_secintegerSeconds part of the playing time (0-59), added to playMin. This game.
fointegerFouls drawn (the player rows of a team sum to the opponent's foul, checked on the 2025-26 sample game). This game.
margin_cnintegerPlus-minus: the point margin while the player was on court. This game.
offrtgnumericOffensive rating: points scored per 100 possessions (estimated). This game.
defrtgnumericDefensive rating: points allowed per 100 possessions (estimated). This game.
netrtgnumericNet rating: offrtg - defrtg. This game.
efg_rtnumericEffective field-goal percentage, 0-100. This game.
ts_rtnumericTrue-shooting percentage, 0-100. This game.
ast_rtnumericAssist rate: share of teammates' field goals assisted while on court, 0-100. This game.
ast_tonumericAssist-to-turnover ratio. This game.
ast_rationumericAssist ratio: assists per 100 possessions used. This game.
oreb_rtnumericOffensive-rebound percentage, 0-100. This game.
dreb_rtnumericDefensive-rebound percentage, 0-100. This game.
reb_rtnumericTotal-rebound percentage, 0-100. This game.
pacenumericPossessions per 40 minutes (estimated; a player row covers his minutes on court). This game.
tov_rtnumericTurnover rate: turnovers per 100 possessions, 0-100. This game.
possnumericPossessions (estimated). This game.
pernumericPlayer efficiency rating (KBL's formula; scale unverified). This game.
pienumericPlayer impact estimate: share of the game's positive events, as a percentage. This game.
usg_rtnumericUsage rate: share of team possessions used while on court, 0-100. This game.
to_rationumericTurnover ratio: turnovers per 100 possessions used. This game.
minutes_playednumericPlaying time in minutes (play_min + play_sec / 60), derived.

return_parsed=False — the raw JSON Dict payload, unparsed.

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. The API has nothing for the request (an empty list, a final game with no box score, no playoff bracket, no schedule rows in a window).
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. The fetch failed or the answer is unknown or partial: any non-2xx (an unknown id is the API's HTTP 500), the KBL error envelope, an empty or non-JSON body, a game that is not final, or a body for another game, season or window than the one asked for.
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help. A malformed gmkey, a season that is not an END year between 1997 and 2027, an unknown division or game_code, or bad schedule dates (raised before any request).

Example​

kbl_player_box(gmkey='S47G01N49')

kbl_player_totals​

Season player totals of one competition (every player with at least one game).

Endpoint URL: GET https://api.kbl.or.kr/leagues/{season}/stats/players

Valid URL: https://api.kbl.or.kr/leagues/2025/stats/players?division=kbl&gameCode=01

API ParameterPythonPatternRequiredNullableDescription
seasonseasonYSeason END year (2026 = 2025-26; the inaugural 1997 season is 1997, the latest 2027). kbl_runtime maps it to the KBL seasonCode (47 = 2025-26).
divisiondivisionY'kbl' (the KBL itself, the default) or 'd_league' (the KBL D-League reserve league, seasonGrade 2, which has its own season codes; it starts with the 2009 summer edition).
gameCodegame_codeYCompetition inside the season, two digits: '01' regular season (default; the first stage of a D-League edition), '03' playoffs, '04' championship final, '07' EASL, '08' D-League stage 2, '10' All-Star, '11'/'13' cups, '14' Open Match Day. Only '01' was probed live.
