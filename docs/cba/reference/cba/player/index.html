CBA — CBA data API (data-server.cbaleague.com, China; encrypted bodies) — Player: box–offensive

cba_player_box​

Player box score of a finished game, both sides, plus a team rebounds/turnovers row per side (null player_id).

Endpoint URL: POST https://data-server.cbaleague.com/api/player-match-datas/data-count

Example request: curl -X POST 'https://data-server.cbaleague.com/api/player-match-datas/data-count' -H 'Content-Type: application/json' -d '{"scheduleId": 100105799}'

API ParameterPythonInPatternRequiredNullableDescription
scheduleIdschedule_idbodyYRequired. CBA game id (integer), the global 9-digit sequence 100xxxxxx (100105799 = 2025-26 round 1). Only a finished game is served.

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
schedule_idInt64CBA game id (key space: CBA games, ONE global 9-digit sequence 100xxxxxx across seasons and match types; the {scheduleId} of every game route). Stamped by the runtime from the request; null on a body parsed without it.
sideStringSide of the game the row belongs to: home (the API's host / home block) or away (guest / visiting block).
assistsInt64Assists in this game (integer). Null on the team row (the 团队篮板/失误 rebounds/turnovers row).
blockedInt64Blocks in this game (integer). Null on the team row (the 团队篮板/失误 rebounds/turnovers row).
cn_aliasStringPlayer name (Chinese). The team row reads 团队篮板/失误 = 'team rebounds / turnovers' (rebounds and turnovers not credited to a player; that row does not exist in the 2009-10 sample).
field_goalsInt64Field goals made in this game (integer). Null on the team row (the 团队篮板/失误 rebounds/turnovers row).
field_goals_attemptedInt64Field goals attempted in this game (integer). Null on the team row (the 团队篮板/失误 rebounds/turnovers row).
field_goals_percentageFloat64Field-goal percentage as a FRACTION 0-1 (0.308), null when no attempt (0/0) as well as on the team row.
foulsInt64Personal fouls in this game (integer). Null on the team row (the 团队篮板/失误 rebounds/turnovers row).
free_throwsInt64Free throws made in this game (integer). Null on the team row (the 团队篮板/失误 rebounds/turnovers row).
free_throws_attemptedInt64Free throws attempted in this game (integer). Null on the team row (the 团队篮板/失误 rebounds/turnovers row).
free_throws_percentageFloat64Free-throw percentage as a FRACTION 0-1, null on the team row.
game_startInt64Starter flag: 1 = started the game. Null on the team row.
numberStringJersey number as a string. Null on the team row.
player_idInt64playerId (key space: CBA persons, stable across seasons and clubs; 3-9 digits, older players have short ids (393433) and newer ones 100xxxxxx). Joins the player box routes, the season player lists and getPlayersByScheduleId. Not a team id. Null on the team row.
plus_minusInt64Plus-minus while on court. Null on the team row and on every row of the 2009-10 sample (not tracked then).
pointsInt64Points in this game (integer). Null on the team row (the 团队篮板/失误 rebounds/turnovers row).
reboundsInt64Total rebounds in this game (integer). The team row carries the team's own total here.
rebounds_defensiveInt64Defensive rebounds in this game (integer). The team row carries the team's own total here.
rebounds_offensiveInt64Offensive rebounds in this game (integer). The team row carries the team's own total here.
stealsInt64Steals in this game (integer). Null on the team row (the 团队篮板/失误 rebounds/turnovers row).
three_point_attemptedInt64Three-pointers attempted in this game (integer). Null on the team row (the 团队篮板/失误 rebounds/turnovers row).
three_point_goalsInt64Three-pointers made in this game (integer). Null on the team row (the 团队篮板/失误 rebounds/turnovers row).
three_point_percentageFloat64Three-point percentage as a FRACTION 0-1, null on the team row.
turnoversInt64Turnovers in this game (integer). The team row carries the team's own total here.
up_timeInt64Time on court in SECONDS (1692 = 28:12). Null on the team row.

return_parsed=False — the raw DECRYPTED JSON (list or dict); a game route that answers an object also carries _request (the game id), and play-by-play is merged over every period into {records, total}.

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. The host answered 404, or the game has no play-by-play (2009-10).
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. The fetch failed or the answer is not the one asked for (an unfinished game, a body that does not decrypt or an unencrypted error envelope, an empty body, a body for another game or season, a partial play-by-play set, a dead connection).
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.

cba_player_box(schedule_id=100105799)
