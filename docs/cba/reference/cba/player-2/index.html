CBA — CBA data API (data-server.cbaleague.com, China; encrypted bodies) — Player: defensive–shots

cba_player_defensive​

Season player defensive rates (one page).

Endpoint URL: POST https://data-server.cbaleague.com/api/player-defensive-list

Example request: curl -X POST 'https://data-server.cbaleague.com/api/player-defensive-list?pageNumber=1&pageSize=100' -H 'Content-Type: application/json' -d '{"season": 2025, "matchTypeId": 1, "countRanger": 1, "playerRanger": 1, "teamId": 29128, "sort": 3, "rank": 1}'

API ParameterPythonInPatternRequiredNullableDescription
seasonseasonbodyYRequired. Season END year (2026 = the 2025-26 season). The API takes the START year (2025), so cba_runtime sends season - 1.
matchTypeIdmatch_type_idbodyYMatch type id: 1 regular season (default), 2 playoffs, 3 preseason, 4 all-star, 9 relegation play-off (cba_match_types).
countRangercount_rangerbodyYHow counting statistics scale: 1 per game (default), 2 season total, 3 per 36 minutes, 4 per 100 possessions.
playerRangerplayer_rangerbodyYWhich players: 1 all (default), 2 domestic (Chinese) only, 4 foreign only.
teamIdteam_idbodyYOptional CBA team id (clubs, stable across seasons and renames) to list one team's players.
sortsortbodyYSort column code the site sends (3 is the default order); the API answers an empty body without it.
rankrankbodyYSort direction code the site sends (1 default); the API answers an empty body without it.
pageNumberpage_numberqueryYPage number of the paged list, from 1.
pageSizepage_sizequeryYRows per page (the site uses 100).

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. The host answered 404, or the game has no play-by-play (2009-10).
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. The fetch failed or the answer is not the one asked for (an unfinished game, a body that does not decrypt or an unencrypted error envelope, an empty body, a body for another game or season, a partial play-by-play set, a dead connection).
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.

cba_player_defensive(season=2026, team_id=29128)

three_rateFloat64三分频率 three-point frequency: three-point attempts per 100 possessions (site definition). A number (the API sends it as display text).
three_rate_rankFloat64Colour rank for the metric, a fraction 0-1 (1 = best, inverted for 'bad' statistics such as turnovers) that the site uses to colour the cell (inferred from the sample values; the base population is not documented). Metric: 三分频率 three-point frequency: three-point attempts per 100 possessions (site definition).
three_rate_sortFloat64Unformatted numeric value behind the formatted string of the same metric (a fraction 0-1 for percentages), used by the site to sort the table. Metric: 三分频率 three-point frequency: three-point attempts per 100 possessions (site definition).

return_parsed=False — the raw DECRYPTED JSON (list or dict); a game route that answers an object also carries _request (the game id), and play-by-play is merged over every period into {records, total}.

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. The host answered 404, or the game has no play-by-play (2009-10).
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. The fetch failed or the answer is not the one asked for (an unfinished game, a body that does not decrypt or an unencrypted error envelope, an empty body, a body for another game or season, a partial play-by-play set, a dead connection).
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.

cba_player_shots(season=2026, team_id=29128)
