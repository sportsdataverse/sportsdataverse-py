cba_seasons​

Every season of the CBA data site, newest first (the upcoming season is the default), 1995-96 on.

Endpoint URL: GET https://data-server.cbaleague.com/api/com-code-tables/getSeason

Valid URL: https://data-server.cbaleague.com/api/com-code-tables/getSeason

API ParameterPythonPatternRequiredNullableDescription

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
is_defaultInt64Default-selection flag: 1 = the site's default season (exactly one row: the season in progress or next), 2 = not the default.
keyStringSeason label 'YYYY-YYYY' (START year - END year), e.g. '2025-2026'; the sdv season key is the second year. The list runs from the upcoming season (2026-2027, 32 rows) down to 1995-1996 with no gap.
valueStringSeason START year (2025 = the 2025-26 season). The sdv season key is the END year = season + 1; map at the boundary. String of digits ('2025'); the value every season parameter takes.

return_parsed=False — the raw DECRYPTED JSON (list or dict); a game route that answers an object also carries _request (the game id), and play-by-play is merged over every period into {records, total}.

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. The host answered 404, or the game has no play-by-play (2009-10).
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. The fetch failed or the answer is not the one asked for (an unfinished game, a body that does not decrypt or an unencrypted error envelope, an empty body, a body for another game or season, a partial play-by-play set, a dead connection).
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.

Endpoint URL: GET https://data-server.cbaleague.com/api/schedules/day

Valid URL: https://data-server.cbaleague.com/api/schedules/day?auto=0&day=2025-12-12

API ParameterPythonPatternRequiredNullableDescription
daydayYRequired. Date 'YYYY-MM-DD'. The runtime always sends auto=0 (the site's auto mode jumps to the next game day) and refuses rows on another date.

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
home_team_idInt64teamId (key space: CBA clubs; 5 digits 29115-29140 for the long-standing clubs, 9 digits for newer ones (100074683 = Ningbo); stable across seasons and club renames, but the display name changes with the sponsor: 29128 = 浙江广厦 'Zhejiang Guangsha' under many sponsor names, 浙江浙商证券 in 2025-26). Joins getTeam / teamList and the team and player routes. Not a player or schedule id.
home_team_logoStringAbsolute URL of the home team logo (300x300 png).
home_team_loseInt64Home team's cumulative losses after this game. An integer (the API sends it as digit text).

home_team_winInt64Home team's cumulative wins after this game in the match type. An integer (the API sends it as digit text).
is_eventsInt64Play-by-play flag: 1 = play-by-play exists (2017-18 and later in the samples), 2 = none (the 2009-10 sample answers empty pages).
is_reportInt64Game-report flag: 1 = a game report page exists (every sample).
match_orderInt64Sequence number of the game within its season and match type (1-based).
match_type_idInt64Match type id (1 regular season, 2 playoffs, 3 preseason, 4 all-star, 9 relegation; see getMatchType).
minutesInt64Regulation length of the game in minutes: 40 (4 x 10) in the 2025-26 sample, 48 (4 x 12) in the 2009-10 and 2017-18 samples.
quarterInt64Number of periods played (4 = no overtime; 5 and up would be overtime periods).
roundInt64Round number within the match type (1-based).
round_descStringUnobserved: null in every sample, so no meaning is claimed beyond its name (round description).
schedule_idInt64CBA game id (key space: CBA games, ONE global 9-digit sequence 100xxxxxx across seasons and match types; the {scheduleId} of every game route). Stamped by the runtime from the request; null on a body parsed without it.
schedule_numInt64Unobserved: null in every sample on this route (the game count is filled on schedules/month). Typed Int64 like the family's other routes.
schedule_timeStringTip-off as 'YYYY-MM-DD HH:MM:SS' (China local time, no zone).
schedule_type_nameStringRound label (Chinese), e.g. 常规赛第1轮 = regular season, round 1.
seasonInt64Season START year (2025 = the 2025-26 season). The sdv season key is the END year = season + 1; map at the boundary.
secondsFloat64Unobserved: null in every sample (the clock seconds of a live game, by its name). Typed Float64 like the family's other routes.
statusInt64Game status: 4 = finished (every sampled game). 1 = not started and 2 = in progress are inferred from the site's polling logic; 3 is unobserved. See the code table.
visiting_team_idInt64teamId (key space: CBA clubs; 5 digits 29115-29140 for the long-standing clubs, 9 digits for newer ones (100074683 = Ningbo); stable across seasons and club renames, but the display name changes with the sponsor: 29128 = 浙江广厦 'Zhejiang Guangsha' under many sponsor names, 浙江浙商证券 in 2025-26). Joins getTeam / teamList and the team and player routes. Not a player or schedule id.
visiting_team_logoStringAbsolute URL of the visiting team logo (300x300 png).
visiting_team_loseInt64Visiting team's cumulative losses after this game. An integer (the API sends it as digit text).
visiting_team_nameStringVisiting team name (Chinese) as of the game's season; changes with the sponsor. Names change with the sponsor, the id does not; teamId -> English glossary in cba_glossary.yaml.
visiting_team_scoreInt64Visiting team final points.
visiting_team_winInt64Visiting team's cumulative wins after this game. An integer (the API sends it as digit text).
