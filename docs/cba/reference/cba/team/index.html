CBA — CBA data API (data-server.cbaleague.com, China; encrypted bodies) — Team

cba_team_options​

The teams of one season as a select list: team id and the season's display name.

Endpoint URL: GET https://data-server.cbaleague.com/api/com-code-tables/getTeam

Valid URL: https://data-server.cbaleague.com/api/com-code-tables/getTeam?type=2&season=2026

API ParameterPythonPatternRequiredNullableDescription
seasonseasonYRequired. Season END year (2026 = the 2025-26 season). The API takes the START year (2025), so cba_runtime sends season - 1.

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
is_defaultInt64Default-selection flag: 2 = not the default on every row (the site prepends its own 'all teams' row, which this route does not send).
keyStringTeam display name (Chinese) in the requested season; names change with the sponsor, the teamId does not.
valueStringteamId (key space: CBA clubs; 5 digits 29115-29140 for the long-standing clubs, 9 digits for newer ones (100074683 = Ningbo); stable across seasons and club renames, but the display name changes with the sponsor: 29128 = 浙江广厦 'Zhejiang Guangsha' under many sponsor names, 浙江浙商证券 in 2025-26). Joins getTeam / teamList and the team and player routes. Not a player or schedule id. Here a string of digits.

return_parsed=False — the raw DECRYPTED JSON (list or dict); a game route that answers an object also carries _request (the game id), and play-by-play is merged over every period into {records, total}.

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. The host answered 404, or the game has no play-by-play (2009-10).
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. The fetch failed or the answer is not the one asked for (an unfinished game, a body that does not decrypt or an unencrypted error envelope, an empty body, a body for another game or season, a partial play-by-play set, a dead connection).
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.
