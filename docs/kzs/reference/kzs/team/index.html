KZS — KZS FMS public API (Basketball Federation of Slovenia) — Team

kzs_team_leaderboard​

Team leaderboard of a competition for one stat category (total, per-game average and single-game best).

Endpoint URL: GET https://api.kzs.si/api/v1/public/competitions/{competition_id}/teamStats

Valid URL: https://api.kzs.si/api/v1/public/competitions/579/teamStats?limit=1000&statsCategory=PTS&orderType=AVERAGE&sortBy=avg&sort=DESC

API ParameterPythonPatternRequiredNullableDescription
competition_idcompetition_idYCompetition id (competition_id in kzs_competitions): one per competition per season, e.g. 579 (men's first league 2025/26).
statsCategorystats_categoryYStat category (the site's statsCategory): PTS points, M_2/A_2/PERC_2 two-pointers, M_3/A_3/PERC_3 three-pointers, M_FG/A_FG/PERC_FG field goals, M_FT/A_FT/PERC_FT free throws, R rebounds (R_D defensive, R_O offensive), ASS assists, ST steals, TOV turnovers, PF_CM/PF_RV fouls committed/received, ASS_TOV and ST_TOV ratios. Competitions without live stats offer only PTS, M_2, M_3, M_FT, A_FT, PERC_FT.
orderTypeorder_typeYFigure the leaderboard is built on: AVERAGE (per game), SUM (season total) or BEST_PERFORMANCE.
sortBysort_byYRow column the board is ordered by: avg (average), sum or max. The runtime checks the order.
sortsortYSort direction.

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
competition_idInt64Competition id: one per competition per season (men's first league 2025/26 = 579, 2026/27 = 608).
stats_categoryStringStat category of the board (PTS points, R rebounds, ASS assists ...): the request's, the rows do not echo it.
club_idInt64Club id: the club across seasons and categories (Ilirija = 16). No captured route is keyed by it.
club_fullnameStringClub's full legal name.
club_logo_uuidStringClub logo: image file id, served at https://api.kzs.si/public/images/{uuid}.
club_codeStringClub 3-letter code.
team_idInt64Team id: one club team in one season (Ilirija 2025-26 = 17551). Joins to /teams/{teamId}, standings teamId, box-score teamId and the teamId query params.
team_nameStringTeam name for the season, sponsor included.
games_playedInt64Games the team played in the competition.
sumFloat64Season total of the requested statsCategory.
averageFloat64Per-game average of the statsCategory.
maxFloat64Single-game best of the statsCategory.

return_parsed=False — the raw JSON Dict payload, unparsed.

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. The API has nothing for the request (an empty list, a competition without standings, a final game with no play-by-play or box score).
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help. The API answered HTTP 400 (its only error status: an unknown id or a bad parameter).
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. The fetch failed or the answer is unknown or partial: a full list page, a game that is not final, an envelope whose status is not OK, or a body for another competition, match, team, player or season than the one asked for.

Example​

kzs_team_leaderboard(competition_id=579)
