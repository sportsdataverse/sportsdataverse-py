# Website

The sdv-py docs site, built with [Docusaurus 3](https://docusaurus.io/) on the Rspack-based `faster` pipeline
(`future: { v4: true, faster: true }` in `docusaurus.config.ts`). Node 20+ (CI uses 22) and Yarn 1.

The per-league reference pages are generated by `uv run python tools/codegen/generate.py`; never hand-edit them.

## Installation

```sh
yarn install --frozen-lockfile
```

## Local development

```sh
yarn start
```

## Build

```sh
python3 ../tools/hooks/sync_docs_changelog.py --no-git-add   # renders the gitignored unreleased-changelog page
NODE_OPTIONS=--max-old-space-size=8192 DOCUSAURUS_SSG_WORKER_THREAD_COUNT=2 yarn build
```

The build compiles every kept docs version, so it needs the larger heap; the worker cap keeps each render thread's
copy of the server bundle from exhausting memory.

## Deployment

`.github/workflows/docs-deploy.yml` builds and publishes `build/` to the `gh-pages` branch on every push to `main`.
There is no manual deploy step.
