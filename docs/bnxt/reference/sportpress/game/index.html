sportpress_game_slider​

The latest 14 finished games of a competition plus every upcoming game, with the Genius match id.

Endpoint URL: GET https://bnxt.sportpress.info/api/v1/schedule/game-slider/{competition_id}

Valid URL: https://bnxt.sportpress.info/api/v1/schedule/game-slider/25

API ParameterPythonPatternRequiredNullableDescription
competition_idcompetition_idYRequired. Competition id (integer), ONE per season of the league: 24 = 2025-26, 25 = 2026-27 (sportpress_phases maps a season to it).

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
game_idInt64Game id (key space: sportpress games), unique across seasons: the key of every game route.
genius_idInt64Genius Sports LiveStats match id (organisation BNXT): the join to the genius family. Upcoming games already carry one; null for the 2020-21 competition.
game_timeStringTip-off as a naive datetime. The source carries no offset; the league's local time is assumed and unverified.
statusStringGame status: finished, or ready for an upcoming game.
competition_idInt64Competition id (key space: sportpress competitions): ONE season of the league (24 = 2025-26, 25 = 2026-27). Not the season number. The key of the standings, ranking, slider and box routes.
seasonInt64Season END year (2026 = 2025-26), the sdv convention and the API's own season key.
phase_idInt64Phase id (key space: sportpress phases), a stage of one competition such as the regular season or the playoffs; new every season.
phase_nameStringPhase name as entered in the CMS ('Regular season 2026-27').
home_competition_team_idInt64Home side. Competition-team id (key space: sportpress competition teams): a team in ONE competition, so the same club has a new id every season (Antwerp = 3 in 2021-22, 506 in 2025-26, 541 in 2026-27). Joins competitors, rosters, box scores, film and standings. The stable club key across seasons is uu_team_id.
home_teamStringHome side. Display name incl. the sponsor. Teams of the playoff phases carry a ' playoff' suffix (2025-26), and standings names vary with X-Localization ('Partena Professional Okapi Aalst Playoff' (en) vs 'Okapi Aalst Playoff' (nl, fr)): never join on it.
home_team_short_nameStringHome side. Three-letter club code (CHA, OOS, ANT, MON, LIM, ...), stable across seasons in the samples.
home_scoreInt64Home side. Final points of the side, including overtime.
away_competition_team_idInt64Away side. Competition-team id (key space: sportpress competition teams): a team in ONE competition, so the same club has a new id every season (Antwerp = 3 in 2021-22, 506 in 2025-26, 541 in 2026-27). Joins competitors, rosters, box scores, film and standings. The stable club key across seasons is uu_team_id.
away_teamStringAway side. Display name incl. the sponsor. Teams of the playoff phases carry a ' playoff' suffix (2025-26), and standings names vary with X-Localization ('Partena Professional Okapi Aalst Playoff' (en) vs 'Okapi Aalst Playoff' (nl, fr)): never join on it.
away_team_short_nameStringAway side. Three-letter club code (CHA, OOS, ANT, MON, LIM, ...), stable across seasons in the samples.
away_scoreInt64Away side. Final points of the side, including overtime.

return_parsed=False — the raw body (dict): {'data': ...} (the settings object for the site config, the nine-category object for the rankings) with contact fields dropped, plus _request (the season, competition, team, roster or game ids asked for).

ExceptionDescription
