sportpress_ui_strings​

UI string tables of the site in English, French and Dutch (one row per language and key).

Endpoint URL: GET https://bnxt.sportpress.info/api/v1/server-config

Valid URL: https://bnxt.sportpress.info/api/v1/server-config

API ParameterPythonPatternRequiredNullableDescription

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
languageStringISO 639-1 code of the UI language: en, fr (French) or nl (Dutch).
keyStringDotted UI string key such as 'statistics.individual.points'; 302 keys per language.
textStringThe UI text in that language; 11 keys label statistics columns, the rest are menus and buttons.

return_parsed=False — the raw body (dict): {'data': ...} (the settings object for the site config, the nine-category object for the rankings) with contact fields dropped, plus _request (the season, competition, team, roster or game ids asked for).

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. The API has nothing for the request (HTTP 404, an empty data list: an unknown id or a season without data, an empty ranking).
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. The fetch failed or the answer is not the one asked for (a rejected key: 'key rotated?', an error or changed envelope, a game that is not finished, a body for another season, competition, team or game).
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.

roster_idInt64Roster id (key space: sportpress roster entries): one player on one competition team in one season, so a player has a new roster_id for every team and season. player_id is the person.
competition_team_idInt64Competition-team id (key space: sportpress competition teams): a team in ONE competition, so a club has a new id every season (Antwerp = 3 in 2021-22, 506 in 2025-26, 541 in 2026-27). uu_team_id is the stable club key.
jerseyStringShirt number as text; the box score sends it as an integer, so a zero-padded '00' is already lost there.
weightInt64Weight in kg; null when unknown.
heightInt64Height in cm; null when unknown.
activeBooleanTrue for a current roster entry; former entries are false.
position_idInt64Position id (key space: sportpress positions; 3 = small_forward).
positionStringPosition code: point_guard, shooting_guard, small_forward, power_forward, center, and the hybrids point_guard-shooting_guard, shooting_guard-small_forward, small_forward-power_forward, power_forward-center.
player_idInt64Player id (key space: sportpress persons): stable across seasons and teams, distinct from roster_id. Not a Genius or FIBA person id.

return_parsed=False — the raw body (dict): {'data': ...} (the settings object for the site config, the nine-category object for the rankings) with contact fields dropped, plus _request (the season, competition, team, roster or game ids asked for).

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. The API has nothing for the request (HTTP 404, an empty data list: an unknown id or a season without data, an empty ranking).
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. The fetch failed or the answer is not the one asked for (a rejected key: 'key rotated?', an error or changed envelope, a game that is not finished, a body for another season, competition, team or game).
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.
