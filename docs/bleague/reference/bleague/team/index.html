B.LEAGUE — B.LEAGUE game contexts (S3) and pages (www.bleague.jp, Japan) — Team

bleague_team_box​

Team rows of the box score (team-credited stats and team totals) per period category.

Endpoint URL: GET https://b-league.s3.amazonaws.com/web_json/contexts/{schedule_key}

Valid URL: https://b-league.s3.amazonaws.com/web_json/contexts/504734

API ParameterPythonPatternRequiredNullableDescription
schedule_keyschedule_keyYRequired. B.LEAGUE ScheduleKey (integer, one global sequence across B1, B2, B3 and every season), e.g. 504734 = B1 2025-26 sec 1, Alvark Tokyo v Utsunomiya Brex; list a day's keys with bleague_schedule.
seasonseasonYOptional guard: the season END year the game must belong to. A context whose Year differs raises AssetFetchError. Omitted = no check (the key alone selects the game).

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
schedule_keyInt64B.LEAGUE ScheduleKey (key space: B.LEAGUE games, ONE global integer sequence across B1, B2, B3 and every season). The {schedule_key} every game wrapper takes and the schedule page's list-item id.
seasonInt64Season END year (2026 = 2025-26), the feed's Year (the START year) plus one.
feedStringSource feed of the row: v2 (v2_genius_contexts, B1/B2 from 2020-21) or v1 (v1_contexts: B3, B1/B2 2018-2020, and the 2016-17 / 2017-18 game-page embed). The feeds differ in id types, dates and some codes.
team_sideStringSide of the game the row belongs to: home or away.
team_idStringB.LEAGUE TeamID as text (key space: B.LEAGUE clubs, stable across seasons AND club renames: 703 = Tochigi Brex in 2016-17 = Utsunomiya Brex in 2025-26). The feed sends a string on v2 and an integer on v1; both are text here. Not a player id.
categoryInt64Row category: 1 = player, 2 = team / coaches row (team-credited stats; on v1 it names the head coach), 3 = team totals (合計). One row per (category, player, period category).
period_categoryInt64Period category: 1-4 = quarters 1-4, 15 = first half, 16 = second half, 18 = whole game. Overtime codes are unverified.
team_name_jStringTeam name in Japanese (official name, e.g. アルバルク東京 = Alvark Tokyo).
team_name_eStringTeam name in English, uppercase ('ALVARK TOKYO').
player_idStringB.LEAGUE PlayerID as text (key space: B.LEAGUE persons, stable across seasons and clubs: Makoto Hiejima = '8589'). A string on v2, an integer on v1; both are text here. Null where the row names no player.
player_noStringShirt number as text, so '00' and '0' stay distinct; null on team and game-level rows.
player_name_jStringPlayer name in Japanese (katakana for foreign players); null on team and game-level rows.
player_name_eStringPlayer name in English ('Makoto Hiejima'); null on team and totals rows.
play_timeStringMinutes played as the feed's 'mm:ss'; 'DNP' = did not play. Totals rows hold 5 x the period length ('200:00' for the game).
on_courtBooleanTrue for the five players on court when the context was last written (for a final game, at the final buzzer); the same value on every period row of the player. Null on v2 team and totals rows.
display_orderInt64Display order of the row (v1 only), integer; null on v2.
starterBooleanTrue when the player started; false for the bench; null on team and totals rows. (The feed sends 1 / null on v2 and a boolean on v1.)
seconds_playedInt64Time on court in seconds, parsed from play_time (50:00 = 3000); null for DNP and blank.
pointsInt64Points scored. The v2 feed sends '' (a placeholder, not 0) on the team row of quarters; null here.
fg3_madeInt64Three-point field goals made (v2 placeholder '' on quarter team rows becomes null).
fg3_attemptedInt64Three-point field goals attempted.
fg2_madeInt64Two-point field goals made.
fg2_attemptedInt64Two-point field goals attempted.
ft_madeInt64Free throws made.
ft_attemptedInt64Free throws attempted.
foulsInt64Personal fouls committed (F).
fouls_drawnInt64Fouls drawn (被ファウル, FD).
reb_offInt64Offensive rebounds (OR).
reb_defInt64Defensive rebounds (DR).
rebInt64Total rebounds.
turnoversInt64Turnovers (TO).
assistsInt64Assists credited to the player or team (AS).
stealsInt64Steals credited to the player or team (ST).
blocksInt64Blocks made (BS).
blocks_receivedInt64Shots of this player or team that were blocked (被ブロック, BSON).
ptfbInt64Fast-break figure (ファストブレイク); equals the summary's fast-break points on the one game checked, but whether it counts points or baskets is unverified.
pt2inInt64Inside-the-paint figure: on v2 a COUNT of made inside-the-paint 2PT (the summary holds 2x that in points); on v1 points in the paint (0 on B3, whose 2PT shots are never split by paint).
pt2ndInt64Second-chance figure (セカンドチャンス); smaller than the summary's second-chance points, so likely made baskets; unverified.
ptpftInt64Points off turnovers (ポインツオフターンオーバー); v1 box rows only, null on v2.
dunksInt64Dunks made (PT2DUNK); v1 box rows only, null on v2.
efficiencyInt64Efficiency rating (貢献度), era-dependent: v2 = points + rebounds + assists + steals + blocks + fouls drawn - missed FG - missed FT - turnovers - fouls - shots blocked (PIR); v1 omits fouls drawn, fouls and shots blocked.
plus_minusInt64Plus/minus: team point difference while on court. v2 from 2022-23 only; null on totals and half rows.
ast_toFloat64Assist-to-turnover ratio (0 when no turnovers). v2 from 2022-23 only; null on half rows.
efgFloat64Effective field-goal percentage as a FRACTION 0-1 (3PT weighted 1.5x); the site multiplies by 100. v2 from 2022-23 only.
tsFloat64True-shooting percentage as a FRACTION 0-1; the site multiplies by 100. v2 from 2022-23 only.
usgFloat64Usage rate in PERCENT 0-100. v2 from 2022-23 only; absent on totals rows.
off_rtgFloat64Offensive rating. v2 from 2022-23 only; on team and totals rows 0 in every sample, never filled.
def_rtgFloat64Defensive rating. v2 from 2022-23 only; on team and totals rows 0 in every sample, never filled.
net_rtgFloat64Net rating. v2 from 2022-23 only; on team and totals rows 0 in every sample, never filled.
possFloat64Possessions. v2 from 2022-23 only; on team and totals rows 0 in every sample, never filled.

return_parsed=False — the raw body (dict): the game context (Game, PlayByPlays, HomeBoxscores, AwayBoxscores, Summaries and on v1 Leaders, Points) stamped _request (schedule_key, feed), or the schedule / standings page record.

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. B.LEAGUE has nothing for the request (a ScheduleKey no source holds, a schedule day without games, HTTP 404).
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. The fetch failed or the answer is not the one asked for (an unfinished game, a context or page for another game, season, tab or day, an error or changed body, a truncated schedule list).
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help. A non-integer or out-of-range argument, or HTTP 400 / 422.

Example​

bleague_team_box(schedule_key=504734)

bleague_team_summary​

Team summary per period category in long form: shooting, rebounds, paint, fast-break and second-chance points.

Endpoint URL: GET https://b-league.s3.amazonaws.com/web_json/contexts/{schedule_key}

Valid URL: https://b-league.s3.amazonaws.com/web_json/contexts/504734
