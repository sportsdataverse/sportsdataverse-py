pgatour_schedule​

A tour's season schedule: one row per tournament (id, dates, course, purse, champion, points on offer), completed events first.

Endpoint URL: POST https://orchestrator.pgatour.com/graphql

Example request: curl -X POST 'https://orchestrator.pgatour.com/graphql' -H 'Content-Type: application/json' -d '{"operationName": "Schedule", "query": "query Schedule($tourCode: String!, $year: String) {\n schedule(tourCode: $tourCode, year: $year) {\n tour\n seasonYear\n completed { ...ScheduleMonthFields }\n upcoming { ...ScheduleMonthFields }\n }\n}\n\nfragment ScheduleMonthFields on ScheduleMonth {\n month\n year\n tournaments {\n id\n tournamentName\n date\n startDate\n sequenceNumber\n tournamentStatus\n courseName\n city\n state\n stateCode\n country\n countryCode\n purse\n champion\n championId\n championEarnings\n tourStandingHeading\n tourStandingValue\n }\n}\n", "variables": {"tourCode": "R", "year": "2026"}}'

API ParameterPythonInPatternRequiredNullableDescription
tourCodetour_codebodyYTour code (R PGA TOUR, S PGA TOUR Champions, H Korn Ferry Tour).
yearyearbodyYSeason year, e.g. 2026; omitted, the current season.

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
seasonInt64Season year the schedule belongs to (e.g. 2026).
schedule_statusString"completed" for an event already played, "upcoming" for one still to come.
tournament_idStringPGA TOUR tournament id (tour code + season + event number, e.g. "R2026014"); the id the leaderboard, scorecard, tee-times and shot-details wrappers take.
tournament_nameStringTournament's full name, sponsor included (e.g. "Travelers Championship").
dateStringTournament dates as the site displays them (e.g. "Apr 9 - 12").
start_dateDatetimeTournament start (UTC).
sequence_numberInt64Event's order in the season.
tournament_statusStringTournament status (e.g. "COMPLETED", "IN_PROGRESS", "NOT_STARTED").
course_nameStringCourse hosting the event (e.g. "TPC River Highlands").
cityStringCity the host course is in (e.g. "Cromwell").
stateStringHost state or province.
state_codeStringHost state or province abbreviation.
countryStringCountry the host course is in, spelled out (e.g. "United States of America").
country_codeStringHost country code (e.g. "USA").
purseStringTotal purse as displayed (e.g. "$9,100,000").
championStringWinner's name; null before the event finishes.
champion_idStringWinner's PGA TOUR player id.
champion_earningsStringWinner's share of the purse as displayed.
standing_headingStringSeason points race the event counts toward (e.g. "FEDEXCUP").
standing_valueStringPoints on offer to the winner as displayed (e.g. "500 pts").

return_parsed=False — the operation's answer (dict), its compressed payload decoded; pgatour_past_champions adds the tournamentId it was asked for, which the answer does not repeat.

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. The API answered null for the request (an unknown tournament, player or stat id), or pgatour_past_results was asked for a season the tournament has no edition in.
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help. The API rejected the query variables, or a variable is not of its type (a year that is not a season).
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. Any other GraphQL error, or a compressed payload that does not decode.

Example​

pgatour_schedule(tour_code='R', year=2026)
