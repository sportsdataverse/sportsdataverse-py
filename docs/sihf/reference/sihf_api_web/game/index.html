SIHF — SIHF statistics API (data.sihf.ch; National League, Swiss League and every SIHF league) — Game

sihf_game_info​

Header of one game: league, phase, teams, final and per-period score and shots, venue, attendance, officials.

Endpoint URL: GET https://data.sihf.ch/statistic/api/cms/gameoverview

Valid URL: https://data.sihf.ch/statistic/api/cms/gameoverview?alias=gameDetail&searchQuery=20261105000325&language=en

API ParameterPythonPatternRequiredNullableDescription
searchQuerygame_idYRequired. SIHF game id (game_id in sihf_results), e.g. 20261105000325.
languagelanguageYResponse language. Only part of the body is translated: status, position and penalty names stay German.

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
game_idintegerSIHF game id (Int64 join key; the details link of sihf_results, the searchQuery of the game wrappers).
seasonintegerSeason by its END year (2026 = 2025-26).
roundintegerRound number within the season.
league_idintegerSIHF league id of the game (1 = National League).
league_namecharacterLeague name (e.g., "National League").
region_idintegerSIHF region id of the game (1 = national).
region_namecharacterRegion name (e.g., "National").
group_idintegerSIHF group id (0 = no group).
group_namecharacterName of the league group the game belongs to ('Keine' = none).
tournament_idintegerSIHF tournament id (1 = championship).
tournament_namecharacterTournament name, German (e.g., 'Meisterschaft' = championship).
qualification_idintegerSIHF id of the stage of the season (1 = regular season).
qualification_namecharacterStage of the season (e.g., "Regular Season", "Playoff Final").
phase_idintegerSIHF phase id (regular season, a playoff round, ...).
phase_namecharacterPhase name (e.g., "NL Playoff Final").
start_date_timecharacterScheduled start, ISO-8601 with UTC offset, as a string.
end_date_timecharacterEnd of the game, ISO-8601 with UTC offset, as a string.
update_date_timecharacterWhen SIHF last updated the record, ISO-8601 with UTC offset, as a string.
status_idintegerSIHF game-status id (12 = finished).
status_namecharacterGame-status name; German whatever the language (e.g., "Ende").
status_percentintegerGame progress, 0-100 (100 once the game is over).
status_canceledlogicalWhether the game was cancelled.
home_team_idintegerSIHF team id of the home team.
home_team_namecharacterHome team display name.
home_team_acronymcharacterHome team abbreviation.
away_team_idintegerSIHF team id of the away team.
away_team_namecharacterAway team display name.
away_team_acronymcharacterAway team abbreviation.
home_scoreintegerFinal home score.
away_scoreintegerFinal away score.
home_score_by_periodintegerHome goals per period, aligned with period_indicators.
away_score_by_periodintegerAway goals per period, aligned with period_indicators.
home_shots_by_periodintegerHome shots on goal per period, aligned with period_indicators.
away_shots_by_periodintegerAway shots on goal per period, aligned with period_indicators.
period_indicatorscharacterPeriod labels: "1", "2", "3", then "OT1", ...
venue_namecharacterName of the arena the game was played in.
venue_citycharacterCity of the arena with its canton code (e.g., 'Davos-Platz GR').
spectatorsintegerAttendance as SIHF reports it.
refereescharacterReferee names, comma-joined.
linesmencharacterLinesman names, comma-joined.
broadcastscharacterBroadcasters, comma-joined (e.g., "MYSPORTS,TV24").

return_parsed=False — the raw JSON Dict payload, unparsed.

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. SIHF answered 404 (unknown game), or it ignored a requested season / league / phase and served another one.
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty.

Example​

sihf_game_info(game_id=20261105000325)

col_nametypedescription
game_idintegerSIHF game id (Int64 join key; the details link of sihf_results, the searchQuery of the game wrappers).
team_sidecharacterSide of the game the row belongs to: "home" or "away".
team_idintegerSIHF team id of the row's side.
team_namecharacterTeam name of the row's side.
player_numberintegerJersey number worn in this game.

assists1integerPrimary assists.

blockingsintegerOpponent shots blocked by the player.
