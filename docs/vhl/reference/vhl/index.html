VHL — VHL (vhlru.ru server-rendered pages, parsed)

sportsdataverse.hockey.vhl — 13 endpoints.

Note: Owner flag: the VHL is run by Russian league operators, and several clubs are owned or sponsored by sanctioned state companies. Fetching on your own machine is fine; a published data release or a hosted mirror needs the owner's sanctions / legal sign-off first.

vhl_schedule​

Schedule and results of one season stage: every game with its club ids, score and decision.

Endpoint URL: GET https://www.vhlru.ru/en/calendar/{season}/0/

Valid URL: https://www.vhlru.ru/en/calendar/2026/0/?stage=regular

API ParameterPythonPatternRequiredNullableDescription
seasonseasonYSeason END year (2026 = 2025/26; the calendar covers 2010/11 on). The runtime maps it, with stage, to the site's tournament id (tn) in this path segment.
stagestageYSeason stage: regular (default) or playoff.

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
seasonInt64Season END year (2026 = 2025/26).
stageStringSeason stage: regular or playoff.
tnInt64Tournament id of the season stage (2025/26 regular season = 1374, playoffs = 1375); vhl_tn maps season + stage to it.
game_idInt64Game id (the calendar's game_id; the report's and the broadcast's idgame). The report and broadcast pages do not print it: it comes from the request.
game_numberInt64Official game number within the tournament (from '№986').
game_dateStringGame date, ISO 'YYYY-MM-DD': the calendar day heading plus the season (August-December = START year).
dateStringDay header in English, day and month only ('18 March'); the page prints no year and no start time.
weekdayStringWeekday of the day header (English).
home_teamStringHome team name (Latin, FULL form: 'Kristall S'; standings, stats and the team page use the short 'Kristall').
home_club_idInt64Home club id: stable across seasons (the img.khl.ru logo path id). Neither a team-season id nor a team page id.
away_teamStringAway team name (Latin, FULL form, like home_team).
away_club_idInt64Away club id: stable across seasons (the img.khl.ru logo path id).
cityStringCity of the home team's arena (English).
scoreStringFinal score 'home:away'; '-:-' before the game.
home_scoreInt64Home goals including the shootout winner goal; null before the game.
away_scoreInt64Away goals including the shootout winner goal; null before the game.
decisionStringHow the game ended beyond regulation: OT (overtime) or SO (shootout); null for regulation or unplayed games.
winnerStringWinning side from the win-home / win-visitor class: home or away; null before the game.
statusStringUnobserved in samples (null in every capture); type and meaning unverified.
online_urlStringText-broadcast URL (online.vhlru.ru/online/{game_id}.html).

return_parsed=False — the page's parsed record (dict), plus _request (season, stage, tn and the ids asked for).

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. The VHL has nothing for the request (a season without that stage, a game not in the season's calendar, an unknown game, player or team page).
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. The page could not be fetched, or it is not the page asked for (another season, game or player; a missing table or header drift).
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.
