elh_events​

Cumulative shot attempts and shots on goal of one game, per team and game minute.

Endpoint URL: GET https://s3-eu-west-1.amazonaws.com/hokej.cz/visualization/events/{match_id}.json

Valid URL: https://s3-eu-west-1.amazonaws.com/hokej.cz/visualization/events/2928321.json

API ParameterPythonPatternRequiredNullableDescription
match_idmatch_idYhokej.cz game id (the S3 file name; hokejcz_game_id of elh_game_ids / elh_scoreboard), e.g. 2928321. Not the onlajny game id.

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
start_dateStringScheduled start, local YYYY-MM-DD HH:MM.
team_sideStringThe team's side: home or away.
team_nameStringTeam full (official) name.
team_scoreInt64The team's final goals.
minuteInt64Game minute (1-60), the end of which the totals run to.
shotsInt64Cumulative shot attempts up to the end of the minute.
shots_on_goalInt64Cumulative shots on goal up to the end of the minute.

return_parsed=False — the raw JSON Dict payload, unparsed.

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. A missing file (404 NoSuchKey), a scoreboard day outside the rolling window, or a stub body (no comments / shots / minutes, no Extraliga game that day).
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. An error envelope, a body for another game or day, or a broken listing page.
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.

Valid URL: https://s3-eu-west-1.amazonaws.com/hokej.cz/?prefix=match%2F2026%2Ffull%2F&max-keys=3

API ParameterPythonPatternRequiredNullableDescription
prefixprefixYKey prefix, e.g. match/2026/full/ or visualization/shots/.
delimiterdelimiterY/ groups keys below the next slash into CommonPrefixes (folder view).
markermarkerYListObjects V1 paging: the last Key of the previous page; repeat until IsTruncated is false (V1 sends NextMarker only with a delimiter).
max-keysmax_keysYPage size, at most 1000 (the default).
list-typelist_typeY2 switches to ListObjectsV2 (KeyCount, NextContinuationToken); omitted = V1 as documented here.
continuation-tokencontinuation_tokenYV2 only (list-type=2): NextContinuationToken of the previous page.
start-afterstart_afterYV2 only (list-type=2): list keys after this key.

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. A missing file (404 NoSuchKey), a scoreboard day outside the rolling window, or a stub body (no comments / shots / minutes, no Extraliga game that day).
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. An error envelope, a body for another game or day, or a broken listing page.
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.
