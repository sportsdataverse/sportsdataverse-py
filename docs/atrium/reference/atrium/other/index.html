atrium_fixtures​

Fixtures (schedule and results) of a season, home and away side by side.

Endpoint URL: GET https://embed-api.eui.connect.sportradar.com/v1/embed/{website_id}/fixtures

Valid URL: https://embed-api.eui.connect.sportradar.com/v1/embed/14/fixtures

API ParameterPythonPatternRequiredNullableDescription
website_idwebsite_idYSite config id: which league site's widget this is (12 LNB France, 14 LNBP Mexico, 3 NBL1 Australia, 13 El Salvador, 22 Panama, 236 Austria, 326 Montenegro). Not a league id: one site serves several competitions.
seasonseasonYSeason END year (2026 = 2025-26 on LNB, site 12, whose own year is the START year; the calendar year on the other sites). Needs competition_id when several competitions share that year (see atrium_seasons). Omit season and season_id for the site's default season.
seasonIdseason_idYSeason UUID (season_id in atrium_seasons); sent as is, skipping the END-year lookup of season.
competitionIdcompetition_idYCompetition UUID (competition_id in atrium_seasons). Picks the season together with season, and is then not sent; with neither season nor season_id the API filters by it.
entityIdentity_idYTeam UUID (entity_id in atrium_teams or any fixture row).
roundNumberround_numberYRound (journee) number to show; the pages that take it list their rounds.
subsubYTab: FIXTURES (upcoming) or RESULTS (played). Omitted = the site's default tab.
localelocaleYLocale of the labels, e.g. en-EN or fr-FR. Omitted = the site's own language. Ids and codes never change.

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.

table_labelStringThe table's heading in the site's language (e.g. Moyennes).
person_idStringPlayer UUID decoded from the widget link beside the name (the tables carry names only); null when the link is missing or undecodable, and always null in team and competition bodies.
person_nameStringPlayer name as the site prints it; null in team tables.
entity_idStringTeam UUID decoded from the widget link (team tables only; player tables name the team but carry no id).
entity_nameStringTeam name as the site prints it; for player rows of a stat table it is the player's team.
stat_keyStringStatistic key as the API names it (pointsPerGame, fieldGoalsMade, ...), unchanged from header key.
stat_nameStringShort column heading the site shows for the statistic (PTS, REB), in the site's language.
stat_labelStringLonger statistic label the site shows (code in the API), in the site's language.
valueFloat64Numeric value of the statistic; null when the API sends a duration or text (see value_text).
value_textStringNon-numeric statistic value, e.g. an ISO 8601 duration such as PT12M2S for minutes per game.

return_parsed=False — the raw JSON Dict payload, unparsed.

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. The site has nothing for the request (no such season, an empty fixture list, a game with no play-by-play yet, an unknown id answered 404, or a fixture id the site does not serve: an unknown id, or a game of another site (the API answers both with an empty fixture)).
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. Also raised for an error body, a stub, or a body that belongs to another site, type, season, game, player or team than the one asked for.
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.
