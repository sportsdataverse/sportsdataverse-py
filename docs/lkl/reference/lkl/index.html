LKL — LKL site API (lkl.lt, Lithuania)

sportsdataverse.basketball.lkl — 14 endpoints.

Note: Unofficial and unsupported: these are the routes lkl.lt's own game page calls (found in its front-end bundle) and its server-rendered pages. The site's robots.txt allows everything and sets no crawl-delay; lkl_runtime still spaces requests at least 1 s apart. SportsDataverse has not ruled on the site's terms, so payloads are not redistributed as release assets.

Note: Coverage: game wrappers serve FINISHED games only (an unfinished game raises AssetFetchError). The box score, summary, score line, statistics and leaders answer for every season from 1993-94 (before 2024-25 the scoring splits and lead statistics are 0). Play-by-play and shots exist from 2024-25 only; an earlier finished game raises NoDataError. From 2016-17 the results season id is also the Genius LiveStats competition id (see the genius family) which holds play-by-play for older games; lkl.lt game, team and player ids are lkl.lt's own and do not join Genius ids. The King Mindaugas Cup shares the routes but is not wrapped. Text fields are Lithuanian.

lkl_game_info​

Game header from the game page: status, tip-off, venue, attendance, officials and both teams.

Endpoint URL: GET https://lkl.lt/rungtynes/{game_id}

Valid URL: https://lkl.lt/rungtynes/11446

API ParameterPythonPatternRequiredNullableDescription
game_idgame_idYRequired. lkl.lt game id (integer), e.g. 11446; game_id in lkl_results. Not sequential by season before 2018-19. Only a finished game is served.

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
game_idInt64lkl.lt game id (key space: LKL games; the {gameId} of every route). Not sequential by season before 2018-19; not the Genius matchId. A frame parsed from a bare body has a null game_id when the body does not echo it (the runtime stamps it under _request).
game_statusStringGame state label in Lithuanian: 'Pasibaigė' = finished, the only value served (the runtime refuses an unfinished game).
start_dateStringGame date (Europe/Vilnius), parsed from the page header 'YYYY m. D d., HH:MM'.
start_timeStringTip-off 'HH:MM' local time (Europe/Vilnius by the site's wording; the page carries no offset).
arenaStringArena name as printed on the game page header.
attendanceStringAttendance text as printed ('1097 žiūrovai' = 1097 spectators).
attendance_countInt64Attendance as an integer, parsed from the attendance text; null when the page has none.
refereesStringReferee names, comma-separated, crew chief first; 'Nepaskelbta' = not announced (old games). Names only: the site publishes no official's contact or birth data.
has_actionsBooleanTrue when the game has play-by-play events (2024-25 onward); false on older games.
is_streamingBooleanTrue while a live stream is on; false on finished games.
home_team_idInt64Home team id (key space: lkl.lt clubs, stable across seasons and renamings; joins the team_id of every other frame). Not the Genius team id.
home_teamStringHome team name as of that game (historical: 'Lietuvos Rytas' in 2007-08).
home_short_nameStringHome three-letter team code ('RYT'); can be the club's current code on old games.
home_slugStringHome team slug (key space: lkl.lt clubs; the {slug} of lkl.lt/komandos/{slug}); joins the team slugs of lkl_results and lkl_standings.
home_winnerBooleanTrue when the home team won the game.
home_coachStringHome head coach's full name as stored for the team: on old games the CURRENT coach, not the historical one.
home_assistant_coachStringHome assistant coach's full name (same caveat as the head coach: current staff on old games).
away_team_idInt64Away team id (key space: lkl.lt clubs, stable across seasons and renamings; joins the team_id of every other frame). Not the Genius team id.
away_teamStringAway team name as of that game (historical: 'Lietuvos Rytas' in 2007-08).
away_short_nameStringAway three-letter team code ('RYT'); can be the club's current code on old games.
away_slugStringAway team slug (key space: lkl.lt clubs; the {slug} of lkl.lt/komandos/{slug}); joins the team slugs of lkl_results and lkl_standings.
away_winnerBooleanTrue when the away team won the game.
away_coachStringAway head coach's full name as stored for the team: on old games the CURRENT coach, not the historical one.
away_assistant_coachStringAway assistant coach's full name (same caveat as the head coach: current staff on old games).

return_parsed=False — the raw body (dict): the JSON of a game route, the game page record, or the merged results / standings record, plus _request (the game id, team ids and slug -> player id map, or the season asked for).

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. Lkl.lt has nothing for the request (an unknown game or standings season, a season the site's selects do not list, a finished game before 2024-25 asked for play-by-play or shots).
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. The fetch failed or the answer is not the one asked for (an unfinished game, a body or page for another game or season, an error or changed body, a truncated results list).
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.
