IBBA — Segev Stats live-stats API (stats.segevstats.com, Israel play-by-play)

sportsdataverse.basketball.ibba — 6 endpoints.

Note: Access (sdv-internal-refs/ibba/README.md): Segev Stats is the live-stats vendor behind basket.co.il's game pages; its JSON-RPC API is keyless, unofficial and not documented for outside use. The wrappers space requests at least one second apart and read only finished games; payloads are not redistributed as release assets. The host serves JSON as text/html.

Note: Games and ids. game_id is one flat Segev id space across seasons AND competitions: men's Winner League, Winner Cup, women's, Leumit, youth, school and pre-season games share it, so read competition from ibba_segev_game_info (team names do not separate men from women reliably). There is no game list: league game ids come from ibba_games.segev_game_id (2025-26 on), the women's league and Leumit from a scan or Genius Sports org IBBA. Segev team and player ids are stable across seasons (Jaylen Hoard = player 1000 in games 50 and 419), unlike the IBBA season registrations, and are not IBBA ids.

Note: Play-by-play: actions name the player by Segev id and by JERSEY number, score reads away-home, and shot x / y are one half-court frame (x 0-1470 across, basket near 735; y out from the baseline, rim near 112-140); which sideline is x = 0 and the metric scale are unverified. Segev renamed its team game stats between 2025-26 and 2026-27; the parsers unify them. Unfinished games and ids of another game are refused.

ibba_segev_game_info​

Game header: tip-off, competition, both teams and the game state (scores are in the box score).

Endpoint URL: GET https://stats.segevstats.com/realtimestat_heb/api/

Valid URL: https://stats.segevstats.com/realtimestat_heb/api/?method=getGameInfo&game_id=50

API ParameterPythonPatternRequiredNullableDescription
game_idgame_idYRequired. Segev game id (e.g. 50 = Hapoel Be'er Sheva vs Maccabi Tel Aviv, 2025-26 round 1): segev_game_id in ibba_games.

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
game_idintegerSegev game id (key space: one flat sequence across seasons and competitions); equals the IBBA ibba_games segev_game_id from 2025-26. Not an IBBA game id.
start_timecharacterScheduled tip-off in Israel local time as a naive datetime (the feed has no offset; it can differ from the IBBA tip_off by minutes).
competitioncharacterCompetition name ('Winner League', 'Winner Cup', 'Women', 'Leumit', 'Noar', 'School', 'Preparation Games'): the reliable men's / women's discriminator.
home_team_idintegerHome Segev team id (key space: Segev teams, stable across seasons and competitions; Maccabi Tel Aviv = 2). Not an IBBA team-season id.
home_teamcharacterHome team name in English, upper case; some women's teams end in ' (W)', not all.
home_team_localcharacterHome team name in Hebrew (Latin sponsor words kept).
home_short_namecharacterHome team short name in English, upper case.
away_team_idintegerAway Segev team id (key space: Segev teams, stable across seasons and competitions).
away_teamcharacterAway team name in English, upper case.
away_team_localcharacterAway team name in Hebrew (Latin sponsor words kept).
away_short_namecharacterAway team short name in English, upper case.
periodsintegerRegulation periods in the game (4).
finishedlogicalTrue once the game is final (the wrappers read finished games only).
current_periodintegerCurrent period, the last one played for a finished game (5+ means overtime).
clockcharacterGame clock remaining as 'mm:ss' ('00:00' for a finished game).

return_parsed=False — the raw JSON-RPC envelope (dict): result with the method's block plus _request (the method and game id sent).

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. Segev has nothing for the request (HTTP 404, 'game not found', a finished game with no actions).
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. The fetch failed or the answer is not the one asked for (a non-200, an error or changed envelope, a body for another game, a game that is not final).
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.
