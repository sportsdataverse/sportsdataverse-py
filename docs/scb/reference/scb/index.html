BBL / DBBL (SCB) — SCB basketball API (BBL and DBBL, Germany)

sportsdataverse.basketball.scb — 23 endpoints.

Note: Unofficial use of a public source: these wrappers read the front-end API of the German Bundesliga sites (easycredit-bbl.de, toyota-dbbl.de), run by SCB; payloads are not redistributed as release assets.

Note: Legal notice: the BBL Impressum forbids storing BBL content (Inhalte) in an information system without BBL's written permission. That is a copyright term, not a robots rule (the API host has no robots.txt). The owner reviewed it and accepted the intake (2026-10-12 ruling); keep requests slow (the runtime waits at least 1 s per host) and raise any published data release with the owner. The DBBL host is the same operator and API; its site notice was not separately reviewed.

Note: Both hosts need two headers: a constant x-api-key and an x-api-secret that rotates. The runtime derives the secret on first use from the key embedded in an easycredit-bbl.de page (reversed, : turned into -) and never logs or returns it. The derivation was reverse-engineered from observed requests and responses and has not been checked against the site's own front-end code; if the site changes how it signs requests, every call fails with AssetFetchError.

Note: Id key spaces: seasonId is the START year (2025 = 2025-26), so a wrapper's END-year season is sent as season - 1. Teams are keyed by teamId (seasonTeamId equals it in every sample). seasonPlayerId is per player per season and per club (a player traded mid-season has two); realPlayerId is the person. playerId is ambiguous (the seasonPlayerId in box scores, records and /season-players; the person in /transfers). Game ids are strings.

Game​

FunctionSummary
scb_games_recentRecent, live and upcoming games, one row per game with its past / present / future bucket.
scb_game_playersBox score of a finished game: one row per player line of both teams (2002-03 on).
scb_game_teamsBox score of a finished game: one row per team, with the head coach and the team line.
scb_game_actionsPlay-by-play of a finished game with shot x/y (BBL 2008-09 on, DBBL 2024-25 on).

Team​

FunctionSummary
scb_team_statisticsSeason team stat table: totals and per-game values, one row per team and stat block.
scb_teamClub profile: names, code, home page, ticket shop, year joined and honours.
scb_team_seasonsEvery season a club played: its name that season and its championship and cup titles.
scb_team_rostersPer club, the current roster, one row per player (BBL only).

Other​

FunctionSummary
scb_seasonsSeasons, newest first, with the active flag (BBL back to 1966, DBBL 2024 on).
scb_season_playersEvery player registered in a season: the id crosswalk (season_player_id, real_player_id, season_team_id).
scb_season_teamsEvery team of a season: club id, season-team id, name and three-letter code.
scb_playoff_seriesPlayoff bracket of a season: one row per series (quarter-finals, semi-finals, finals).
scb_playoff_gamesEvery playoff game of a season with its series and the points of each series team.
scb_player_statisticsSeason player stat table: totals and per-game values, one row per player and stat block.
scb_gamesGames of a season (the whole season in one page): teams, score by period, officials, venue and top scorer.
scb_gameOne game header: teams, score by period, officials, venue and top scorer.
scb_standingsLeague table of a season: record, home / away split, streaks and tie-break detail (2005-06 on).
scb_season_playerPlayer profile by season-player id: bio, position, club and previous clubs.
scb_refereesCurrent referees and commissioners (BBL only).
scb_transfersLatest transfers, one row per move (BBL only).
scb_transfers_teamsPer club, the players joining and leaving, one row per move with its direction (BBL only).
scb_records_per_gameSingle-game records: the season's and the all-time ones, one row per record.
scb_records_season_averagesAll-time season-average records (points, rebounds, assists, ...), one row per record.
