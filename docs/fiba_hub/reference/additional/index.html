FIBA (digital API and game pages) — additional Python functions

Additional functions in sportsdataverse.basketball.fiba_hub that are not generated API-endpoint wrappers (those have their own reference pages): per-competition functions minted from the competition registry (each binds a base wrapper to one competition), plus hand-written wrappers, loaders, and helpers.
