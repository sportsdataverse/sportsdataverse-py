fiba_gdap_awards​

Awards of a competition (MVP, All-Star Five...).

Endpoint URL: GET https://digital-api.fiba.basketball/hapi/getgdapcompetitionawardsbyid

Valid URL: https://digital-api.fiba.basketball/hapi/getgdapcompetitionawardsbyid?gdapCompetitionId=208182

API ParameterPythonPatternRequiredNullableDescription
gdapCompetitionIdcompYRequired. FIBA competition id (GDAP key space), one per edition: competition.competitionId of any game row (208182 = World Cup 2023, 208722 = Paris 2024 men, 208850 = BCL 2024-25). Find it with fiba_gdap_editions or fiba_gdap_games_between.
disciplineFormatdiscipline_formatYOptional; the site passes its discipline format. 5x5 answers the same as omitting it (verified on awards and rosters)

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
competition_idInt64FIBA competition id (GDAP key space): one per edition (2023 World Cup = 208182, BCL 2024-25 = 208850); gdapCompetitionId.
competition_end_dateStringLast day of the competition, YYYY-MM-DD.
award_dateStringDate awarded, YYYY-MM-DD.
competition_seasonInt64Season key, three rules: the END year for club competitions (BCL 2024-25 = 2025) and the event year for national-team events (World Cup 2023 = 2023), both equal to the sdv season key; qualifiers carry the TARGET tournament year, not the year played (World Cup 2027 qualifiers played in 2025 = 2027, EuroBasket 2029 pre-qualifiers = 2029), whose sdv mapping is an open Phase B decision.
competition_official_nameStringOfficial name of the competition edition the award was given in.
award_nameStringAward name (All-Star 5, MVP...).
award_codeStringAward code (ALLSTAR, MVP...).
award_level_idInt64Id of the object the award is attached to: the competitionId when awardLevel is Competition.
award_levelStringLevel the award is given at: Competition.
award_labelStringExtra label; null in every sample.
player_idInt64FIBA person id, global across competitions and roles (player, coach, official): roster personId = play-by-play pId = game-page P_ = gdapPlayerId.
player_first_nameStringAwarded player's first name.
player_last_nameStringAwarded player's last name.
player_date_of_birthStringAwarded player's date of birth, YYYY-MM-DD.
player_nationalityStringAwarded player's nationality, FIBA code.
teamsStringTeams the awarded player played for in the competition. Stored as a JSON string.

return_parsed=False — the raw JSON Dict payload, unparsed.

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. FIBA has nothing for the request (HTTP 404, or GDAP answered {} or [] for an unknown id).
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. The fetch failed, or the answer is not about the request (an error envelope, HTTP 401 after a key refresh, HTTP 500, a body for another game, competition, team, player, federation, family or season).
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help. HTTP 400 / 422, or a malformed id, season or date.
