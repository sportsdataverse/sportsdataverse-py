🏒🌍 European and college hockey with sportsdataverse-py

This page is the executed notebook 17_european_college_hockey_intro.ipynb: download it to run it yourself.

North America's minor and junior leagues have their own notebook (11_junior_hockey_intro). This one crosses the Atlantic and drops into the NCAA:

LeagueModuleProvider
SHL (Sweden)sportsdataverse.hockey.shlshl.se
Liiga (Finland)sportsdataverse.hockey.liigaliiga.fi
DEL (Germany)sportsdataverse.hockey.del_DEL (eSports feed)
KHLsportsdataverse.hockey.khlkhl.ru
NCAA men's / women's hockeysportsdataverse.hockey.mch / .wchESPN

DEL's package is del_, because del is a Python keyword. The European runtimes take the season as its END year (2026 is 2025-26) and space requests at least a second apart, so be patient. ⏳

🔌 Setup​

pip install "sportsdataverse[sdvplot]"
import matplotlib.pyplot as plt
import polars as pl

from sportsdataverse.hockey import del_, khl, liiga, mch, shl, wch

pl.Config.set_tbl_rows(10)
SEASON = 2026  # END year: the completed 2025-26 season

Provider feeds are seasonal and occasionally rate-limited, so a tiny safe() helper runs each call defensively: you get the frame when the feed is up, and a one-line skip when it isn't, naming whether the answer was nothing there (NoDataError) or the fetch failed (AssetFetchError). 🛟

from sportsdataverse.errors import AssetFetchError, NoDataError

def safe(label, thunk):
    try:
        out = thunk()
        print(f"✅ {label}")
        return out
    except (NoDataError, AssetFetchError) as e:
        print(f"\u23ed\ufe0f  {label}: {type(e).__name__}: {e}")
        return None

A DEL shot map 🎯​

del_shots ships coordinate_x / coordinate_y in the provider's own frame (both axes run about -100 to 100), plus team_side and is_goal. sdvplot has no mapping from this frame to a regulation IIHF rink yet, so the chart below plots the raw frame rather than drawing a rink under it.

dsched = safe(f"DEL schedule {SEASON}", lambda: del_.del_schedule(SEASON))
mid = int(dsched.filter(pl.col("final_score_home").is_not_null())["match_id"][-1]) if dsched is not None else None
dshots = safe(f"DEL shots {mid}", lambda: del_.del_shots(mid)) if mid else None
if dshots is not None and dshots.height:
    fig, ax = plt.subplots(figsize=(8, 5))
    for side, color in (("home", "#1f77b4"), ("visitor", "#ff7f0e")):
        s = dshots.filter(pl.col("team_side") == side)
        name = s["home_name" if side == "home" else "visitor_name"][0] if s.height else side
        ax.scatter(s["coordinate_x"], s["coordinate_y"], s=25, alpha=0.6, c=color, label=name)
    goals = dshots.filter(pl.col("is_goal") == True)
    ax.scatter(goals["coordinate_x"], goals["coordinate_y"], s=160, facecolors="none",
               edgecolors="black", linewidths=1.5, label="goal")
    ax.set_xlim(-105, 105)
    ax.set_ylim(-105, 105)
    ax.set_aspect("equal")
    ax.legend(loc="upper center", ncol=3, fontsize=8)
    ax.set_title(f"DEL match {mid}: {dshots.height} shots (provider frame)")
    plt.show()
else:
    print("no DEL shots for this match")

🎓 College hockey (ESPN)​

The NCAA men's (mch) and women's (wch) leagues ride the cross-league ESPN wrappers. Team colors come from sdvplot's team_colors, keyed by ESPN team id under the ncaa_mhockey league key.

import sdvplot

cst = safe("NCAA men's hockey standings", mch.espn_mch_standings)
if cst is not None and cst.height:
    top = cst.sort("wins", "win_percent", descending=True).head(15).sort("wins", "win_percent")
    colors = sdvplot.team_colors("ncaa_mhockey", [str(i) for i in top["team_id"]])
    colors = [c or "#999999" for c in colors]
    fig, ax = plt.subplots(figsize=(7, 6))
    ax.barh(top["team_display_name"], top["wins"], color=colors)
    ax.set_xlabel("wins")
    ax.set_title("NCAA men's hockey: the 15 teams with the most wins so far")
    plt.tight_layout()
    plt.show()
else:
    print("standings unavailable")
