🏀🌍 International basketball with sportsdataverse-py

This page is the executed notebook 16_international_basketball_intro.ipynb: download it to run it yourself.

The NBA is one league; the rest of the basketball world is dozens. sportsdataverse-py wraps the feeds behind the biggest of them, and this notebook tours four:

LeagueModuleProvider
EuroLeaguesportsdataverse.basketball.euroleagueEuroLeague Competition Engine
Super League Basketball (UK)sportsdataverse.basketball.geniusGenius Sports LiveStats
NBL (Australia)sportsdataverse.basketball.nbl_auNBL Rosetta
Liga Endesa (Spain)sportsdataverse.basketball.acbACB

No API keys, polars by default (return_as_pandas=True for pandas), and at the end a EuroLeague shot chart drawn on a FIBA court with sdvplot. 🎯

🧰 The toolbox​

FunctionWhat it gives you
euroleague_seasonsSeasons of a competition (E = EuroLeague, U = EuroCup)
euroleague_gamesEvery game of a season, played or not
euroleague_standingsStandings after a round
euroleague_game_pointsShot chart of one game (coord_x / coord_y in cm)
slb_competitionsSLB competitions with their END-year season
slb_scheduleEvery match of an SLB season
slb_player_boxPlayer box score of a finished SLB game
slb_shotsShot chart of a finished SLB game
nbl_rosetta_standingsNBL regular-season ladder
nbl_rosetta_matchesMatches of an NBL season
acb_standingsLiga Endesa table after a round
acb_calendarEvery round of a season with its games

Genius LiveStats serves many leagues (wbbl_*, bal_*, nznbl_*, esake_*, lfb_*, ...) with the same shape, so the SLB recipes below work for every one of them.

🔌 Setup​

pip install "sportsdataverse[sdvplot]"

The sdvplot extra brings in sdvplot and sportypy for the court drawing.

import matplotlib.pyplot as plt
import polars as pl

from sportsdataverse.basketball import euroleague as el
from sportsdataverse.basketball import acb, genius, nbl_au

pl.Config.set_tbl_rows(10)
polars.config.Config

Provider feeds are seasonal and occasionally rate-limited, so a tiny safe() helper runs each call defensively: you get the frame when the feed is up, and a one-line skip when it isn't, naming whether the answer was nothing there (NoDataError) or the fetch failed (AssetFetchError). 🛟

from sportsdataverse.errors import AssetFetchError, NoDataError

def safe(label, thunk):
    try:
        out = thunk()
        print(f"✅ {label}")
        return out
    except (NoDataError, AssetFetchError) as e:
        print(f"\u23ed\ufe0f  {label}: {type(e).__name__}: {e}")
        return None

🇪🇺 EuroLeague​

Season codes are the competition letter plus the START year (E2025 is 2025-26). We take the newest season that has a played game, so the notebook works in the off-season too.

seasons = safe("EuroLeague seasons", lambda: el.euroleague_seasons("E"))
season_code, games = None, None
if seasons is not None:
    for code in seasons.sort("year", descending=True)["code"].head(3):
        g = safe(f"games {code}", lambda code=code: el.euroleague_games("E", code))
        if g is not None and g.filter(pl.col("played") == True).height:
            season_code, games = code, g
            break
print("season:", season_code, "| games:", None if games is None else games.shape)

A shot chart on a FIBA court 🎯​

euroleague_game_points returns one row per field-goal attempt and made free throw, in centimeters with the hoop at the origin. sdvplot.court_coords(..., provider="euroleague") converts that frame to meters on the FIBA court that sdvplot.surface("fiba") draws (free throws, encoded -1, -1, become null). Both teams shoot at one basket, so we draw the defensive half.

import sdvplot

gcode = str(played["game_code"][-1]) if played is not None and played.height else None
pts = safe(f"shots game {gcode}", lambda: el.euroleague_game_points(gcode, season_code)) if gcode else None
if pts is not None and pts.height:
    shots = sdvplot.court_coords(pts, x="coord_x", y="coord_y", provider="euroleague")
    shots = shots.filter(pl.col("court_x").is_not_null())
    made = shots.filter(pl.col("id_action").is_in(["2FGM", "3FGM"]))
    missed = shots.filter(pl.col("id_action").is_in(["2FGA", "3FGA"]))
    ax = sdvplot.surface("fiba", display_range="defense")
    ax.scatter(missed["court_x"], missed["court_y"], marker="x", s=30, c="#888888", zorder=20, label="missed")
    ax.scatter(made["court_x"], made["court_y"], s=30, c="#d62728", zorder=21, label="made")
    ax.legend(loc="upper right")
    ax.set_title(f"EuroLeague {season_code} game {gcode}: {shots.height} field-goal attempts")
    plt.show()
else:
    print("no shot data for this game")
✅ shots game 69

🇪🇸 Liga Endesa (ACB)​

acb_standings defaults to the table after the current round; acb_calendar lists every round of the season in one call. A bar chart of the table makes the early-season race easy to read.

table = safe("ACB standings", acb.acb_standings)
if table is not None and table.height:
    t = table.sort("win_pct", "plus_minus")
    fig, ax = plt.subplots(figsize=(7, 6))
    ax.barh(t["team"], t["win_pct"], color="#1f4e79")
    ax.set_xlabel("win %")
    end = int(t["season"][0])  # END year
    ax.set_title(f"Liga Endesa {end - 1}-{str(end)[2:]} standings")
    plt.tight_layout()
    plt.show()
else:
    print("ACB standings unavailable")
