Provider feeds are seasonal and occasionally rate-limited, so a tiny safe() helper runs each call defensively: you get the frame when the feed is up, and a one-line skip when it isn't, naming whether the answer was nothing there (NoDataError) or the fetch failed (AssetFetchError). 🛟

from sportsdataverse.errors import AssetFetchError, NoDataError

def safe(label, thunk):
    try:
        out = thunk()
        print(f"✅ {label}")
        return out
    except (NoDataError, AssetFetchError) as e:
        print(f"\u23ed\ufe0f  {label}: {type(e).__name__}: {e}")
        return None

🏀 NBA G League​

The G League rides the cross-league ESPN wrappers (espn_nbagl_*). espn_nbagl_standings takes a season (END year), and sdvplot's team_colors("nbagl", ...) resolves ESPN team ids to each team's color.

The nbagl_enhanced_pbp / nbagl_possessions / nbagl_rapm_from_games helpers in the same module read stats.nba.com, which blocks datacenter IPs, so this notebook does not call them.

import sdvplot

gst = safe("G League standings 2026", lambda: nbagl.espn_nbagl_standings(season=2026))
if gst is not None and gst.height:
    top = gst.sort("win_percent", "point_differential")
    colors = [c or "#999999" for c in sdvplot.team_colors("nbagl", [str(i) for i in top["team_id"]])]
    fig, ax = plt.subplots(figsize=(7, 8))
    ax.barh(top["team_display_name"], top["win_percent"], color=colors)
    ax.set_xlabel("win %")
    ax.set_title("G League 2025-26 standings")
    plt.tight_layout()
    plt.show()
else:
    print("standings unavailable")

🏎️ Formula 1​

dst = safe(f"F1 driver standings {F1_SEASON}", lambda: f1.f1_driver_standings(F1_SEASON))
cols = ["position", "driver_given_name", "driver_family_name", "constructors", "points", "wins"]
dst.select([c for c in cols if c in dst.columns]).head(10) if dst is not None else None

📚 TheSportsDB​

safe("TheSportsDB leagues", thesportsdb.thesportsdb_leagues)
