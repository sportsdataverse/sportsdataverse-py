espn_wnba_calendar(season=None, ondays=None, return_as_pandas=False, **kwargs) -> 'pl.DataFrame'

espn_wnba_calendar - look up the WNBA calendar for a given season

Parameters

ParameterTypeDefaultDescription
seasonintNoneUsed to define different seasons. 2002 is the earliest available season.
ondaysbooleanNoneUsed to return dates for calendar ondays
return_as_pandasFalse

Returns

Polars dataframe containing calendar dates for the requested season.

col_nametypedescription
seasonInt64Season identifier (4-digit year or 'YYYY-YY' string).
datetimeStringThe calendar day as ESPN sends it, an ISO 8601 UTC timestamp string.
dateStringDate in YYYY-MM-DD format.
yearString4-digit year.
monthStringMonth of the calendar day as a two-digit string.
dayStringDay number within the month.
dateURLStringThe calendar day as YYYYMMDD, the dates= value of that day's scoreboard request.
urlStringRotoWire player page URL.

Raises

ExceptionDescription
ValueErrorIf season is less than 2002.

Example

from sportsdataverse.wnba import espn_wnba_calendar
cal = espn_wnba_calendar(season=2024)
print(cal.shape)
cal.head()

# Just the on-days (game-played dates), useful for batch loops

ondays = espn_wnba_calendar(season=2024, ondays=True)
for url in ondays["url"].head(3).to_list():
    print(url)

Pull ESPN WNBA draft picks for a season.

Parameters

ParameterTypeDefaultDescription

from sportsdataverse.wnba import espn_wnba_draft
draft = espn_wnba_draft(season=2024)

draft_pd[["overall_pick", "athlete_display_name", "school_name"]].head()
