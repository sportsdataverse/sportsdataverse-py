sportality_boxscore​

Player box score and team rows of both sides (2023/24 on).

Endpoint URL: GET https://www.basketligaen.dk/api/gameday/boxscore/{game_uuid}

Valid URL: https://www.basketligaen.dk/api/gameday/boxscore/c4hh5nig6t

API ParameterPythonPatternRequiredNullableDescription
game_uuidgame_uuidYGame uuid: gameInfo[].uuid of the schedule (10 lowercase letters and digits). Key space: platform game uuids; the Genius match id is extId / gameSourceId in the body.

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
team_sideStringhome or away: the side the row belongs to.
row_typeStringKind of row: player, team_coach (the bench row: team rebounds, turnovers and fouls charged to the team or coach) or team_totals.
player_idInt64Genius person id (Int64). A string key in the players maps, an integer in play-by-play and box-score rows; cast here so the frames join, and join the genius family.
team_idInt64Genius team id (Int64): in gameday bodies, an integer in standings and stats tables.
team_nameStringName of the team.
periodInt64Period of the line: 0 = the whole game (the only value seen).
full_nameStringFull display name of the player.
first_nameStringGiven (first) name(s) of the player.
last_nameStringFamily name (surname) of the player.
nrInt64Jersey number (null on the bench and totals rows).
posStringPosition code of the line (G, F, C; null on the bench and totals rows).
minsStringMinutes played as 'MM:SS' (null on the bench and totals rows).
ptsInt64Number of points scored.
fgStringField goals as 'made-attempted'.
fg_percFloat64Field-goal percentage, 0-100.
2_pStringTwo-pointers as 'made-attempted'.
2_p_percFloat64Two-point percentage, 0-100.
3_pStringThree-pointers as 'made-attempted'.
3_p_percFloat64Three-point percentage, 0-100.

offInt64Offensive rebounds.

rebInt64Total rebounds.
astInt64Number of assists credited.

stlInt64Number of steals.
blkInt64Number of blocked shots made.
blkrInt64Blocks received (shots of the player that were blocked).
pfInt64Personal fouls.

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. The site answered 404, an empty body (gameday routes before 2023/24, or an unknown game), a table with no rows, or the season and game type are not in layout-info.
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. An error envelope or non-JSON 200, another game / team / athlete / ssgt than the one asked for, an unfinished game or truncated play-by-play, a cut stats table, or any other failed fetch (a 500 is the site's answer for an unknown uuid and is not retried).
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. The site answered 404, an empty body (gameday routes before 2023/24, or an unknown game), a table with no rows, or the season and game type are not in layout-info.
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. An error envelope or non-JSON 200, another game / team / athlete / ssgt than the one asked for, an unfinished game or truncated play-by-play, a cut stats table, or any other failed fetch (a 500 is the site's answer for an unknown uuid and is not retried).
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.
