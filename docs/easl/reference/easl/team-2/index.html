easl_team_stats​

A team's cumulative season statistics: totals, per-game rates and the opponent's totals (*_against).

Endpoint URL: GET https://easl.joshricha.com/api/v1/teams/{team_id}/stats

Valid URL: https://easl.joshricha.com/api/v1/teams/865489e8-b0f5-11ed-8b3f-c199a9dea184/stats?season=2026

API ParameterPythonPatternRequiredNullableDescription
team_idteam_idYDataCore team (entity) UUID v1, e.g. '865489e8-b0f5-11ed-8b3f-c199a9dea184' (Utsunomiya Brex): the team_id of easl_teams, easl_standings and the box scores. easl_team resolves the 12 historical teams easl_teams does not list.
seasonseasonYSeason END year (2026 = EASL 25-26; the four editions are 2024 to 2027). easl_runtime reads easl_seasons and maps it to the DataCore seasonId. Default: the ACTIVE season.

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. The server has nothing for the request (an empty list or leaders object, a team or player without games, a 404).
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. The fetch failed or the answer is unknown or partial: any non-2xx (an unknown fixture is the server's HTTP 500), an error envelope, a game that is not finished or whose box score or play-by-play is incomplete, a stalled sync on the active season, or a body for another game, season, team or player than the one asked for.
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help. A malformed id or a season that is not one of the server's END years (raised before the request that would use it).

categoryStringLeader category, the wire key of the group: pointsPerGame, reboundsPerGame, assistsPerGame, stealsPerGame, blocksPerGame, pointsThreeMade, pointsThreePercentage, fieldGoalsPercentage or freeThrowsPercentage.
rankInt64Rank inside the category, 1 = best, in the delivered order (the server lists the top 5).
valueFloat64The leader's value in the category: a per-game average, a count (pointsThreeMade) or a percentage (0-100). Float64.
player_idStringplayerId: DataCore person UUID v1 (key space: EASL persons, the same id as the box score's personId; joins /players, leaders and play-by-play players). Not a team id.
player_nameStringPlayer display name in 'FAMILY Given' form with the family name upper-cased (OSAKABE Taiki), in Latin script.
player_name_latinStringAlternative name: equal to nameFullLocal for 257 of 552 players, otherwise null; never non-Latin in the observed data.
jersey_numberStringJersey number as a string ('00', '0' and '75' are distinct).
positionStringPlaying position: G, F, C, PG, SG, SF, PF or GF (guard-forward).
player_statusStringRegistration state of the player in the database: ACTIVE, INACTIVE or UNREGISTERED.
team_idStringteamId: DataCore team (entity) UUID v1 (key space: EASL teams, the same id as entityId; joins /teams, /standings team.id, fixture competitors, box and play-by-play teams). Not a player id.
team_nameStringDisplay name. Despite the field name this is the English / Latin-script name used on the league site.
team_name_nativeStringAlternative name: the native-script name of some Japanese clubs (for example 宇都宮ブレックス for Utsunomiya Brex), blank for most clubs; for players it usually equals nameFullLocal. Despite the field name it is not always Latin script.
team_code_latinStringThree-letter club code (for example BRE); null or empty for some clubs.
team_code_localStringNot yet populated upstream: null in every full body observed (2026-10-12), so its meaning is unverified; the 2026-27 bodies start filling some of these columns, so it is typed from its family (String).

return_parsed=False — the raw JSON Dict payload, unparsed.

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. The server has nothing for the request (an empty list or leaders object, a team or player without games, a 404).
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. The fetch failed or the answer is unknown or partial: any non-2xx (an unknown fixture is the server's HTTP 500), an error envelope, a game that is not finished or whose box score or play-by-play is incomplete, a stalled sync on the active season, or a body for another game, season, team or player than the one asked for.
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help. A malformed id or a season that is not one of the server's END years (raised before the request that would use it).

easl_team_leaders(season=2026, team_id='865489e8-b0f5-11ed-8b3f-c199a9dea184')
