nba_referee_assignments​

nba_referee_assignments(date: 'str | _dt.date', *, league: 'str' = 'nba', raw: 'bool' = False, return_as_pandas: 'bool' = False, proxy: 'dict | None' = None) -> 'dict[str, Any]'

Fetch and parse NBA referee assignments for a given date from official.nba.com.

Retrieves one league's referee crew assignments and replay-center officials for a date: NBA, G-League or WNBA, picked by league (raw=True returns all three leagues' blocks). The crew_position column (1–4) represents the feed's slot order; slot 1 is inferred to be the crew chief. The season column converts from the feed's format to an END year: START+1 for NBA/G-League (two-calendar-year seasons) and START unchanged for WNBA.

Parameters

ParameterTypeDefaultDescription
datestr | dateThe date to fetch assignments for (str in "YYYY-MM-DD" format or datetime.date).
leaguestr'nba'The league to extract ("nba", "gl", or "wnba"). Defaults to "nba".
rawboolFalseIf True, return the raw JSON payload (dict) with all three leagues instead of parsed DataFrames.
return_as_pandasboolFalseIf True, return pandas DataFrames instead of polars.
proxydict | NoneNoneOptional proxy dict passed through to the HTTP layer.

Returns

If raw=True, the raw JSON dict with keys "nba", "gl", "wnba". Otherwise, a dict with keys "officials" and "replay_center" mapping to DataFrames as documented in parse_nba_referee_assignments.

col_nametypedescription
officials.leagueStringLeague the assignment belongs to: nba, gl (G League), or wnba.
officials.game_idString10-digit game id (zero-padded) for the assigned game.
officials.game_dateDateGame date parsed from the feed's MM/DD/YYYY format.
officials.seasonInt64Season end year, converted from the feed's code: start year + 1 for NBA/G League's two-calendar-year seasons, start year unchanged for WNBA's single-year seasons.
officials.season_typeStringSeason type decoded from the feed's season code first digit: preseason, regular, all-star, playoffs, play-in, or nba-cup-final.
officials.game_codeStringLeague game code in YYYYMMDD/AWYHOM format, matching the away and home team abbreviations.
officials.home_team_idInt6410-digit team id of the home team.
officials.home_team_abbrStringThree-letter abbreviation of the home team.
officials.away_team_idInt6410-digit team id of the away team.
officials.away_team_abbrStringThree-letter abbreviation of the away team.
officials.crew_positionInt64Feed's official slot order (1-4); slot 1 is inferred to be the crew chief since the API does not label roles.
officials.official_idInt64Numeric official id from the feed (source field official{n}_code); expected to match stats.nba.com's OFFICIAL_ID.
officials.official_nameStringOfficial's display name for this crew slot.
officials.jersey_numStringOfficial's jersey number as a string, from the feed's official{n}_JNum field.
replay_center.leagueStringLeague the replay-center staffing belongs to: nba, gl, or wnba.
replay_center.game_dateDateDate the replay-center official worked; a date-level staffing record, not tied to one game.

replay_center.official_nameStringReplay-center official's display name for that date.

Raises

ExceptionDescription
ValueErrorIf league is not "nba", "gl", or "wnba", or date is not a valid "YYYY-MM-DD" date (checked before any request).
NoDataErrorOfficial.nba.com answered 404, or 403 with S3's AccessDenied body. A date without games is not this: it comes back as a 200 with empty rows (see the Note).
AssetFetchErrorThe fetch failed (network error, rate limit, or Akamai WAF block), the 200 body is not a JSON object, or the league's Table/Table1 rows are missing or malformed (a Table row without a 10-digit game_id, or a Table1 row without a replaycenter_official name, included). With raw=True all three leagues are checked, since the whole payload is returned.

Example

from sportsdataverse.nba.nba_officiating import nba_referee_assignments
result = nba_referee_assignments("2026-06-13")
officials = result["officials"]
print(f"Found {officials.height} official slots")

# Fetch WNBA assignments for the same date

result = nba_referee_assignments("2026-06-13", league="wnba")
wnba_officials = result["officials"]

nba_season_sim​

nba_season_sim(season: 'int', *, as_of_date: 'dt.date | None' = None, league_id: 'str' = '00', n_sims: 'int' = 10000, seed: 'int' = 20261103, chances: 'list[float] | None' = None, cup_schedule: 'pl.DataFrame | None' = None, return_as_pandas: 'bool' = False) -> 'pl.DataFrame | pd.DataFrame'

Season sim as of a date: projected W-L, division, seed, play-in, playoff and lottery odds.

Reads the {nba,wnba}_stats_schedules and _possessions releases for the season and the one before, fits the game model on the regular-season games played before as_of_date, shrunk toward last season's final ratings (as_of_game_model, preseason_prior), and simulates the rest (simulate_pro_season). Before the first game the ratings are the prior alone. The rules applied to each simulated season are in sportsdataverse.nba.nba_season_rules.

Parameters

ParameterTypeDefaultDescription
seasonintThe season, named by the year it ends (2027 is 2026-27); the WNBA season is its calendar year.
as_of_datedate | NoneNoneGames on or after this date are simulated even when the release has their score (a backtest). None: every game with a score counts as played.
league_idstr'00'"00" NBA or "10" WNBA.
n_simsint10000Simulated seasons (Monte Carlo error: see SIM_SCHEMA's _se columns).
seedint20261103Seeds the generator; the same release data and seed give the same output.
chanceslist[float] | NoneNoneLottery chances per slot, worst record first, one per lottery team; overrides the published table (needed for the 2027 WNBA lottery's seven teams, not published yet).
cup_scheduleDataFrame | NoneNoneNBA: stats.nba.com's schedule for the season (~sportsdataverse.nba.nba_stats.nba_stats_scheduleleaguev2), which marks the Cup games. Read only while the release lists TBD Cup games; None fetches it then (a residential connection), and a failed fetch falls back to league-average opponents for the Cup slots with a warning.
return_as_pandasboolFalseReturn a pandas frame instead of polars.

Returns

One row per team (stats.nba.com team_id, Int64), sorted by conference and mean seed: * wins / losses so far, games_remaining, and the as-of adj_net_rtg with its posterior sd adj_net_rtg_sd (capped so two teams' shift carries at most 3/4 of a game's variance; it binds only near the prior, before many games are played). * proj_wins / proj_losses (means), proj_wins_sd, the 10th and 90th percentiles, and proj_wins_se (the Monte Carlo error of the mean). * p_division (NBA), p_seed_1 .. p_seed_15 (the regular-season finish in the conference, NBA, or the league, WNBA) and mean_seed. * p_top4 (first-round home court), p_top6 (NBA, straight to the playoffs), p_play_in (NBA, seeds 7-10), p_playoffs (NBA: top 6 or through the play-in; WNBA: top 8) and its Monte Carlo p_playoffs_se. * p_lottery, p_pick_1, p_drawn_pick (a pick from the drawing: the NBA's top four, the WNBA's top two) and mean_pick (given a lottery finish). The pick columns are null when the league has no published chances for that many lottery teams. * n_sims.

nba_season_standings(games: 'pl.DataFrame', *, league_id: 'str' = '00', seed: 'int' = 0, return_as_pandas: 'bool' = False) -> 'pl.DataFrame | pd.DataFrame'

Standings with the league's tiebreakers from completed regular-season games.

NBA: conference seeds and division ranks under the NBA tie-break procedure (division leaders first, postseason-eligible = a top-10 conference record). WNBA: one league table under the WNBA procedure. The rules and their sources are in sportsdataverse.nba.nba_season_rules.

Parameters

ParameterTypeDefaultDescription
gamesDataFrameOne row per game with season, home_team_id, away_team_id (Int64 stats.nba.com ids), home_pts and away_pts; rows without both scores are not played yet and are skipped. A load_nba_stats_schedules frame can be passed as is: with a season_type column only the "regular-season" rows count (the NBA Cup final, preseason, play-in and playoffs do not).
league_idstr'00'"00" NBA or "10" WNBA.
seedint0Seeds the drawing that ends a tie no criterion breaks.
return_as_pandasboolFalseReturn a pandas frame instead of polars.

Returns

One row per (season, team_id) that played: conference / division (NBA; the WNBA rows say "WNBA"), games, wins, losses, win_pct, point_diff, division_rank (1 = the division winner), division_leader, seed (rank in the conference for the NBA, in the league for the WNBA, 1 = best) and games_back (behind the seed-1 team). Sorted by season, conference and seed.

col_nametypedescription
seasonInt64Season, named by the year it ends (2026 is 2025-26); the WNBA season is its calendar year.
team_idInt64stats.nba.com team id (Int64).
conferenceStringNBA conference (East / West); "WNBA" for every WNBA team.
divisionStringNBA division; "WNBA" for every WNBA team.
gamesInt64Regular-season games played.
winsInt64Regular-season wins.
lossesInt64Regular-season losses.
win_pctFloat64Regular-season winning percentage, wins divided by games played; the first key of the seeding.
point_diffInt64Points scored minus points allowed over the regular-season games.
division_rankInt64Rank within the division under the NBA tiebreakers, 1 = the division winner (the WNBA rows rank the league).
division_leaderBooleanTrue for the NBA division winner after the division tiebreak; False for every WNBA row.
seedInt64Seed under the league's tiebreakers: rank in the conference (NBA) or the league (WNBA), 1 = best.
games_backFloat64Games behind the seed-1 team of the conference (NBA) or league (WNBA): ((leader wins - wins) + (losses - leader losses)) / 2.

Raises

ExceptionDescription
ValueErrorIf league_id is not "00" or "10", or an NBA team id is unknown.
TypeErrorIf the team-id columns are not Int64.

Example

One-call shot-value spine: fetch, score, and run all five models.

Fetches each player's shotchartdetail, scores per-shot expected points (score_shot_xpoints: the location model for the NBA, the LeagueAverages zone table elsewhere), and returns the scored shots plus shooter talent, selection quality, and zone-value maps (and the defender/shot-clock context tables when include_context=True).

return_as_pandasboolFalseReturn pandas frames instead of polars.

Returns

{"shots", "talent", "selection", "zones"} (plus "context" when requested). An empty fetch returns a dict of zero-row frames.

Example

from sportsdataverse.nba import nba_shot_value
out = nba_shot_value([201939], "2022-23")

One row per (season, team_id, game_id, split): a game has an all row, a home or away row (neither at a neutral site) and, when it has clutch possessions, close and clutch rows. team_id is the stats.nba.com team id (Int64), game_id the stats.nba.com game id. poss / opp_poss are the team's offensive / defensive possessions, pts / opp_pts their points and seconds the game clock they used. season_type is the game's schedule type, so a list's rows of one type add up to that type's nba_team_season_rates row. nba_team_luck​

nba_team_luck(seasons: 'int | list[int]', *, league_id: 'str' = '00', season_type: 'str' = 'regular-season', return_as_pandas: 'bool' = False) -> 'pl.DataFrame | pd.DataFrame'

Luck and close-game record: Pythagorean expected wins vs actual wins, and close-game W-L.

One row per team and season. exp_wins is the Pythagorean expectation on the season's final scores, games * pts^x / (pts^x + opp_pts^x), with the exponent x fitted per league on past seasons (~sportsdataverse._common.team_luck.PYTHAG_EXPONENT). luck_wins is wins - exp_wins. A close game is one within 5 points at the start of a possession in play in the last 5:00 of the 4th quarter or in overtime: one that starts there, or starts before 5:00 and ends after it (stats.nba.com's clutch window; BB-D3's close split). For the WNBA (league_id="10") through 2005, two 20-minute halves, the regulation window is the last 5:00 of the 2nd half; overtime counts as above.

Parameters

ParameterTypeDefaultDescription
seasonsint | list[int]A season or list of seasons, named by the year it ends (2026 is 2025-26). The WNBA season is its calendar year.
league_idstr'00'"00" NBA or "10" WNBA.
season_typestr'regular-season'"regular-season" (default), "preseason", "playoffs" or "play-in", matched to the schedule's season_type. The exponent was fitted on regular seasons; on a handful of playoff or play-in games exp_wins is only indicative.
return_as_pandasboolFalseReturn a pandas frame instead of polars.

Returns

One row per (season, team_id); team_id is the stats.nba.com team id (Int64). games, wins, losses, pts and opp_pts are from the final scores; win_pct, pythag_win_pct, exp_wins and luck_wins (wins - exp_wins) follow. pbp_games counts the games with published possessions, and close_games, close_wins, close_losses and close_win_pct (null with no close game) are the close games among them. pythag_win_pct, luck_wins and close_win_pct have <m>_rank (1 = highest), <m>_pct (the Weibull percentile) and <m>_n (games, or close games); ranks are within the season, among teams with at least half the most games (close_win_pct also needs possessions for half of them and five close games), and null under five teams. Empty input returns that schema with zero rows.
