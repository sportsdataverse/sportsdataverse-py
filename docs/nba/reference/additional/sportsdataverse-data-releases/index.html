load_nba_stats_draft_combine_anthro​

load_nba_stats_draft_combine_anthro(seasons: 'int | Iterable[int]', return_as_pandas: 'bool' = False) -> 'pl.DataFrame | pd.DataFrame'

Load draft-combine anthropometric measurements (draftcombineplayeranthro).

One row per combine participant: height with and without shoes, weight, wingspan, standing reach, body fat and hand size.

Parameters

ParameterTypeDefaultDescription
seasonsint | Iterable[int]Draft year(s) of the combine, e.g. 2024 for the May 2024 combine ahead of the 2024 draft (the 2024-25 season's START year; the asset is keyed by the END year and the loader translates). 2000 is the earliest combine on the tag.
return_as_pandasboolFalseIf True, returns a pandas dataframe. If False, returns a polars dataframe.

Returns

One row per participant; season is the asset's END year. An empty frame when no requested season is published.

col_nametypedescription
temp_player_idintegerCombine participant id; equals player_id in every row checked.
player_idintegerstats.nba.com player identifier (PERSON_ID); Int64.
first_namecharacterParticipant's first name.
last_namecharacterParticipant's last name.
player_namecharacterParticipant's full name.
positioncharacterPosition listed by the combine (e.g. 'PG', 'SF-PF').
height_wo_shoesdoubleHeight without shoes, in inches.
height_wo_shoes_ft_incharacterHeight without shoes as feet-and-inches text (e.g. "6' 5.75''").
height_w_shoescharacterHeight in shoes, in inches; null in recent combines, which stopped measuring it.
height_w_shoes_ft_incharacterHeight in shoes as feet-and-inches text; null when not measured.
weightcharacterWeight in pounds, as text (e.g. '227.80').
wingspandoubleWingspan, in inches.
wingspan_ft_incharacterWingspan as feet-and-inches text.
standing_reachdoubleStanding reach, in inches.
standing_reach_ft_incharacterStanding reach as feet-and-inches text.
body_fat_pctcharacterBody-fat percentage; null in combines that did not publish it.
hand_lengthdoubleHand length, in inches.
hand_widthdoubleHand width (span), in inches.
seasonintegerEND year of the season the draft class enters (2025 = the May 2024 combine for the 2024 draft) -- one more than the seasons argument.

Raises

ExceptionDescription
SeasonNotFoundErrorIf any requested season is below 2000.
AssetFetchErrorIf a release asset request fails.

Example

from sportsdataverse.nba import load_nba_stats_draft_combine_anthro
anthro = load_nba_stats_draft_combine_anthro(2024)
print(anthro.shape)

# Pipeline next step (largest hands)

anthro.sort("hand_length", descending=True).head()
