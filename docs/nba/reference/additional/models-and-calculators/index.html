AdjRapmModel​

AdjRapmModel(prior: 'Dict[int, Tuple[float, float]]', alphas: 'np.ndarray' = <factory>, n_samples: 'int' = 200, seed: 'int' = 0) -> None

Prior-informed RAPM: ridge toward a per-player box prior with an RTO posterior.

Implements the ~sportsdataverse.nba.nba_model_validation.PriorModel protocol so the validation harness routes through fit_with_prior and the resulting ~sportsdataverse.nba.nba_model_validation.FitResult carries a posterior — enabling Oracle ④ (interval calibration).

Parameters

ParameterTypeDefaultDescription
priorDict[int, Tuple[float, float]]Per-player {player_id: (o_prior, d_prior)} in per-100 units.
alphasndarray<factory>RidgeCV alpha grid forwarded to _fit_prior_ridge.
n_samplesint200Number of RTO posterior samples.
seedint0RNG seed for the RTO sampler.

Example

from sportsdataverse.nba import AdjRapmModel, nba_spm
from sportsdataverse.nba.nba_model_validation import validate_model
prior = AdjRapmModel.from_spm(nba_spm(box_feats, coef))
report = validate_model(prior, season_frames, model_name="adj_rapm")
print(report.calibration.coverage)      # non-None: the prior model has a posterior

CurrentImpactFilter​

CurrentImpactFilter(params: 'CurrentImpactParams | None' = None) -> 'None'

The joint Kalman filter of nba_current_impact, fed one season and one game at a time.

State, per possession and in the RAPM design's sign: each player's offense deviation, defense deviation (negative = good defense) and the league level. Within a season the covariance is joint over the season's players; across seasons each player's mean and variance carry (the cross terms do not: ponytail, carry the block if a gate ever wants it).

CurrentImpactFilter.ratings​

CurrentImpactFilter.ratings() -> 'dict[int, Rating]'

Every seen player's (o, d, o_prior, d_prior, off_poss, def_poss, last_game, w_o, w_d, w).

Ratings and priors per 100 (d positive = good defense): the prior in force plus the deviation. A player carried from an earlier season who is not in this one's matrix gets his carried deviation plus the prior in force for him (0 when he has none). Possessions count this season's games. w_o / w_d / w are the prior weights of the offense, defense and net rating (module docstring): posterior variance over the no-update variance, clipped to [0, 1] against rounding.

Scores a fold via faithful BPM 2.0; position/role are estimated fold-native (recomputed over the fold's games) in v1 — a full-season-position refinement is a documented follow-up. fit_ratings restricts the box rate + team margin to the fold's games (the leakage guard).

adjust_efficiency​

adjust_efficiency(game_eff: 'pl.DataFrame', *, league_id: 'str' = '00', max_iter: 'int' = 100, tol: 'float' = 0.0001) -> 'pl.DataFrame'

Iterative opponent-adjusted rating -> AdjOffRtg / AdjDefRtg / AdjNet per team-season.

KenPom-style fixed point: initialize adj_off = raw_off / adj_def = raw_def, then repeatedly recompute each team's rating from its games with the opponent's current adjusted rating and a home-court adjustment removed, until the largest change is below tol. Ratings are computed independently per season.

The per-game offensive update is off_rtg - (adj_def_opp - avg) - loc_o where loc_o is +hfa/2 at home, -hfa/2 away, 0 neutral (defense is symmetric with the opposite sign); avg is the league baseline off rating and hfa comes from ~sportsdataverse.nba.nba_prediction_constants.get_constants.

(T7.2-shared algorithm) -- identical fixed point to the MBB mbb_team_ratings.adjust_efficiency / CFB ratings cores.

Parameters

ParameterTypeDefaultDescription
game_effDataFrameOutput of raw_game_efficiency.
league_idstr'00'"00" NBA / "10" WNBA / "20" G-League -- selects the HFA + baseline off-rating constants.
max_iterint100Maximum fixed-point iterations.
tolfloat0.0001Convergence tolerance on the largest rating change.

Returns

One row per (season, team_id): season, team_id, adj_off_rtg, adj_def_rtg, adj_net_rtg, raw_off_rtg, raw_def_rtg, games. Empty input returns that schema with zero rows.

fit_reml_prior_ridge​

Ridge toward prior_mean with one penalty for offense and one for defense, chosen by REML.

The model is y = c + X b + e, e ~ N(0, s2), with each offensive coefficient b_j ~ N(prior_j, s2 / lambda_o) and each defensive one ~ N(prior_j, s2 / lambda_d), and a flat prior on the intercept c. The restricted (REML) likelihood integrates b and c out; with s2 profiled, -2 times it is, up to a constant,

.. code-block:: text

(n - 1) log RSS + log |M| - P log lambda_o - P log lambda_d,
M = Xc'Xc + diag(lambda),  RSS = min_d |yc' - Xc d|^2 + d' diag(lambda) d,

Xc / yc' the centred design and prior-residualized response. Its gradient in log lambda_o is lambda_o ((n - 1) |d_o|^2 / RSS + tr_o(M^-1)) - P (and likewise for defense), so a bounded quasi-Newton search finds the pair in a few dozen 2P x 2P Cholesky factorizations.

game_lines​

game_lines(lines_checkpoints: 'pl.DataFrame', crosswalk: 'pl.DataFrame', schedule: 'pl.DataFrame', *, league: 'str | None' = None) -> 'pl.DataFrame'

Per ESPN game: opening and closing spread, total and moneylines, the no-vig market WP, and the result.

Parameters

ParameterTypeDefaultDescription
lines_checkpointsDataFrameThe odds store's lines_checkpoints rows (any sports and years: rows of other sports are ignored). Needs event_id, sport_key, home_team, away_team, bookmaker_key, market_key, outcome_name, open_price / open_point, close_price / close_point and close_mins_before.
crosswalkDataFrameThe odds store's espn_crosswalk (sport_key, event_id, espn_game_id, match_method).

leaguestr | NoneNone"nba", "wnba", "mbb" or "wbb" (default NBA).

Returns

game_minutes​

game_minutes(periods: 'int', *, league_id: 'Optional[str]' = None, league: 'Optional[str]' = None, regulation_periods: 'Optional[int]' = None) -> 'int'

Minutes played in a game of periods periods: the league's regulation length plus five per overtime.

Regulation is 48 minutes in the NBA and 40 in the WNBA and both college leagues (two 20-minute halves or four 10-minute quarters); every overtime is 5 minutes. A period past the game's regulation_periods is an overtime, so period 3 of a halves game is the first overtime.

Parameters

ParameterTypeDefaultDescription
periodsintHighest period number played.
league_idOptional[str]NoneLegacy alias: "00" NBA / "10" WNBA.
leagueOptional[str]None"nba", "wnba", "mbb" or "wbb" (default NBA).
regulation_periodsOptional[int]NoneThe game's regulation periods (2 or 4); default game_regulation_periods for the league without a season (MBB 2, otherwise 4).

Returns

Game minutes.

Raises

ExceptionDescription
TypeErrorIf periods is None or another non-numeric type.
ValueErrorIf periods is a string that is not an integer, the league is unknown, or league contradicts league_id.

Example

from sportsdataverse.nba.nba_game_page import game_minutes
game_minutes(5)  # 53

# A double-overtime men's college game (two halves + two OTs)

game_minutes(4, league="mbb")  # 50

game_page_frames​

game_page_frames(final: 'dict', *, league_id: 'Optional[str]' = None, league: 'Optional[str]' = None, rated_home_prob: 'Optional[float]' = None, shot_cells: 'Optional[pl.DataFrame]' = None) -> 'dict[str, object]'

Everything the Game on Paper basketball game page needs, from one espn_<league>_pbp payload.

Reads the game's regulation (format.regulation.periods, else the season cutoff of game_regulation_periods) and neutral site (header.competitions[0].neutralSite), runs the league's hoopR / wehoop converters (helper_<league>_play_by_play / helper_<league>_team_box / helper_<league>_player_box) and then game_page_tables. The sdv-db nightly stage calls game_page_tables directly on the warehouse's copies of the same frames.

Parameters

ParameterTypeDefaultDescription
finaldictThe dict espn_<league>_pbp(..., return_parsed=False) returns (for example ~sportsdataverse.nba.nba_pbp.espn_nba_pbp).
league_idOptional[str]NoneLegacy alias: "00" NBA / "10" WNBA.
leagueOptional[str]None"nba", "wnba", "mbb" or "wbb" (default NBA).
rated_home_probOptional[float]NoneThe game's rated pregame home win probability, the prior when there is no line (NBA / WNBA: ~sportsdataverse.nba.nba_rated_prior.nba_rated_priors).
shot_cellsOptional[DataFrame]NoneThe league's shot counts as of the game date (~sportsdataverse.nba.nba_game_expected.shot_cells), for the expected points of team_game_expected; None leaves its expected columns null.

Returns

{"pbp", "team_box", "team_game_rates", "player_box", "player_game_rates", "team_game_splits", "player_game_splits", "team_game_expected", "periods", "prior", "league", "regulation_periods", "period_kind", "neutral_site"}; see game_page_tables for the shared keys. Missing boxes retain empty identifier columns. Team rates need both team rows, and player rates also need player rows. Unavailable rates are empty frames with their documented columns.
