game_page_tables​

game_page_tables(pbp: 'pl.DataFrame', team_box: 'pl.DataFrame', player_box: 'pl.DataFrame', *, league_id: 'Optional[str]' = None, league: 'Optional[str]' = None, regulation_periods: 'Optional[int]' = None, neutral_site: 'Optional[bool]' = False, rated_home_prob: 'Optional[float]' = None, shot_cells: 'Optional[pl.DataFrame]' = None) -> 'dict[str, object]'

Every game-page table for one game, from its basketball pbp / team box / player box frames.

The warehouse path: the sdv-db nightly stage reads one game's rows from <league>.pbp / team_box / player_box and its schedule row (season, format_regulation_periods, neutral_site) and calls this. game_page_frames builds the same frames live from ESPN and calls this too, so a game renders identically from either source. Runs score_win_prob, shot_coordinates, team_game_rates, player_game_rates, ~sportsdataverse.nba.nba_game_splits.team_game_splits, ~sportsdataverse.nba.nba_game_splits.player_game_splits and ~sportsdataverse.nba.nba_game_expected.team_game_expected on the game's own regulation.

Parameters

ParameterTypeDefaultDescription
pbpDataFrameOne game's plays in the basketball pbp schema, in play order (empty before tip-off).
team_boxDataFrameThe game's team box rows (rates need exactly two).
player_boxDataFrameThe game's player box rows.
league_idOptional[str]NoneLegacy alias: "00" NBA / "10" WNBA.
leagueOptional[str]None"nba", "wnba", "mbb" or "wbb" (default NBA).
regulation_periodsOptional[int]NoneThe game's regulation periods; default game_regulation_periods from the frame's season. Pass the schedule's format_regulation_periods through game_regulation_periods when you have it.
neutral_siteOptional[bool]FalseWhether the game was at a neutral site (no home-court advantage in a lineless prior); None, NaN or pd.NA counts as false.
rated_home_probOptional[float]NoneThe game's rated pregame home win probability, the prior when there is no line (NBA / WNBA: ~sportsdataverse.nba.nba_rated_prior.nba_rated_priors).
shot_cellsOptional[DataFrame]NoneThe league's shot counts as of the game date (~sportsdataverse.nba.nba_game_expected.shot_cells), for the expected points of team_game_expected; None leaves its expected columns null.

Returns

{"pbp", "team_game_rates", "player_game_rates", "team_game_splits", "player_game_splits", "team_game_expected", "periods", "regulation_periods", "period_kind", "prior"}: the scored plays with shot coordinates, the two rate frames (empty with their documented columns without two team rows), the two split frames (counted from the plays so far; the team frame is empty before tip-off, the player frame then holds the boxed players with zero counts), the expected points by zone and situation (empty before tip-off), the highest period played (the regulation count before tip-off), the regulation periods, "half" or "quarter", and {"home_win_prob", "source", "home_team_spread", "game_spread_available"}.

Raises

ExceptionDescription
ValueErrorIf the league is unknown, league contradicts league_id, or pbp holds more than one game.
polars.exceptions.ColumnNotFoundErrorIf a frame lacks a column the derivations need.

Example

import polars as pl
from sportsdataverse.nba.nba_game_page import game_page_tables, game_regulation_periods
from sportsdataverse.wbb.wbb_loaders import load_wbb_pbp, load_wbb_player_boxscore, load_wbb_team_boxscore
gid = 293170052
pbp = load_wbb_pbp([2010]).filter(pl.col("game_id") == gid)
tb = load_wbb_team_boxscore([2010]).filter(pl.col("game_id") == gid)
pb = load_wbb_player_boxscore([2010]).filter(pl.col("game_id") == gid)
tables = game_page_tables(pbp, tb, pb, league="wbb", regulation_periods=game_regulation_periods("wbb", season=2010))

# The win-probability chart

tables["pbp"].select("game_play_number", "home_win_prob", "wp_delta", "wp_regime")

game_regulation_periods​

game_regulation_periods(league: 'str', *, season: 'int | None' = None, format_regulation_periods: 'float | None' = None) -> 'int'

Regulation periods of one game: 2 (halves) or 4 (quarters).

The game's own value wins: ESPN's summary format.regulation.periods on the live path, the schedule's format_regulation_periods in the warehouse. Without it (null, NaN, or anything other than 2 or 4) the season decides: the NBA always plays quarters, men's college basketball always halves, the WNBA halves before 2006 and women's college basketball halves before the 2015-16 season (season 2016, ESPN's end year). With neither, WNBA and WBB default to quarters.

Parameters

ParameterTypeDefaultDescription
leaguestr"nba", "wnba", "mbb" or "wbb"; None means NBA.
seasonint | NoneNoneESPN season.year of the game (the end year for college); null or NaN counts as unknown.
format_regulation_periodsfloat | NoneNoneThe game's own regulation period count, if known.

Returns

2 or 4.

Raises

ExceptionDescription
ValueErrorIf league is a string other than the four.

Example

from sportsdataverse.nba.nba_game_page import game_regulation_periods
game_regulation_periods("wbb", season=2015)  # 2: halves before 2015-16
game_regulation_periods("wnba", season=2024, format_regulation_periods=4.0)  # 4

# A warehouse schedule row

game_regulation_periods("mbb", season=2024, format_regulation_periods=2.0)  # 2

home_prior​

home_prior(home_team_spread: 'Optional[float]', game_spread_available: 'Optional[bool]', *, league_id: 'Optional[str]' = None, league: 'Optional[str]' = None, neutral_site: 'Optional[bool]' = False, rated_home_prob: 'Optional[float]' = None) -> 'tuple[float, str]'

Pregame home win probability for the in-game model, and where it came from.

home_team_spread is the signed expected home margin the basketball pbp frames carry (positive when the home side is favoured). With no line, every basketball pickcenter helper leaves it None (older releases carry an invented +2.5), so the value is only trusted when game_spread_available is true. A line already prices the venue. Without one the prior is rated_home_prob when given (the NBA / WNBA as-of team-ratings prior, ~sportsdataverse.nba.nba_rated_prior.nba_rated_priors, which prices the venue itself), else home-court advantage alone, and at a neutral site (common in college tournaments) there is none: the prior is 0.5. NBA and WNBA use ~sportsdataverse.nba.nba_game_predict.win_prob_from_margin and their fitted hfa; MBB and WBB use ~sportsdataverse.mbb.mbb_game_predict.win_prob_from_margin with league="mens" / "womens".

Parameters

ParameterTypeDefaultDescription
home_team_spreadOptional[float]Signed expected home margin, or None.
game_spread_availableOptional[bool]Whether a real line backed that spread.
league_idOptional[str]NoneLegacy alias: "00" NBA / "10" WNBA.
leagueOptional[str]None"nba", "wnba", "mbb" or "wbb" (default NBA).
neutral_siteOptional[bool]FalseESPN neutralSite / the schedule's neutral_site; None, NaN or pd.NA counts as false.
rated_home_probOptional[float]NoneThe game's rated pregame home win probability, used when there is no line; None, NaN or a value outside [0, 1] falls through to home-court advantage.

Returns

(probability, source) with source "spread", "rated", "neutral" or "hfa".

Raises

ExceptionDescription
ValueErrorIf the league is unknown or league contradicts league_id.

Example

from sportsdataverse.nba.nba_game_page import home_prior
home_prior(3.0, True)      # (0.58, 'spread')
home_prior(2.5, False)     # (0.56, 'hfa')  the default line is ignored
home_prior(None, False, rated_home_prob=0.71)  # (0.71, 'rated')

# A lineless college tournament game

home_prior(None, None, league="mbb", neutral_site=True)  # (0.5, 'neutral')

The ESPN fetch and parse pair for one league: (espn_<league>_pbp, helper_<league>_pbp).

A live processor fetches once (fetch(game_id, raw=True), the summary with its keys defaulted and nothing parsed), checks the payload has plays, then parses (parse(game_id, summary)) and hands the result to game_page_frames. Splitting the two keeps an upstream failure (fetch) apart from a parsing bug (parse).

(fetch, parse).

Raises

ExceptionDescription

luck_adjusted_response​

luck_adjusted_response(possessions: 'pl.DataFrame', shooting: 'pl.DataFrame', player_rates: 'Optional[dict[int, tuple[float, float]]]' = None, *, fg3_k: 'float' = 100.0, ft_k: 'float' = 50.0) -> 'pl.DataFrame'

Attach a per-possession la_points expected-points response.

DECISION 2/4: la_points = 2*fg2m + 3*Σ_shooter fg3a·p̂3 + Σ_shooter fta·p̂ft (offense-only, "one_way"). 2-pt makes stay realized. p̂ come from player_rates when given, else _shrunk_shooter_rates on shooting.

Defense-shooter exclusion (bugfix): shooting (~sportsdataverse.nba.nba_possessions.build_possession_shooting) deliberately retains defense-team shooters in a possession group — e.g. a defensive technical free throw shooter — because it is a per-shooter companion frame, not a team-attributed one (that's why it carries its own team_id column). The expected-points sum is offense-only by definition (DECISION 2), so before aggregating exp_extra this function joins possessions[["game_id", "possession_number", "offense_team_id"]] onto shooting and filters to team_id == offense_team_id, dropping any defense-team shooter row. Without this filter a defense tech-FT's fta·p̂ft term leaks into the offense's la_points, inflating it (reproduced: 2.9 vs. the offense-only-correct 2.0 for a single offense 2-pt make plus one defense tech FT).

nba_adj_rapm​

nba_adj_rapm(possessions: 'pl.DataFrame', prior: 'Dict[int, Tuple[float, float]]', *, league_id: 'str | None' = None, alpha: 'float | None' = None, alphas: 'np.ndarray | None' = None, prior_scale: 'float | None' = None, n_samples: 'int' = 200, seed: 'int' = 0, return_as_pandas: 'bool' = False) -> 'Union[pl.DataFrame, pd.DataFrame]'

One-shot prior-informed RAPM over a possession frame -> per-player ratings.

Builds the sparse design matrix via ~sportsdataverse.nba.nba_rapm.build_rapm_design, constructs the per-possession prior_mean vector from prior, fits a residualized ridge with an RTO posterior via _fit_prior_ridge, and returns the per-player offensive, defensive, and combined adj-RAPM ratings alongside possession counts.

Sign convention (matches ~sportsdataverse.nba.nba_rapm.nba_rapm): d_adj_rapm is positive for a good defender (lowers opponent points); adj_rapm = o_adj_rapm + d_adj_rapm exactly.

Centring: the ridge fits an unpenalized intercept (the league's points per possession), as ~sportsdataverse.nba.nba_rapm.nba_rapm does, so o_adj_rapm and d_adj_rapm are each relative to an average player: their possession-weighted means sit near 0 (2025-26 NBA +0.32 / +0.06, 2025 WNBA +0.45 / +0.11, against o_rapm's +0.41 / +0.11). Fit without one, as every release fit before #1137 was, the penalty split that level between every offensive and defensive coefficient: o / d read about +12 / -11 (2025-26 NBA +12.03 / -10.84), a thinly-used player kept less of the offset (-8.9 on offense under 200 possessions), and so adj_rapm itself leaned toward heavy-minute players.

Penalty and prior scale: one per league, ADJ_RAPM_PENALTY and ADJ_RAPM_PRIOR_SCALE (fitted by tools/fit_adj_rapm_penalty.py; the constants' comment carries the evidence), as ~sportsdataverse.nba.nba_rapm.nba_rapm takes ~sportsdataverse.nba.nba_rapm.RAPM_PENALTY. Before #1150 each fit took RidgeCV's per-season pick at the unscaled prior, which collapsed the spread in seven published WNBA seasons (2004: sd 0.64 against plain RAPM's 1.47) and held NBA 2025-26 at 0.77 of plain RAPM's.

Parameters

ParameterTypeDefaultDescription
possessionsDataFrameA possession+lineup frame produced by the possession engine (game_id, offense_team_id, points, off_player_1..5, def_player_1..5).
priorDict[int, Tuple[float, float]]Per-player {player_id: (o_prior, d_prior)} in per-100 units. Players absent from prior receive a (0.0, 0.0) default.
league_idstr | NoneNone"00", "10" or "20": the league whose penalty and prior scale are used. None reads it from the game_id prefix (NBA without one).
alphafloat | NoneNoneA penalty instead of the league's (positive; ValueError otherwise).

Returns

Frame with columns player_id (Int64), o_adj_rapm (Float64), d_adj_rapm (Float64), adj_rapm (Float64), off_poss (Int64), def_poss (Int64).

nba_bpm​

nba_bpm(player_logs: 'pl.DataFrame', team_logs: 'pl.DataFrame', positions: 'pl.DataFrame', *, team_adjust: 'bool' = True, granularity: 'str' = 'season', league_ortg: 'float | None' = None, return_as_pandas: 'bool' = False) -> 'pl.DataFrame'

Faithful BPM 2.0 per player, at season or single-game granularity.

Team adjustment (Myers, "About Box Plus/Minus (BPM)", BPM 2.0, Basketball-Reference): a team's %Min-weighted ratings (five slots) sum to its rating, so its minute-weighted mean bpm is its net rating per 100 / 5, and its minute-weighted obpm is (its offensive rating - the league's) / 5, a separate constant. dbpm = bpm - obpm then averages (the league's offensive rating - the team's defensive rating) / 5, positive for a good defense, so league minute-weighted obpm and dbpm each sit near 0 (2025-26 NBA -0.001 / -0.006, 2025 WNBA +0.005 / +0.013). Team ratings are raw per-100 box margins, not the schedule-adjusted ones Basketball-Reference uses. A traded player's minutes count with the first team he appears for in the logs. Before #1148 every player took net - team mean on both bpm and obpm: a team-mean target of the full net rating, five times BPM 2.0's, and all of the adjustment on offense, so dbpm stayed raw (2025-26 regular season, minute-weighted: league obpm -2.94 / dbpm +2.90, 97% of players with dbpm > 0; Michael Porter Jr. -8.97 / +2.26, now +2.22 / -0.95). On 2024-25 the fix lifts agreement with Basketball-Reference's BPM from corr 0.708 / MAE 3.83 to 0.945 / 0.65 (500+ minutes).

Parameters

ParameterTypeDefaultDescription
player_logsDataFrameper-player-per-game box lines (nba_box_logs's player); must carry game_id when granularity="game".
team_logsDataFrameper-team-per-game lines incl. plus_minus (nba_box_logs's team); must carry game_id when granularity="game".
positionsDataFramelisted positions (nba_player_positions): player_id, position_num.
team_adjustboolTrueapply the team adjustment (True) or return raw box-BPM (False).
granularitystr'season'"season" (default) aggregates every row in player_logs/ team_logs into one row per player. "game" runs the exact same pipeline independently per game_id (position/role are estimated game-native, mirroring NbaBpmModel's existing fold-native design) and returns one row per (game_id, player_id) with a leading game_id column; gp is always 1 in this mode.
league_ortgfloat | NoneNoneThe league offensive rating (points per 100) the OBPM adjustment is relative to. None (default) takes it from team_logs: per season_id when that column is there (stats.nba.com's season_id also encodes the season type, so regular season and playoffs stay apart), else over all of team_logs, which must then be one season and season type. Pass it when team_logs is not a whole league, for example one game scored on its own.
return_as_pandasboolFalsereturn pandas instead of polars.

nba_matchup_drapm​

nba_matchup_drapm(season: 'str', *, league_id: 'str' = '00', matchups: 'Optional[pl.DataFrame]' = None, config: 'Optional[PlaytypeConfig]' = None, return_as_pandas: 'bool' = False) -> 'Union[pl.DataFrame, pd.DataFrame]'

Matchup-based defensive RAPM (offense-quality-controlled).

Fits points_allowed_per_100 ~ defender_FE + offense_FE via ~sklearn.linear_model.RidgeCV (weighted by matchup possessions), reusing the shipped RAPM ridge machinery on the build_matchup_drapm_design two-way-FE design.

Sign + scale: the design target y is already points-allowed per 100 matchup possessions (100 * player_pts / partial_poss), so the defender coefficient is already on the per-100 scale -- matchup_drapm = -(beta_defender - mean_beta_defender) (centered, NO extra ×100, unlike ~sportsdataverse.nba.nba_rapm.nba_rapm whose y is per-possession and needs the ×100). Sign is negated so higher = better defense (fewer points allowed), matching the d_rapm convention. Typical magnitudes are a few to low-double-digit points per 100 vs the league defender average.
