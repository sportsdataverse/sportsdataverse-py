TPBL — TPBL API (api.tpbl.basketball, Taiwan) — Other

tpbl_seasons​

Every TPBL season with its TPBL and GoHoops ids, label, status and date window.

Endpoint URL: GET https://api.tpbl.basketball/api/seasons

Valid URL: https://api.tpbl.basketball/api/seasons

API ParameterPythonPatternRequiredNullableDescription

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
seasonInt64Season END year, read from the label '2024-2025 賽季' (賽季 = season): 2025 for 2024-25.
season_idInt64TPBL season id (key space: TPBL seasons on api.tpbl.basketball; 1 = 2024-25, 2 = 2025-26, 3 = 2026-27): the {season_id} of the season game list and, equal to it, the {event_id} of /events/{event_id}/*. Not the GoHoops season id.
gohoops_season_idInt64GoHoops season id (key space: GoHoops seasons, the id system the API echoes beside its own; 101 = 2024-25, 213 = 2025-26, 275 = 2026-27). Not the TPBL season id.
nameStringSeason label in Traditional Chinese: '2024-2025 賽季' = 'season 2024-2025'.
statusStringSeason status: COMPLETED or IN_PROGRESS.
started_atStringSeason start, 'YYYY-MM-DD 00:00:00' text. Preseason games can be played before it (the 2026-27 start is 2026-10-17, its first games were played 2026-10-09).
ended_atStringSeason end, 'YYYY-MM-DD 00:00:00' text (the planned end for a season in progress).

return_parsed=False — the raw body (dict): the API's JSON object, or a list body wrapped as {'data': [...]}, plus _request (the season, game, division, team or player asked for and the ids the runtime resolved).

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. The API has nothing for the request (an unknown id, a season it does not list, an empty list such as the standings of a playoff division).
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. The fetch failed or the answer is not the one asked for (an unfinished game, a box score or list that disagrees with the game it was asked for, an error envelope, a non-JSON body, a server error).
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.

API ParameterPythonPatternRequiredNullableDescription

tpbl_games​

Every game of one season, all divisions, played and scheduled, with teams, venue, status and score.

Endpoint URL: GET https://api.tpbl.basketball/api/seasons/{season}/games

Valid URL: https://api.tpbl.basketball/api/seasons/2026/games

API ParameterPythonPatternRequiredNullableDescription
seasonseasonYRequired. Season END year (2026 = the 2025-26 season; 2025 is the first). The API keys a season by its own small integer (1, 2, 3 = 2024-25, 2025-26, 2026-27; the event id of /events/{id}/* is the same number): tpbl_runtime reads /seasons once and sends that id, so the example URL shows the year. A year the list lacks raises NoDataError.
team_idteam_idYTPBL team id (2-8): keep only that team's games (the API's own filter). Cannot be combined with verify.
verifyverifyYDefault False. Cross-check the list for completeness: every division's completed games must equal the matches of its own standings (one extra request per division; a division whose standings are empty is checked against the team-filtered lists instead). A mismatch raises AssetFetchError.

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

game_idInt64TPBL game id (key space: TPBL games on api.tpbl.basketball): the {game_id} of the game routes. Not sequential by date (2024-25 = 1-1367, 2025-26 = 1371-8641, 2026-27 = 27535-27667). The box score echoes no game id, so a box frame parsed without the request stamp has a null game_id.
gohoops_game_idInt64GoHoops game id (key space: GoHoops games; 1242 for TPBL game 6). Not the TPBL game id.
division_idInt64TPBL division id (key space: TPBL divisions, one competition phase of one season; 1, 2, 5, 6, 7 = 2024-25, 8, 9, 11, 12, 35 = 2025-26, 655, 656 = 2026-27): the {division_id} of every division route. Not the GoHoops division id.

gohoops_season_idInt64GoHoops season id (key space: GoHoops seasons, the id system the API echoes beside its own; 101 = 2024-25, 213 = 2025-26, 275 = 2026-27). Not the TPBL season id. Read from the home team.

is_liveBooleanTrue while the game is being played; false for finished and scheduled games.

home_team_idInt64Home TPBL team id (key space: TPBL teams = franchises, 2-8 so far; stable across seasons): the {team_id} of the division team routes. Not the GoHoops franchise id and not the squad id.

away_team_idInt64Away TPBL team id (key space: TPBL teams = franchises, 2-8 so far; stable across seasons): the {team_id} of the division team routes. Not the GoHoops franchise id and not the squad id.
