icehl_game_info​

Game info of one match: state, arena, attendance, officials, coaches, period scores.

Endpoint URL: GET https://s3.eu-west-1.amazonaws.com/icehl.hokejovyzapis.cz/matches/{match_id}/game-header.json

Valid URL: https://s3.eu-west-1.amazonaws.com/icehl.hokejovyzapis.cz/matches/8161/game-header.json

API ParameterPythonPatternRequiredNullableDescription
match_idmatch_idYMatch id (per-bucket match key space: match_id in icehl_schedule). Not the league website's game id.

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
actual_time_nameStringDisplay label of the game state, e.g. end / Ende.

return_parsed=False — the raw JSON Dict payload, unparsed.

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. The bucket has no such key (S3 404 NoSuchKey: unknown season, competition, match or team), or the file holds no rows (an unplayed game, an empty shot shell).
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty.

Example​

icehl_game_info(match_id=8161)
