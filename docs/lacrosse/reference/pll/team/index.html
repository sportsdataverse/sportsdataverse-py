pll_team_box​

A game's team box score: one row per team (scoring, shooting, faceoffs, clears, saves, special teams, possessions and time of possession).

Endpoint URL: GET https://stats.premierlacrosseleague.com/api/v4/events/{event_slug}/teams/stats

Valid URL: https://stats.premierlacrosseleague.com/api/v4/events/2026-ev-4/teams/stats

API ParameterPythonPatternRequiredNullableDescription
event_slugevent_slugYGame slug (event_slug in pll_schedule), 2021 onward.

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
event_slugStringGame slug, the id every per-game wrapper takes (e.g. 2026-ev-4; the format changes by season).
team_idStringTeam code (e.g. WAT).
scoresInt64Points scored (a 2-point goal counts 2).
scores_againstInt64Points allowed (a 2-point goal counts 2).
goalsInt64Goals (1-point plus 2-point; goals = one_point_goals + two_point_goals).
one_point_goalsInt641-point goals (inside the arc).
two_point_goalsInt642-point goals (from beyond the arc).
assistsInt64Assists credited (passes leading directly to a goal).
shotsInt64Shots taken (on and off goal).
shot_pctFloat64Goals per shot (goals / shots).
shots_on_goalInt64Shots that were on goal (saved or scored).
shots_on_goal_pctFloat64Shots on goal per shot.
two_point_shotsInt64Shots from beyond the arc.
two_point_shot_pctFloat64Goals per shot from beyond the arc.
two_point_shots_on_goalInt642-point shots on goal.
two_point_shots_on_goal_pctFloat642-point shots on goal per 2-point shot.
goals_againstInt64Goals allowed (each goal once, whatever its point value).
two_point_goals_againstInt642-point goals allowed.
savesInt64Saves made by the goalie (or team).
save_pctFloat64Saves per shot on goal faced (saves / (saves + goals_against); checked on the captures).
clean_savesInt64Saves the goalie controlled cleanly (no rebound).
messy_savesInt64Saves that left a rebound.
clean_save_pctFloat64Clean saves per save (clean_saves / saves).
ground_ballsInt64Ground balls picked up.
turnoversInt64Turnovers committed.
caused_turnoversInt64Caused turnovers (takeaways credited to a defender).
faceoffs_wonInt64Faceoffs won by the player or team.
faceoffs_lostInt64Faceoffs lost by the player or team.
faceoffsInt64Faceoffs taken (faceoff_pct = faceoffs_won / faceoffs; won + lost can fall short of it, as in the captures).
faceoff_pctFloat64Faceoffs won per faceoff taken (faceoffs_won / faceoffs).
clearsInt64Successful clears.
clear_attemptsInt64Clearing attempts (moving the ball from the defensive to the offensive half).
clear_pctFloat64Successful clears per attempt (clears / clear_attempts).
ride_attemptsInt64Riding attempts (opponent clears contested).
num_penaltiesInt64Penalties committed.
pimFloat64Penalty minutes.
shot_clock_expirationsInt64Shot-clock violations.
times_man_upInt64Man-up (power-play) chances.
power_play_goalsInt64Power-play goals.
power_play_shotsInt64Power-play shots.
power_play_pctFloat64Power-play goals per man-up chance.
times_short_handedInt64Man-down (short-handed) spells.
power_play_goals_againstInt64Power-play goals allowed.
power_play_goals_against_pctFloat64Power-play goals allowed per opponent man-up chance.
man_down_pctFloat64Man-down (penalty kill) success rate.
total_passesInt64Passes made, as the league's tracking counts them.
touchesInt64Touches (possessions of the ball by the player).
time_in_possesionInt64Time in possession, seconds (the API's spelling).
time_in_possesion_pctFloat64Share of game time in possession (0-1).
total_possessionsInt64Team possessions in the game.

return_parsed=False — the raw JSON Dict payload, unparsed.

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. An unknown game, team or player slug, or a 2019-2020 game slug on a per-game route (HTTP 404).
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help. The API rejected a parameter (a missing year, a season segment or stat name outside its allowed list; HTTP 400).
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. The 403 origin refusal, any other failed fetch, or a 200 that is not the {data: ...} envelope.

Example​

pll_team_box(event_slug='2026-ev-4')

pll_team_roster​

One team's roster: one row per player (jersey, position, bio, injury and contract status).

Endpoint URL: GET https://stats.premierlacrosseleague.com/api/v4/teams/{team_slug}/roster

Valid URL: https://stats.premierlacrosseleague.com/api/v4/teams/waterdogs/roster?year=2026&seasonSegment=regular

API ParameterPythonPatternRequiredNullableDescription
team_slugteam_slugYTeam slug (team_slug in pll_team_season_stats), e.g. waterdogs.
yearyearYSeason; omitted, the current one.
seasonSegmentseason_segmentYSeason segment.

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.
