nbl_rosetta_match_by_id​

One match's header (the same body as nbl_rosetta_match): status, scores, venue, season and teams.

Endpoint URL: GET https://prod.rosetta.nbl.com.au/get/match/{match_id}

Valid URL: https://prod.rosetta.nbl.com.au/get/match/b217a699-4bef-11f0-bc08-933162362355

API ParameterPythonPatternRequiredNullableDescription
match_idmatch_idYDataCore fixture id of the match (match_id of nbl_rosetta_matches), a UUID, e.g. b217a699-4bef-11f0-bc08-933162362355.

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
orgStringOrganisation the row belongs to: nbl, wnbl or nbl1. From the row's competition, else from the request.
match_idStringDataCore fixture id (UUID v1); equal to id.
match_statusStringStatus of the match in Rosetta's words (complete for a finished game): box score and play-by-play of any other status are partial.
start_time_datetimeStringTip-off, UTC; same value as start_time.
match_typeStringMatch type: regular, final (FINAL upper case seen)
attendanceInt64Attendance, a STRING; null when not recorded.
clockStringGame clock of the latest event, HH:MM:SS remaining in the period.
current_periodInt64Latest period number as a STRING; null on older matches.
clock_runningBooleanGame clock is running.
home_scoreInt64Home final score, a STRING; null before tip-off.
away_scoreInt64Away final score, a STRING; null before tip-off.
roundStringRound label: a number as a string in the regular season ("13"), words in the finals ("SEMI FINAL SERIES 1", "CHAMPIONSHIP")
start_timeStringTip-off, UTC, with no offset or a Z suffix (ESPN dates the same Perth v SE Melbourne game 2025-12-18T10:30Z; Rosetta says 2025-12-18T10:30:00)
statusStringProvider fixture status: CONFIRMED, SCHEDULED.
external_media_idStringMedia id. Through NBL25 (2024-25): the Genius Sports match id (7 digits, e.g. 2636769; 6 or fewer in older seasons). From NBL26: mostly an 8-digit number of unverified origin (e.g. 61386925), date-like codes on some games (05042026 = DDMMYYYY on the 2026 Championship game, 1409252 = DDMMYY + n on the Blitz), null on many preseason games. NBL1 and WNBL 2025 carry 8-digit numbers.
match_slugStringURL slug of the match page on nbl.com.au.
match_titleStringMatch title (" v <men|women> DD-MM-YYYY")
secondary_external_idStringUnobserved in samples (null in every capture); type and meaning unverified.
live_exclusiveBooleanMatch is a live-stream exclusive.
season_idStringDataCore id (UUID v1, Sportradar) of the season; stable across seasons and the id to join on across routes.
rosetta_season_idStringRosetta's own id (UUID v4; v5 on NBL1) of the season; routes that take this entity accept it as well as the DataCore id.
season_yearInt64Rosetta's year of the season: the START year for the NBL and WNBL from 1998-99 (2025 = 2025-26), the calendar year for NBL1 and the 1979-1997 winter seasons. See season_end_year for the sdv key.
season_typeStringSeason type: regular (includes finals), preseason, in_season (cups, blitz, exhibition), test.
season_competition_idStringRosetta competition id (UUID v4)
season_competition_nameStringName of the competition the season belongs to (e.g. NBL, WNBL, NBL1 North Men).
season_competition_genderStringGender (MALE/FEMALE upper case on seasons and players, male/female lower case on competitions and divisions; UNKNOWN seen)
season_competition_league_nameStringName of the league the competition belongs to (NBL, WNBL or NBL1).
season_competition_divisionStringNBL1 divisions (conference x gender); empty for NBL and WNBL.
venue_idStringDataCore id (UUID v1, Sportradar) of the venue; stable across seasons and the id to join on across routes.
rosetta_venue_idStringRosetta's own id (UUID v4; v5 on NBL1) of the venue; routes that take this entity accept it as well as the DataCore id.
venue_nameStringName of the venue (arena), e.g. RAC Arena.
venue_addressStringUnobserved in samples (null in every capture); type and meaning unverified.
venue_capacityInt64Unobserved in samples (null in every capture); type and meaning unverified.
venue_timezoneStringIANA time zone of the venue, e.g. Australia/Sydney.
venue_codeStringVenue code; often null.
venue_stateStringUnobserved in samples (null in every capture); type and meaning unverified.
venue_suburbStringUnobserved in samples (null in every capture); type and meaning unverified.
venue_latitudeFloat64Unobserved in samples (null in every capture); type and meaning unverified.
venue_longitudeFloat64Unobserved in samples (null in every capture); type and meaning unverified.
venue_countryStringCountry; often null.
home_team_idStringDataCore id (UUID v1, Sportradar) of the home team; stable across seasons and the id to join on across routes.
home_team_nameStringDisplay name of the team.
home_team_external_team_nameStringTeam name as DataCore spells it.
home_team_codeStringTeam code of the home team, e.g. PER or SYD.
away_team_idStringDataCore id (UUID v1, Sportradar) of the away team; stable across seasons and the id to join on across routes.
away_team_nameStringDisplay name of the team.
away_team_external_team_nameStringTeam name as DataCore spells it.
away_team_codeStringTeam code of the away team, e.g. PER or SYD.
data_sourceStringBackend that built the body: nexus-api or lambda-cache (observed). It varies between requests for the same match (the NBL 2025-26 sample game came back lambda-cache from /live/all and nexus-api from /match/{match_id} minutes apart, with identical play-by-play), so it says nothing about the data.
match_status_stringStringStatus banner text, e.g. FINAL.
play_by_play_updated_datetimeStringLast play-by-play update, ISO 8601 UTC.
season_end_yearInt64sdv season key: the END year of the season (2026 = 2025-26), derived from season_year (a START year for the NBL and WNBL from 1998-99, a calendar year for NBL1 and the 1979-1997 winter seasons; year 1998 is split on the start date). Where the body carries no year it is the season asked for.

return_parsed=False — the raw JSON Dict payload, unparsed.

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. Rosetta answered 404 or no rows (an unknown match, team, player or season id, an org or season type with nothing, or no season in progress).
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. The 403 gate body, a stub or error envelope, a page cut by Rosetta's path cache, or a body for another org, season or entity than the one asked for.
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.
