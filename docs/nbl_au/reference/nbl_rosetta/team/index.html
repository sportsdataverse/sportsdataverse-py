nbl_rosetta_teams​

Every team record of an organisation: current, defunct, exhibition and development sides.

Endpoint URL: GET https://prod.rosetta.nbl.com.au/get/{org}/teams

Valid URL: https://prod.rosetta.nbl.com.au/get/nbl/teams

API ParameterPythonPatternRequiredNullableDescription
orgorgYOrganisation: nbl (men's NBL), wnbl (women's) or nbl1 (the second tier, men's and women's conferences).
limitlimitYRows to return. Omitted = a page large enough for the whole list (a short page cut by Rosetta's path cache is refused).

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
orgStringOrganisation the row belongs to: nbl, wnbl or nbl1. From the row's competition, else from the request.
team_idStringDataCore team id (UUID v1); stable across seasons.
rosetta_team_idStringRosetta team id (UUID v4; v5 on NBL1); stable across seasons; accepted as {team_id}.
nameStringTeam name as Rosetta spells it, e.g. Perth Wildcats.
team_codeStringTeam code, e.g. PER (the {team_code} path value)
establishedStringYear the club was founded; often null.
head_coachStringHead coach; often null.
championshipsStringChampionships won; often null.
websiteStringClub website URL.
external_media_competitor_idStringTeam id on the media/OTT service; often null.
conferenceStringNBL1 conference of the team (name); null for NBL and WNBL teams.
divisionStringNBL1 division of the team (name); null for NBL and WNBL teams.
venue_nameStringName of the venue (arena), e.g. RAC Arena.
venue_addressStringUnobserved in samples (null in every capture); type and meaning unverified.
venue_stateStringUnobserved in samples (null in every capture); type and meaning unverified.
venue_countryStringUnobserved in samples (null in every capture); type and meaning unverified.
venue_timezoneStringIANA time zone of the venue, e.g. Australia/Sydney.
venue_latitudeFloat64Unobserved in samples (null in every capture); type and meaning unverified.
venue_longitudeFloat64Unobserved in samples (null in every capture); type and meaning unverified.
venue_capacityInt64Unobserved in samples (null in every capture); type and meaning unverified.
conference_nameStringName of the NBL1 conference the team plays in (e.g. North, South); null outside NBL1.
division_nameStringDivision name (NBL1 conference + gender)

return_parsed=False — the raw JSON Dict payload, unparsed.

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. Rosetta answered 404 or no rows (an unknown match, team, player or season id, an org or season type with nothing, or no season in progress).
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. The 403 gate body, a stub or error envelope, a page cut by Rosetta's path cache, or a body for another org, season or entity than the one asked for.
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.

Example​

nbl_rosetta_teams(org='nbl')

nbl_rosetta_team_players​

Roster of one team in a season: player bio, jersey and position.

Endpoint URL: GET https://prod.rosetta.nbl.com.au/get/{org}/players/for/team/{team_id}/in/season/{season}

Valid URL: https://prod.rosetta.nbl.com.au/get/nbl/players/for/team/befee10a-410c-11f0-b3f4-1b3c55488bbb/in/season/2026

API ParameterPythonPatternRequiredNullableDescription
team_idteam_idYTeam id: the DataCore id (team_id of nbl_rosetta_teams) or Rosetta's own id; either is accepted.
seasonseasonYSeason END year (2026 = 2025-26). The runtime maps it to Rosetta's year: the START year for the NBL and WNBL from 1998-99, the calendar year for NBL1 and the NBL / WNBL winter seasons up to 1998. END 1998 and 1999 both read Rosetta year 1998, which holds two seasons; the matches frame keeps the one asked for.
orgorgYOrganisation: nbl (men's NBL), wnbl (women's) or nbl1 (the second tier, men's and women's conferences).

player_idStringDataCore id (UUID v1, Sportradar) of the player; stable across seasons and the id to join on across routes.
rosetta_player_idStringRosetta's own id (UUID v4; v5 on NBL1) of the player; routes that take this entity accept it as well as the DataCore id.
player_first_nameStringThe player's given name, e.g. Elijah.

Where the body carries no year it is the season asked for.
