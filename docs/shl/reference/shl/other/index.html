shl_boxscore​

Skater and goalie box score per team (2023/24 on).

Endpoint URL: GET https://www.shl.se/api/gameday/boxscore/{game_uuid}

Valid URL: https://www.shl.se/api/gameday/boxscore/bdhvuc5tex

API ParameterPythonPatternRequiredNullableDescription
game_uuidgame_uuidYGame uuid (gameInfo[].uuid from /sports-v2/game-schedule). gameday/* has data from 2023/24 on; older games answer 200 with an empty body.

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
team_sidecharacterSide of the game: home or away.
position_groupcharacterskater or goalie (goalies come from the body's gkStats rows).
player_idintegerisa (StatNet) player id, Int64. Play-by-play sends it as a string, every other route as an integer; it is cast here so the frames join.
team_idcharacterTeam code (e.g. FHC) in gameday and standings payloads; not the team uuid.
periodintegerPeriod: 0 = the whole game, 1-3 the periods, 4 and up overtime.
full_namecharacterGiven name and surname.
first_namecharacterGiven (first) name of the player.
last_namecharacterSurname (family name) of the player.
nrintegerJersey (shirt) number of the player.
poscharacterPosition code in this game (e.g. CE, LW, RW, D, GK).
lineintegerLine (unit) number the player was listed on.
gnumericNumber of goals scored.
anumericNumber of assists credited.
ppgnumericPower-play goals.
swnumericNumber of shots that missed the net.
pimnumericPenalty minutes.
sognumericNumber of shots on goal.
ppsognumericPower-play shots on goal.
plus_minusnumericPlus/minus in the game.
toicharacterTime on ice (mm:ss). Clock/duration as an mm:ss string.
hitsnumericBody checks delivered.
fownumericNumber of face-offs won.
folnumericFace-offs lost.
fo_percnumericFace-off win %.
ganumericNumber of goals conceded (goals against).
soganumericShots on goal against.
spganumericUnverified goalie column (box score).
svsnumericNumber of saves made by the goalie.
svs_percnumericSave percentage of the game as a FRACTION 0-1 (e.g. '0.9655...'); integer 0 for a goalie without shots. Numeric, but sent as a string in some rows and as a number in others.

return_parsed=False — the raw JSON Dict payload, unparsed.
