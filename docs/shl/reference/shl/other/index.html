shl_boxscore​

Skater and goalie box score per team (2023/24 on).

Endpoint URL: GET https://www.shl.se/api/gameday/boxscore/{game_uuid}

Valid URL: https://www.shl.se/api/gameday/boxscore/bdhvuc5tex

API ParameterPythonPatternRequiredNullableDescription
game_uuidgame_uuidYGame uuid (gameInfo[].uuid from /sports-v2/game-schedule). gameday/* has data from 2023/24 on; older games answer 200 with an empty body.

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
team_sideStringSide of the game: home or away.
position_groupStringskater or goalie (goalies come from the body's gkStats rows).
player_idInt64isa (StatNet) player id, Int64. Play-by-play sends it as a string, every other route as an integer; it is cast here so the frames join.
team_idStringTeam code (e.g. FHC) in gameday and standings payloads; not the team uuid.
periodInt64Period: 0 = the whole game, 1-3 the periods, 4 and up overtime.
full_nameStringGiven name and surname.
first_nameStringGiven (first) name of the player.
last_nameStringSurname (family name) of the player.
nrInt64Jersey (shirt) number of the player.
posStringPosition code in this game (e.g. CE, LW, RW, D, GK).
lineInt64Line (unit) number the player was listed on.
gFloat64Number of goals scored.
aFloat64Number of assists credited.
ppgFloat64Power-play goals.
swFloat64Number of shots that missed the net.
pimFloat64Penalty minutes.
sogFloat64Number of shots on goal.
ppsogFloat64Power-play shots on goal.
plus_minusFloat64Plus/minus in the game.
toiStringTime on ice (mm:ss). Clock/duration as an mm:ss string.
hitsFloat64Body checks delivered.
fowFloat64Number of face-offs won.
folFloat64Face-offs lost.
fo_percFloat64Face-off win %.
gaFloat64Number of goals conceded (goals against).
sogaFloat64Shots on goal against.
spgaFloat64Unverified goalie column (box score).
svsFloat64Number of saves made by the goalie.
svs_percFloat64Save percentage of the game as a FRACTION 0-1 (e.g. '0.9655...'); integer 0 for a goalie without shots. Numeric, but sent as a string in some rows and as a number in others.

return_parsed=False — the raw JSON Dict payload, unparsed.

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. SHL answered 404, an empty body (gameday routes before 2023/24), a table with no rows, another game / team / ssgt than the one asked for, or the season and game type are not in layout-info.
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty.

Example​

shl_boxscore(game_uuid='bdhvuc5tex')
