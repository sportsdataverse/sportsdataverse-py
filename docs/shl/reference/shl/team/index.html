SHL — SHL site API (www.shl.se/api, Sweden) — Team

shl_team​

One team.

Endpoint URL: GET https://www.shl.se/api/sports-v2/teams/{team_uuid}

Valid URL: https://www.shl.se/api/sports-v2/teams/087a-087aTQv9u

API ParameterPythonPatternRequiredNullableDescription
team_uuidteam_uuidYTeam uuid (homeTeamInfo.uuid / awayTeamInfo.uuid in the schedule, or teamList[].uuid).

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
names_codeStringDisplay abbreviation; differs from the team code for some clubs (SKE vs SAIK, ÖRE vs OHK).
names_shortStringShort club name ('Herr' = men's team).
names_longStringLong club name ('Herr' = men's team).
names_fullStringFull club name ('Herr' = men's team).
names_code_siteStringDisplay abbreviation on the site; 'Herr' = men's team (e.g. 'DIF Herr').
names_short_siteStringShort club name as shown on the site ('Herr' = men's team).
names_full_siteStringFull club name as shown on the site ('Herr' = men's team).
names_long_siteStringLong club name as shown on the site ('Herr' = men's team).
info_foundedStringClub founding year (text). Numeric value sent as a string.
info_goldsStringClub's championships (text).
info_finalsStringClub's final appearances (text).
info_retired_numbersStringRetired jersey numbers (text).
info_addressStringClub postal address.
info_phoneStringTelephone number of the club.
info_faxStringFax number of the club.
info_emailStringContact email address of the club.
info_chairmanStringName of the club chairman.
info_managerStringClub general manager.
info_accreditationStringPress-accreditation contact, free Swedish text (e.g. 'Senast dagen före match till …' = 'no later than the day before the game, to …').
info_facebookStringClub Facebook URL.
info_instagramStringClub Instagram URL.
info_twitterStringClub X/Twitter URL.
contactStringClub contact text.
uuidStringTeam uuid (platform key space, e.g. 087a-087aTQv9u); joins to /sports-v2/teams/{team_uuid} and schedule homeTeamInfo/awayTeamInfo.uuid. Not the team code.
nationalityStringNationality (ISO country code).
arena_nameStringName of the arena hosting the game. Empty string in every sample (placeholder).
public_urlStringPublic image URL.
iconStringURL of the team logo image.
owner_instance_idStringClub site instance id (e.g. fhc1_fhc); also names the logo at sportality.cdn.s8y.se/team-logos/{id}.svg.
site_display_nameStringClub name as shown on its own site (e.g. Frölunda HC).

return_parsed=False — the raw JSON Dict payload, unparsed.

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. SHL answered 404, an empty body (gameday routes before 2023/24), a table with no rows, another game / team / ssgt than the one asked for, or the season and game type are not in layout-info.
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty.

Example​

shl_team(team_uuid='087a-087aTQv9u')

away_team_names_long_siteStringLong club name as shown on the site ('Herr' = men's team).

shl_team_stats​

Team stats per period and total (2023/24 on).

Endpoint URL: GET https://www.shl.se/api/gameday/team-stats/{game_uuid}

Valid URL: https://www.shl.se/api/gameday/team-stats/bdhvuc5tex

API ParameterPythonPatternRequiredNullableDescription
game_uuidgame_uuidYGame uuid (gameInfo[].uuid from /sports-v2/game-schedule). gameday/* has data from 2023/24 on; older games answer 200 with an empty body.

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
team_sideStringSide of the game: home or away.
game_source_idStringStatNet game key, date-HOME-AWAY (e.g. 20250913-FHC-LHC); the same game as gameId.
game_idInt64StatNet game number (StatNet key space, e.g. 22003); keys stats-info games{} and equals sports-v2 game-info extId. Not the game uuid.
placeStringSide of the game: home or away.
scoreInt64Goals scored by the team in the game.
team_idStringTeam code (e.g. FHC) in gameday and standings payloads; not the team uuid.
team_nameStringName of the team.
team_codeStringStatNet team code (SAIK, FHC).
game_uuidStringPlatform game uuid (bdhvuc5tex); every gameday route takes it.
periodInt64Period: 0 = the whole game, 1-3 the periods, 4 and up overtime.
gFloat64Number of goals scored.
pimFloat64Penalty minutes.
fowFloat64Number of face-offs won.

return_parsed=False — the raw JSON Dict payload, unparsed.

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. SHL answered 404, an empty body (gameday routes before 2023/24), a table with no rows, another game / team / ssgt than the one asked for, or the season and game type are not in layout-info.
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty.

Example​

shl_team_stats(game_uuid='bdhvuc5tex')
