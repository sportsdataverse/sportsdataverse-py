SHL — SHL site API (www.shl.se/api, Sweden) — Other: standings–stats_info

shl_standings​

Standings of an ssgt (gameday widget).

Endpoint URL: GET https://www.shl.se/api/gameday/team-standings/{ssgt_uuid}

Valid URL: https://www.shl.se/api/gameday/team-standings/iuzqg7dqk9

API ParameterPythonPatternRequiredNullableDescription
ssgt_uuidssgt_uuidYssgt uuid: one season + series + game type (e.g. 2025/2026 SHL regular season). Directory: /statistics-v2/layout-info seasonSeriesGameTypeTeams[].ssgtUuid.

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
seasonInt64Season END year (2026 = 2025/26).
ssgt_uuidStringssgt uuid (platform key space: one season + series + game type); label via layout-info seasonSeriesGameTypeTeams[].
team_codeStringStatNet team code (SAIK, FHC).
team_uuidStringPlatform team uuid.
team_nameStringName of the team.
team_short_nameStringShort display name of the team.
rankInt64Position in the table (1 = top).
rank_diffInt64Change in standings rank, in places (the reference point is unverified).
gpInt64Number of games played.
wInt64Regulation wins.
tInt64Games tied after regulation, decided in overtime or a shootout (= OTW + OTL).
lInt64Regulation losses.
otwInt64Overtime and shootout wins.
otlInt64Overtime and shootout losses.
pInt64Standings points (3 per regulation win, 2 per OT/SO win, 1 per OT/SO loss).
gfInt64Number of goals scored (goals for).
gaInt64Number of goals conceded (goals against).
diffInt64Goal difference.

return_parsed=False — the raw JSON Dict payload, unparsed.

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. SHL answered 404, an empty body (gameday routes before 2023/24), a table with no rows, another game / team / ssgt than the one asked for, or the season and game type are not in layout-info.
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty.

Example​

shl_standings(ssgt_uuid='iuzqg7dqk9')

shl_stats_info​

Stats table of one module for an ssgt (standings, players, goalies, teams, games).

Endpoint URL: GET https://www.shl.se/api/statistics-v2/stats-info/{module}

Valid URL: https://www.shl.se/api/statistics-v2/stats-info/players_summary?count=1000&season=2026&gameType=regular

API ParameterPythonPatternRequiredNullableDescription
modulemoduleYStats module: _. Every name under layout-info [].filters..modules.
seasonseasonYRequired. Season END year (2026 = 2025/26). Mapped to the provider's ssgt through /statistics-v2/layout-info (SHL 1975/76 on); a season it does not list raises NoDataError.
gameTypegame_typeYGame type: regular (Grundserie), playoff (Slutspel), qualdown (relegation qualification) or playin (2023/24 on).
