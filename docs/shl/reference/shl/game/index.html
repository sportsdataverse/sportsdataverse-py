SHL — SHL site API (www.shl.se/api, Sweden) — Game

shl_game_header​

Game header: StatNet extId, arena, state, teams, scores.

Endpoint URL: GET https://www.shl.se/api/sports-v2/game-info/{game_uuid}

Valid URL: https://www.shl.se/api/sports-v2/game-info/bdhvuc5tex

API ParameterPythonPatternRequiredNullableDescription
game_uuidgame_uuidYGame uuid (gameInfo[].uuid from /sports-v2/game-schedule). gameday/* has data from 2023/24 on; older games answer 200 with an empty body.

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
instance_context_site_team_is_in_gamelogicalWhether the site's team plays in the game.
instance_context_site_team_is_home_teamlogicalWhether the site's team is the home team.
instance_context_site_team_is_away_teamlogicalWhether the site's team is the away team.
game_info_game_uuidcharacterGame uuid (platform key space, e.g. bdhvuc5tex); joins to schedule gameInfo[].uuid and every gameday/{game_uuid} route. The StatNet number of the same game is gameId.
game_info_ext_idintegerStatNet game number as a string (StatNet key space); equals gameday gameId. Numeric value sent as a string.
game_info_start_date_timecharacterScheduled start, local time (Europe/Stockholm).
game_info_arena_namecharacterName of the arena hosting the game.
game_info_statecharacterGame state with an underscore (post_game seen); the schedule spells it post-game.
game_info_overtimelogicalWhether the game went to overtime.
game_info_shootoutlogicalWhether the game went to a shootout.
game_info_series_codecharacterSeries code of the game (SHL).
game_info_series_namecharacterSeries label of the game (SHL).
game_info_round_numberintegerSchedule round (1 = first game day of the season).
game_info_round_labelcharacterRound label (often empty). Empty string in every sample (placeholder).
game_info_series_display_namecharacterSeries label shown on the site (SHL).
home_team_names_codecharacterDisplay abbreviation; differs from the team code for some clubs (SKE vs SAIK, ÖRE vs OHK).
home_team_names_shortcharacterShort club name ('Herr' = men's team).
home_team_names_longcharacterLong club name ('Herr' = men's team).
home_team_names_fullcharacterFull club name ('Herr' = men's team).
home_team_names_code_sitecharacterDisplay abbreviation on the site; 'Herr' = men's team (e.g. 'DIF Herr').
home_team_names_short_sitecharacterShort club name as shown on the site ('Herr' = men's team).
home_team_names_full_sitecharacterFull club name as shown on the site ('Herr' = men's team).
home_team_names_long_sitecharacterLong club name as shown on the site ('Herr' = men's team).
home_team_uuidcharacterTeam uuid (platform key space, e.g. 087a-087aTQv9u); joins to /sports-v2/teams/{team_uuid} and schedule homeTeamInfo/awayTeamInfo.uuid. Not the team code.
home_team_instance_idcharacterClub site instance id (e.g. fhc1_fhc).
home_team_founded_oncharacterClub founding date. Numeric value sent as a string.
home_team_addresscharacterClub postal address.
home_team_emailcharacterContact email address of the club.
home_team_iconcharacterURL of the team logo image.
home_team_scoreintegerGoals scored by the team in the game.
away_team_names_codecharacterDisplay abbreviation; differs from the team code for some clubs (SKE vs SAIK, ÖRE vs OHK).
away_team_names_shortcharacterShort club name ('Herr' = men's team).
away_team_names_longcharacterLong club name ('Herr' = men's team).
away_team_names_fullcharacterFull club name ('Herr' = men's team).
away_team_names_code_sitecharacterDisplay abbreviation on the site; 'Herr' = men's team (e.g. 'DIF Herr').
away_team_names_short_sitecharacterShort club name as shown on the site ('Herr' = men's team).
away_team_names_full_sitecharacterFull club name as shown on the site ('Herr' = men's team).
away_team_names_long_sitecharacterLong club name as shown on the site ('Herr' = men's team).
away_team_uuidcharacterTeam uuid (platform key space, e.g. 087a-087aTQv9u); joins to /sports-v2/teams/{team_uuid} and schedule homeTeamInfo/awayTeamInfo.uuid. Not the team code.
away_team_instance_idcharacterClub site instance id (e.g. fhc1_fhc).
away_team_founded_oncharacterClub founding date. Numeric value sent as a string.
away_team_addresscharacterClub postal address.
away_team_emailcharacterContact email address of the club.
away_team_iconcharacterURL of the team logo image.
away_team_scoreintegerGoals scored by the team in the game.
ssgt_uuidcharacterssgt uuid (platform key space: one season + series + game type); label via layout-info seasonSeriesGameTypeTeams[].
series_uuidcharacterSeries uuid (platform key space; SHL = qQ9-bb0bzEWUk); the seriesUuid param of game-schedule.

return_parsed=False — the raw JSON Dict payload, unparsed.

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. SHL answered 404, an empty body (gameday routes before 2023/24), a table with no rows, another game / team / ssgt than the one asked for, or the season and game type are not in layout-info.
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty.

Example​

shl_game_header(game_uuid='bdhvuc5tex')

game_uuidgame_uuidYGame uuid (gameInfo[].uuid from /sports-v2/game-schedule). gameday/* has data from 2023/24 on; older games answer 200 with an empty body.

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

home_team_game_source_idcharacterStatNet game key, date-HOME-AWAY (e.g. 20250913-FHC-LHC); the same game as gameId.
home_team_game_idintegerStatNet game number (StatNet key space, e.g. 22003); keys stats-info games{} and equals sports-v2 game-info extId. Not the game uuid.
home_team_placecharacterSide of the game: home or away.

home_team_team_namecharacterTeam display name (e.g. Frölunda HC).
home_team_team_codecharacterTeam code (FHC, LHC, ...).
home_team_game_uuidcharacterGame uuid (platform key space, e.g. bdhvuc5tex); joins to schedule gameInfo[].uuid and every gameday/{game_uuid} route. The StatNet number of the same game is gameId.
away_team_game_source_idcharacterStatNet game key, date-HOME-AWAY (e.g. 20250913-FHC-LHC); the same game as gameId.
