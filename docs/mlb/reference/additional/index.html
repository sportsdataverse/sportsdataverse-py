MLB — additional Python functions

Hand-written wrappers, loaders, and helpers in sportsdataverse.mlb not covered by the generated API-endpoint reference above.

ESPN​

FunctionSummary

espn_mlb_player_statsPull an MLB athlete's ESPN season stat line as one wide row.
espn_mlb_scheduleespn_mlb_schedule - look up the MLB schedule for a given date or season-year.
espn_mlb_teamsespn_mlb_teams - look up MLB teams from ESPN's Site v2 API.
