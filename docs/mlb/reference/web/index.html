espn_mlb_player_overview​

ESPN endpoint.

Endpoint URL: GET https://site.web.api.espn.com/apis/common/v3/sports/baseball/mlb/athletes/{athlete_id}/overview

Valid URL: https://site.web.api.espn.com/apis/common/v3/sports/baseball/mlb/athletes/4239/overview

API ParameterPythonPatternRequiredNullableDescription
athlete_idathlete_idYathlete_id path parameter.

col_nametypedescription

espn_mlb_player_stats_v3​

ESPN endpoint.

Endpoint URL: GET https://site.web.api.espn.com/apis/common/v3/sports/baseball/mlb/athletes/{athlete_id}/stats

Valid URL: https://site.web.api.espn.com/apis/common/v3/sports/baseball/mlb/athletes/39832/stats

API ParameterPythonPatternRequiredNullableDescription
athlete_idathlete_idYathlete_id path parameter.
seasonseasonYSeason year (e.g. 2024).

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
categoryStringESPN stat category the row belongs to (e.g., basketball "averages" / "totals" / "miscellaneous", NFL "passing", MLB "career-batting"). The stat columns after position are named from each category's own names list, so they differ by sport, and the other categories' columns are null on a row.
split_nameStringSeason label of the row (e.g., "2010-11") on the Web v3 payload, or "Career" on the row built from the category's career totals; the split's name on payloads that ship named splits.
split_categoryStringCategory of a named split; null on the Web v3 per-season rows.
split_valueStringValue of a named split; null on the Web v3 per-season rows.
seasonInt64Season end year of the row (e.g., 2011 for 2010-11); null on the "Career" row.
team_idInt64ESPN team id (Int64) the athlete played that season for; a traded player has one row per team. Null on the "Career" row.
positionStringPosition abbreviation the athlete was listed at for that season and team (e.g., "G"); null on the "Career" row.
games_playedStringGames played (GP), as ESPN ships it (a string).
at_batsStringAt bats (AB), plate appearances minus walks, hit-by-pitches and sacrifices.
runsStringRuns scored (R).
hitsStringHits (H), singles through home runs.
doublesStringDoubles (2B), two-base hits.
triplesStringTriples (3B), three-base hits.
home_runsStringHome runs (HR).
rb_isStringRuns batted in (RBI); ESPN's stat key RBIs, snake-cased.
walksStringWalks (BB), bases on balls.
hit_by_pitchStringTimes hit by a pitch (HBP).
strikeoutsStringStrikeouts (SO).
stolen_basesStringStolen bases (SB).
caught_stealingStringTimes caught stealing (CS).
avgStringBatting average (AVG), hits / at bats.
on_base_pctStringOn-base percentage (OBP), (hits + walks + hit-by-pitches) / plate appearances.
slug_avgStringSlugging percentage (SLG), total bases / at bats.
opsStringOn-base plus slugging (OPS).
warbrStringWins above replacement (WAR); ESPN's stat key WARBR, snake-cased.
plate_appearancesStringPlate appearances (PA).
pitchesStringPitches seen (P).
pitches_per_plate_appearanceStringPitches seen per plate appearance (P/PA).
extra_base_hitsStringExtra-base hits (XBH), doubles plus triples plus home runs.
total_basesStringTotal bases (TB), 1 per single, 2 per double, 3 per triple, 4 per home run.
intentional_walksStringIntentional walks (IBB).
gid_psStringGrounded into double play (GIDP); ESPN's stat key GIDPs, snake-cased.
sac_hitsStringSacrifice bunts (SH).
sac_fliesStringSacrifice flies (SF).
stolen_base_pctStringStolen-base success percentage (SB%).
off_warbrStringOffensive wins above replacement (OWAR); ESPN's stat key offWARBR, snake-cased.
runs_createdStringRuns created (RC), an estimate of the runs a batter produced.
runs_created_per27_outsStringRuns created per 27 outs (RC/27).
isolated_powerStringIsolated power (ISOP), slugging percentage minus batting average.
secondary_avgStringSecondary average (SECA), extra bases from hits plus walks and stolen bases, per at bat.
at_bats_per_home_runStringAt bats per home run (AB/HR).
walks_per_plate_appearanceStringWalks per plate appearance (BB/PA).
walk_to_strikeout_ratioStringWalks per strikeout (BB/K).
ground_ballsStringGround-ball outs (GO).
fly_ballsStringFly-ball outs (FO).
ground_to_fly_ratioStringGround outs per fly out (GO/FO).

espn_mlb_leaders​

ESPN endpoint.

Endpoint URL: GET https://site.web.api.espn.com/apis/common/v3/sports/baseball/mlb/statistics/byathlete

Valid URL: https://site.web.api.espn.com/apis/common/v3/sports/baseball/mlb/statistics/byathlete?limit=50&page=1

API ParameterPythonPatternRequiredNullableDescription
categorycategoryYLeaderboard population: the athletes ranked in that category, whose values it fills (other categories come back null). Football takes <group>:<category> (offense:passing, offense:rushing, offense:receiving, defense:defensive, scoring:scoring); a bare passing is rejected with HTTP 400 (ValueError). Basketball takes the bare name (offensive).
seasonseasonYSeason year (e.g. 2024).
seasontypeseason_typeYSeason phase: 1=preseason, 2=regular season, 3=postseason.
limitlimitYMaximum number of items to return.
pagepageYpage query parameter.
sortsortYSort key <category>.<statName>:<asc|desc>, the names in the payload's categories (passing.passingYards:desc, offensive.avgPoints:desc). A stat without its category is rejected with HTTP 400 (ValueError).

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
sort_orderInt64Position of the athlete in ESPN's leaderboard order (the requested category or sort), counted across pages: (page - 1) * limit + position on the page. A position, not a rank: tied athletes still count up; ESPN's per-stat ranks stay in the raw payload (return_parsed=False).
athlete_idInt64ESPN id of the athlete, the key the athlete endpoints (athlete_overview, athlete_stats) take.
athlete_uidStringESPN composite athlete uid (s:<sport>~l:<league>~a:<athlete id>), kept as text.
athlete_display_nameStringAthlete's full display name.
athlete_short_nameStringAthlete's abbreviated name (e.g. 'B. Nix').
athlete_first_nameStringAthlete's first name.
athlete_last_nameStringAthlete's last name.
athlete_positionStringAthlete's position abbreviation (e.g. QB, G, C).
athlete_statusStringAthlete's ESPN status name (e.g. Active, Inactive) as ESPN reports it at request time, not for the requested season.
team_idInt64ESPN id of the team the athlete played for in the requested season.
team_abbreviationStringAbbreviation of the athlete's team in the requested season (ESPN teamShortName, e.g. ORE).
team_nameStringNickname of the athlete's team in the requested season (ESPN teamName, e.g. Ducks).
batting_games_playedFloat64Games Played (ESPN 'batting' category).
batting_at_batsFloat64At Bats (ESPN 'batting' category): The number of times a batter comes up to bat not counting walks and sacrifices.
batting_runsFloat64Runs (ESPN 'batting' category): The number of runs scored.
batting_hitsFloat64Hits (ESPN 'batting' category): The number of hits.
batting_avgFloat64Batting Average (ESPN 'batting' category): The average number of times the batter reached successfully on base due to a hit: hits / atBats.
batting_doublesFloat64Doubles (ESPN 'batting' category): The number of times that a batter reaches second base as the result of a hit without an error being committed.
batting_triplesFloat64Triples (ESPN 'batting' category): The number of hits that result in the batter reaching 3rd base without the aid of an error.
batting_home_runsFloat64Home Runs (ESPN 'batting' category): The number of hits that allowed the batter to round the bases and score without the aid of an error of the defense.
batting_rb_isFloat64Runs Batted In (ESPN 'batting' category): The number of runs scored by a batter's play.
batting_total_basesFloat64Total Bases (ESPN 'batting' category): The number of bases calculated as 1 for a 1B, 2 for a 2B, 3 for a 3B and 4 for a HR.
batting_walksFloat64Walks (ESPN 'batting' category): The number of times a batter reaches base on four balls.
batting_strikeoutsFloat64Strikeouts (ESPN 'batting' category): The number of times a player strikes out.
batting_stolen_basesFloat64Stolen Bases (ESPN 'batting' category): The number of bases stolen.
batting_on_base_pctFloat64On Base Percentage (ESPN 'batting' category): The ratio of the number of times the batter reached base per plate appearnce: (hits + walks + hbp / plateAppearances).
batting_slug_avgFloat64Slugging Percentage (ESPN 'batting' category): Slugging percentage is a metric that is meant to measuring how many bases the hitter safely advances to after making contact with the ball: (totalBases / atBats).
batting_opsFloat64OBP Pct + SLG Pct (ESPN 'batting' category): The average calculated by adding up on-base percentage and slugging percentage.
batting_warbrFloat64Wins Above Replacement (ESPN 'batting' category).
pitching_games_playedFloat64Games Played (ESPN 'pitching' category).
pitching_games_startedFloat64Games Started (ESPN 'pitching' category): The number of games started by a pitcher.
pitching_quality_startsFloat64Quality Starts (ESPN 'pitching' category): The number of quality starts for a pitcher.
pitching_eraFloat64Earned Run Average (ESPN 'pitching' category): The average number of runs a pitcher yields per 9 innings thrown.
pitching_winsFloat64Wins (ESPN 'pitching' category): The number of times the pitcher was attributed with a win.
pitching_lossesFloat64Losses (ESPN 'pitching' category): The number of losses for a pitcher.
pitching_savesFloat64Saves (ESPN 'pitching' category): The number of times a pitcher enters and finishes the game without surrendering the lead in a save opportunity.
pitching_holdsFloat64Holds (ESPN 'pitching' category): The number of times a pitcher enters the game with the lead, gets at least an out and leaves the game wihtout having given up the lead.
pitching_inningsFloat64Innings pitched (ESPN 'pitching' category): The number of innings pitched.
pitching_hitsFloat64Hits (ESPN 'pitching' category): The number of hits surrendered by a pitcher.
pitching_earned_runsFloat64Earned runs (ESPN 'pitching' category): The number of earned runs surrendered by a pitcher.
pitching_home_runsFloat64Home Runs (ESPN 'pitching' category): The number of times a pitcher has allowed a home run.
pitching_walksFloat64Walks (ESPN 'pitching' category): The number of times a pitcher surrenders a base on balls.
pitching_strikeoutsFloat64Strikeouts (ESPN 'pitching' category): The number of times the pitcher struck out a batter.
pitching_strikeouts_per_nine_inningsFloat64Strikeouts Per 9 Innings (ESPN 'pitching' category): The average number of strikeouts for a pitcher per 9 innings.
pitching_whipFloat64Walks Plus Hits Per Inning Pitched (ESPN 'pitching' category): The number representing walks plus hits divided by innings pitched.
pitching_warbrFloat64Wins Above Replacement (ESPN 'pitching' category).
fielding_games_playedFloat64Games Played (ESPN 'fielding' category).
fielding_games_startedFloat64Games Started (ESPN 'fielding' category): The number of games started by a fielder.
fielding_full_innings_playedFloat64Full Innings (ESPN 'fielding' category): The number of fully completed innings by a fielder.
fielding_total_chancesFloat64Total Chances (ESPN 'fielding' category): The number of chances a fielder has to make an out calculated by assists plus putouts plus errors.
fielding_putoutsFloat64Putouts (ESPN 'fielding' category): The number of times the fielder tags or forces the out of a baserunner.
fielding_assistsFloat64Assists (ESPN 'fielding' category): The number of times a fielder is involved in an out when the fielder is not the putouter.
fielding_fielding_pctFloat64Fielding Percentage (ESPN 'fielding' category): The percentage of plays made by a fielder given the total number of chances.
fielding_errorsFloat64Errors (ESPN 'fielding' category): The number of times a fielder fails to make the play they are expected to make.
fielding_double_playsFloat64Double Plays (ESPN 'fielding' category): The number of double plays a fielder has been a part of as either the assister or putouter.
fielding_range_factorFloat64Range Factor (ESPN 'fielding' category): The estimation of how much field a fielder can cover.
fielding_def_warbrFloat64Defensive Wins Above Replacement (ESPN 'fielding' category).
fielding_passed_ballsFloat64Passed Balls (ESPN 'fielding' category): The number of times the ball is dropped or passes by the catcher.
fielding_catcher_stolen_bases_allowedFloat64Stolen Bases Allowed (ESPN 'fielding' category): The number of stolen bases that a catcher allows.
