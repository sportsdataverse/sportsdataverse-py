lba_championships​

Championships of a season, one per phase (Regular Season, Play Off); every season when none is given.

Endpoint URL: GET https://www.legabasket.it/api/championships/get-championships

Valid URL: https://www.legabasket.it/api/championships/get-championships?cs_id=1&items=1000&s=2027

API ParameterPythonPatternRequiredNullableDescription
sseasonYSeason END year (2027 = 2026-27). Omitted = every season (310 championships).

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
seasonInt64Season END year (2027 = 2026-27): the row's START year + 1.
championship_idInt64Championship id (one season and phase).
yearInt64Season START year (2026 = 2026-27); sdv END year = year + 1.
nameStringChampionship name, e.g. Regular Season A, Play Off A1.
statusInt64Championship status: 1 = in progress, 2 = finished (inferred from the 2026-27 and past samples).
championship_type_idInt64Phase type id: 4 = Regular Season, 2 = Play Off.
championship_series_idInt64Series id, 1 = Serie A.
full_nameStringName with the season, e.g. Regular Season A 2017.
focus_onBooleanHighlighted on the site.
ctype_codeStringPhase type code: RS / PO.
ctype_nameStringPhase type name, as sent in English: Regular Season, Play Off.
cserie_codeStringSeries code, A1 = Serie A.
cserie_nameStringName of the championship series, e.g. Serie A.
logo_keyStringImage key: the image is {cdn_url}/{key}, resized copies {cdn_url}/variants/{key}/thumb or /large (the site's getApiImageUrl).

return_parsed=False — the raw JSON Dict payload, unparsed.

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. The site has nothing for the request (an unknown season, a play-by-play before 2017-18, standings of a finished championship without a round, no rows).
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. The fetch failed or the answer is unknown or partial: an unknown id (the site answers HTTP 500), a game that is not final, a truncated page, or a body for another season, championship, game, team or player than the one asked for.
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.

Example​

lba_championships(season=2027)

scoreStringScore after the action, home - away string (0 - 0); 2020-21 on scoring actions only, null before.
linked_action_idInt64action_id of the related action: the shot an assist or rebound belongs to, the foul a drawn foul answers, the player swapped in a substitution.

action_2_qualifier_codeStringSecond qualifier code (fast break 500, blocked 1005, tip-ins 1001-1004, ...).

action_2_qualifier_descriptionStringlegend label of action_2_qualifier_code, Italian.
side_area_zoneStringA = in the actor's attacking half, D = its defensive half (2021-22 on).
side_area_codeStringCourt zone 1-10, number sent as a string (see the coordinates section; 2021-22 on).
player_nameStringGiven name of the acting player.
player_surnameStringFamily name of the acting player.
player_numberStringJersey number, number sent as a string.
team_nameStringTeam name in that season, with its sponsor (Nutribullet Treviso Basket); changes with the sponsor.
