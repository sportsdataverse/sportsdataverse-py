wbb_team_shot_zones​

wbb_team_shot_zones(seasons: 'int | list[int]', *, return_as_pandas: 'bool' = False) -> 'pl.DataFrame | pd.DataFrame'

Women's college season shot profile by zone per team, for and allowed.

Delegates to sportsdataverse.mbb.mbb_shot_zone_profiles.mbb_team_shot_zones with league="womens".

Parameters

ParameterTypeDefaultDescription
seasonsint | list[int]A season or list of seasons, named by the year it ends (2025 is 2024-25).
return_as_pandasboolFalseReturn a pandas frame instead of polars.

Returns

One row per (season, team_id): games, the team's zone profile and its opponents' (opp_), with the _n / _rank / _pct columns. See the mbb core for the definitions.

wbb_team_strength​

wbb_team_strength(seasons: 'int | list[int]', *, return_as_pandas: 'bool' = False) -> 'pl.DataFrame | pd.DataFrame'

Women's college team strength: adjusted ratings, SOS, SOV, tempo and the four factors.

Delegates to sportsdataverse.mbb.mbb_team_strength.mbb_team_strength with league="womens". adj_*_rtg are the published wbb_ratings; adj_*_rtg_ridge the possession ridge on the ncaa_wbb_possessions release.

Parameters

ParameterTypeDefaultDescription
seasonsint | list[int]A season or list of seasons, named by the year it ends (2025 is 2024-25).
return_as_pandasboolFalseReturn a pandas frame instead of polars.

Returns

One row per (season, team_id): games, wins, losses, poss, opp_poss, pts, opp_pts, both sets of adjusted ratings, sos, sov, the BB-D3 rates and their _rank / _pct / _n. See the mbb core for the definitions.

col_nametypedescription
seasonInt64Season, named by the year it ends (2025 is 2024-25).
team_idInt64ESPN team id. Non-D1 opponents have none and get no row.
gamesInt64Games with at least one possession in the season (from the possession release).
winsInt64Wins in the season's completed ESPN games.

weighted_avg​

weighted_avg(mutable_acc: 'LineupStatSet', obj: 'LineupStatSet') -> 'None'

Merge obj into mutable_acc with possession weighting.

Faithful port of LineupUtils.weightedAvg (LineupUtils.ts:645). Mutates mutable_acc in place (matching the upstream mutable-state contract) and returns None. Each call accumulates a weighted sum, not a weighted average -- the companion completeWeightedAvg (upstream LineupUtils.ts:752, not yet ported) divides by the accumulated weight totals to finish the average. The per-field weight used at each merge step is derived from obj's own totals (e.g. that single lineup's total_off_fga), not from any running total on mutable_acc -- callers accumulating many lineups must call weighted_avg once per lineup so every lineup contributes its own weight.

Parameters

ParameterTypeDefaultDescription
mutable_accLineupStatSetThe running accumulator (LineupStatSet). Mutated in place; fields absent from the accumulator are initialized to {"value": 0.0} (plus old_value / override when obj's field carries a luck-adjustment override marker) before obj's contribution is added.
objLineupStatSetThe per-lineup LineupStatSet document to merge in.

Returns

None. mutable_acc is mutated in place.

Raises

ExceptionDescription
NotImplementedErrorIf obj carries a game_info key -- that merge branch is deliberately deferred (see module docstring).

Example

from sportsdataverse.mbb.mbb_lineup_stats import weighted_avg

acc: dict = {}
weighted_avg(acc, lineup_a)
weighted_avg(acc, lineup_b)
print(acc["off_poss"]["value"])  # plain sum (SUM_FIELDS)

# Two-lineup possession-weighted merge

acc = {}
for lineup in three_lineups:
    weighted_avg(acc, lineup)
