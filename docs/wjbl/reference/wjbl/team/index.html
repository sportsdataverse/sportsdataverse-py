wjbl_team_box_score​

Team line and totals of each side of a final game's box score, with the shooting percentages.

Endpoint URL: GET https://api.wjbl.01core.app/api/boxscore

Valid URL: https://api.wjbl.01core.app/api/boxscore?play_schedule_id=7987

API ParameterPythonPatternRequiredNullableDescription
play_schedule_idplay_schedule_idYGame id (play_schedule_id in wjbl_schedule): ONE global sequence across every league edition and season, e.g. 7987 (2025-26 playoff final game 1), 5533 (2018-19), 4243 (2013-14 final, box score only). The game must be final.

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
play_schedule_idInt64Game id play_schedule_id (key space: W League games, ONE global sequence across every league_id and season, e.g. 4243 = 2013-14 final, 7987 = 2025-26 final). The play_schedule_id parameter of every game route and of the site's /schedule_result/detail/*?play_schedule_id= pages.
team_sideStringWhich side of the game the row belongs to: home or away (the API's home / away blocks).
team_idInt64Franchise id team_id of the side (stable across seasons and sponsor renames; 13 = Toyota Antelopes).
row_typeStringWhich line of the side: team (stats credited to the team itself) or total (the whole side).
ptsInt64Points scored by the side (the sum of its players' points).
p2mInt64Two-point field goals made.
p2aInt64Two-point field goals attempted.
p3mInt64Three-point field goals made.
p3aInt64Three-point field goals attempted.
ftmInt64Free throws made.
ftaInt64Free throws attempted.
fInt64Personal fouls committed.
offInt64Offensive rebounds.
defInt64Defensive rebounds.
totInt64Total rebounds (offensive plus defensive).
astInt64Assists credited to the side.
stlInt64Steals credited to the side.
blkInt64Blocked shots credited to the side.
toInt64Turnovers committed by the side.
minStringMinutes: summed minutes 'mmm:ss' on the total row ('200:00' = 5 x 40:00), always '00:00' on the team row.
min_secondsInt64Minutes played in whole seconds, from the 'mm:ss' clock string min (null when it does not parse).
p2pFloat64Two-point field-goal percentage 0-100 (a string on the wire); total row only.
p3pFloat64Three-point field-goal percentage 0-100 (a string on the wire); total row only.
ftpFloat64Free-throw percentage 0-100 (a string on the wire); total row only.
fgpFloat64Field-goal percentage 0-100, two- and three-pointers together (a string on the wire); total row only.

return_parsed=False — the raw body (dict): the route's JSON (a bare list as {'items': [...]}) plus _request (the ids asked for, with season the END year).

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. The API has nothing for the request (an empty list, an id it does not know, a game without play-by-play before 2018-19, a season without months or games).
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. The fetch failed or the answer is unknown or partial: an error envelope (HTTP 200), any other non-2xx, a game that is not final, a truncated play-by-play, or a body for another game, league edition, month, team, season phase or player than the one asked for.
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help. A season that is not the END year of a W League edition, an id that is not an integer, a game_month that is not YYYY-MM (raised before the request), or the API's HTTP 400 / 422.

Example​

wjbl_team_box_score(play_schedule_id=7987)

Valid URL: https://api.wjbl.01core.app/api/pbp/team-stats?play_schedule_id=7987

home_team_idInt64Home team: Franchise id team_id (key space: W League franchises, STABLE across seasons and sponsor renames: 13 = Toyota Antelopes, 12 = Denso Iris, 8 = ENEOS Sunflowers; all-star sides have their own ids, e.g. 591). away_ptrFloat64Away field-goal percentage (2PT + 3PT) in the period, 0-100, a NUMBER with up to one decimal (61.5; whole values come as integers).
away_pt2rFloat64Away two-point percentage, 0-100, number.
away_pt3rFloat64Away three-point percentage, 0-100, number.
away_ftrFloat64Away free-throw percentage, 0-100, number (0 when no attempts).
away_rebound_offInt64Away offensive rebounds in the period, the first number of the wire's 'off-def-total' string.
away_rebound_defInt64Away defensive rebounds in the period, the second number of the wire's 'off-def-total' string.
away_rebound_totInt64Away total rebounds in the period, the third number of the wire's 'off-def-total' string.
away_assistInt64Away assists (integer).
away_turnoversInt64Away turnovers in the period, from the wire's counted string ('6本' = 6); the wire key is spelled away_trun_over.
away_max_differenceInt64Away team's largest lead in the period, points (integer).
lead_countInt64Lead changes in the period, from the wire's counted string ('0回' = 0 times).
tie_countInt64Times the score was tied in the period, from the wire's counted string ('4回' = 4 times).

wjbl_team_standings​

League table of one or more season phases: rank and record of every team.

Endpoint URL: GET https://api.wjbl.01core.app/api/team-standings

Valid URL: https://api.wjbl.01core.app/api/team-standings?season_ids=169

API ParameterPythonPatternRequiredNullableDescription
season_idsseason_idsYSeason phase id or ids (season_id in wjbl_standing_seasons; a phase inside a league edition, not a year): an integer, a list or a comma string such as '169,170' (2025-26 regular season Premier and Future divisions).

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
season_idInt64Season-phase id season_id (key space: phases WITHIN a league_id, e.g. 169 = 25-26 regular season Premier, 170 = 25-26 regular season Future, 176 = 25-26 playoff final). Not a year: one league_id has several season_ids. The season_ids parameter of /team-standings and /team-ranking and the season_id of /team/roster.
season_titleStringPhase title in Japanese: 'レギュラーシーズン' = regular season, 'プレーオフ　ファイナル' / 'プレーオフ／ファイナル' = playoff final, 'プレーオフ／セミファイナル' = playoff semifinal (the separator varies by era).
league_nameStringDivision name, Japanese ('プレミア' = Premier).
season_league_nameStringPhase / division label in Japanese: 'プレミア' = Premier, 'フューチャー' = Future, 'グループステージ' = group stage, '2次ラウンド 下位リーグ' = second round, lower league; empty for a single-table phase.
season_league_flgInt64Division layout flag: 1 = one table per division (Premier / Future), 2 = split by season_team_area (East / West, by the site's JS), 0 = cup / group stage.
update_dateStringAs-of date in Japanese, 'YYYY年M月D日(曜)'.
team_idInt64Franchise id team_id (key space: W League franchises, STABLE across seasons and sponsor renames: 13 = Toyota Antelopes, 12 = Denso Iris, 8 = ENEOS Sunflowers; all-star sides have their own ids, e.g. 591). The team_id of /team/roster and of the site's /team/roster/?team_id=. Not season_team_id.
season_team_nameStringTeam name as registered for the season, in Japanese (company + nickname: 'トヨタ自動車 アンテロープス' = Toyota Antelopes).
season_team_short_nameStringShort team name for that season, Japanese ('トヨタ自動車' = Toyota).
team_entry_flgInt64Official-league participant flag (公式戦参加フラグ): 1 = a W League member team (the site links its roster), 0 = not (guest or all-star side). Integer.
positionInt64Rank of the team in the phase (a string on the wire, equal to the map key).
season_team_areaStringUnobserved: null in every sample, so no type and no meaning is claimed. (By the site's standings JS: 0 = East, 1 = West conference when season_league_flg = 2.)
win_lostStringRecord in Japanese, 'N勝M負' ('23勝5負' = 23 wins, 5 losses).
winsInt64Wins in the record, parsed from win_lost ('23勝5負' = 23 wins).
lossesInt64Losses in the record, parsed from win_lost ('23勝5負' = 5 losses).

return_parsed=False — the raw body (dict): the route's JSON (a bare list as {'items': [...]}) plus _request (the ids asked for, with season the END year).

wjbl_team_ranking​

League table with per-game team averages (points, shooting, rebounds, assists) of one or more season phases.

Endpoint URL: GET https://api.wjbl.01core.app/api/team-ranking

Valid URL: https://api.wjbl.01core.app/api/team-ranking?season_ids=169%2C170

API ParameterPythonPatternRequiredNullableDescription
season_idsseason_idsYSeason phase id or ids (season_id in wjbl_standing_seasons; a phase inside a league edition, not a year): an integer, a list or a comma string such as '169,170' (2025-26 regular season Premier and Future divisions).

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
league_idInt64Competition-edition id league_id (key space: W League competitions; sequential, ONE id per season of the league AND per all-star game, cup or camp: 45 = '25-26 Wリーグ', 47 = '26-27', 20 = '13-14', 46 = All-Star 2025-26). The league_id parameter of /play-schedules and /play-schedule-months; enumerate with /leagues. The sdv season is the END year of league_title (END = 2000 + the second YY: '25-26' -> 2026, '99-00' -> 2000).
league_titleStringCompetition-edition title in Japanese: '25-26 Wリーグ' = 2025-26 W League (sdv END year 2026; END = 2000 + the second YY: '25-26' -> 2026, '99-00' -> 2000); also 'Wリーグオールスター2025-26' = All-Star game, 'オータムカップ2021' = Autumn Cup, 'サマーキャンプ2019' = Summer Camp, 'WリーグSUPERGAMES'.
seasonInt64Season END year (2025-26 = 2026, 1999-2000 = 2000) from league_title ('25-26 Wリーグ'); null for an all-star game, cup or camp.

Not a year: one league_id has several season_ids. The season_ids parameter of /team-standings and /team-ranking and the season_id of /team/roster.

season_full_nameStringleague_title + phase (+ division) in Japanese: '25-26 Wリーグ レギュラーシーズン プレミア' = 2025-26 regular season, Premier division ('フューチャー' = Future division, from 2024-25).

season_tournament_textStringTournament text (HTML); empty in every sample.

team_entry_flgInt64Official-league participant flag (公式戦参加フラグ): 1 = a W League member team (the site links its roster), 0 = not (guest or all-star side). Integer.
positionInt64Rank of the team in the phase (a string on the wire).
season_team_areaStringUnobserved: null in every sample, so no type and no meaning is claimed. (By the site's standings JS: 0 = East, 1 = West conference when season_league_flg = 2.)
winInt64Wins (勝), integer.
lostInt64Losses (負), integer.
winning_rateFloat64Winning percentage as a FRACTION 0-1 with three decimals, a string ('0.821'); parsed to a number.
ppgFloat64Points per game, a string with two decimals; parsed to a number.
oppFloat64Opponent points per game (OPP), a string with two decimals; parsed to a number.
fgFloat64Field-goal percentage 0-100 with a '%' sign, a string ('41.99%'); parsed to a number.
opp_fgFloat64Opponents' field-goal percentage 0-100 with '%', a string; parsed to a number.
p3pgFloat64Three-pointers made per game (3PPG), a string; parsed to a number.
rpgFloat64Rebounds per game, a string; parsed to a number.

unsatisfiedStringUnobserved: null in every sample, so no type and no meaning is claimed. (By the site's JS: a column shown only when filled; meaning unverified.)
