KHL — KHL webcaster mobile API (khl.api.webcaster.pro)

sportsdataverse.hockey.khl — 9 endpoints.

Note: Owner flag: the KHL and its webcaster platform are run by Russian operators, some clubs by sanctioned state companies. Fetching on your own machine is fine; any published data release, hosted mirror or redistribution needs owner (sanctions / legal) sign-off first.

khl_webcaster_stages​

Season table: every stage (season END year, regular / playoff) with its khl.ru tournament id and webcaster stage id.

Endpoint URL: GET https://khl.api.webcaster.pro/api/khl_mobile/data.json

Valid URL: https://khl.api.webcaster.pro/api/khl_mobile/data.json?locale=en

API ParameterPythonPatternRequiredNullableDescription
localelocaleYResponse language: en or ru.

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
seasonInt64Season END year (2026 = 2025-26)
typeStringregular or playoff
tournament_idInt64khl.ru tournament (stage) id, tnId: 1369 = 2025-26 regular season, 1370 its playoff; equals webcaster stage khl_id
stage_idInt64Webcaster stage id (its own id space; not a khl.ru tournament id)
season_labelStringSeason label as sent (26/27, 2025/2026)
titleStringStage title (Regular / Playoff)
display_ruleStringFront-end display rule key
percent_points_scoredBooleanFront-end flag: rank the stage by points percentage (False in every stage captured; unverified)

return_parsed=False — the raw JSON body (betting fields and the caller's IP removed).

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. An error envelope with code 404 (unknown id), an empty object, or an unknown season.
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. A body for another id / stage / player than the one requested, or any other error envelope.
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.
