KHL — KHL site REST (www.khl.ru/rest)

sportsdataverse.hockey.khl — 14 endpoints.

Note: Owner flag: the KHL and its webcaster platform are run by Russian operators, some clubs by sanctioned state companies. Fetching on your own machine is fine; any published data release, hosted mirror or redistribution needs owner (sanctions / legal) sign-off first.

Note: The documented curl request is schematic: the runtime primes a session (adds the form field sessid), maps season / stage to the form field values[tournament] (the tournament id) and sends the X-Requested-With, Origin and Referer headers.

khl_schedule​

Season schedule and results of a tournament, one row per game (All-Star games dropped).

Endpoint URL: POST https://www.khl.ru/rest/calendar/list/

Example request: curl -X POST 'https://www.khl.ru/rest/calendar/list/' -d 'season=2026&stage=regular'

API ParameterPythonInPatternRequiredNullableDescription
seasonseasonbodyYSeason by its END year (2026 = 2025-26), mapped to the KHL tournament id (tnId) through the webcaster season table (khl_webcaster_stages). None = the site's current season.
stagestagebodyYWhich stage of the season: regular or playoff.
values[tournament]tournament_idbodyYkhl.ru tournament id (tnId), sent as is instead of season / stage (1369 = 2025-26 regular season, 1370 its playoff; the schedule's tournament_id column). The All-Star games have their own.

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
game_idInt64khl.ru game id; equals webcaster event khl_id / match_id
tournament_idInt64khl.ru tournament (stage) id, tnId: 1369 = 2025-26 regular season, 1370 its playoff; equals webcaster stage khl_id
dateStringGame date YYYY-MM-DD (Moscow time)
timeStringStart time hh:mm (Moscow time); not a game clock
home_club_idInt64Home CLUB id (stable across seasons; joins webcaster team khl_id)
home_nameStringHome team name (Russian on www.khl.ru)
away_club_idInt64Visitor CLUB id (stable across seasons; joins webcaster team khl_id)
away_nameStringVisitor team name (Russian on www.khl.ru)
home_scoreInt64Home goals (final, shootout winner counted)
away_scoreInt64Visitor goals (final, shootout winner counted)
decisionStringOT or SO when decided in overtime / a shootout; null in regulation
period_scoresStringPer-period home:away scores, comma-joined
winner_club_idInt64Club id of the winner
approvedInt641 = result confirmed by the league
arena_idInt64khl.ru arena id
arena_nameStringArena (city) name, from data.ARENAS

return_parsed=False — the raw khl.ru envelope Dict ({status, data, errors}).

Raises​

ExceptionDescription
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. Khl.ru answered an error envelope (status != success), a 307 again after re-priming the session, or a page for another game / player / tournament than the one requested.
NoDataErrorThe host answered 404 -- the requested resource does not exist. Khl.ru answered no rows, or the season has no such stage.
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.

Example​

khl_schedule(season=2026)
