ACB — ACB API (api2.acb.com, Spain) — Other: period_scores–bracket_games

acb_period_scores​

Points each team scored in each period of a game.

Endpoint URL: GET https://api2.acb.com/api/matchdata/MatchHeader/match-header

Valid URL: https://api2.acb.com/api/matchdata/MatchHeader/match-header?matchId=105401

API ParameterPythonPatternRequiredNullableDescription
matchIdmatch_idYRequired. ACB match id (integer), one global sequence for every competition: legacy ids (seasons up to 2019-20) sit below about 20000 (12559 = the 2005-06 final); ids from 2020-21 start around 100000 (105401 = Barca 89-86 Valencia Basket, Liga 2026-27 round 3).

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
match_idInt64ACB match id (one global sequence for every competition; legacy ids are below about 20000 up to 2019-20, ids from 2020-21 start around 100000). Taken from the request when the body does not name the game.
quarterInt64Period number: 1-4 quarters, 5+ overtimes (a finished game lists every period played).
home_scoreInt64Points the home team scored IN this period (not cumulative).
away_scoreInt64Points the away team scored IN this period (not cumulative).

return_parsed=False — the raw body (dict): the route's JSON plus _request (the ids asked for, in snake_case, with season the END year).

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. The ACB has nothing for the request (an unknown id, play-by-play or shots before 2016-17, a club with no games that season); a game outside a playoff series is zero rows.
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. The fetch failed or the answer is not the one asked for (a rejected key, an error envelope or stub, a body for another season, round, club or player, a game that is not finished).
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help. A missing or non-integer id, or a season before 1984 (raised before any request), or the API's HTTP 400 / 422.

acb_shots​

Every field-goal and free-throw attempt of a game (2016-17 onward) with its court position.

Endpoint URL: GET https://api2.acb.com/api/matchdata/MatchShots/match-shots

Valid URL: https://api2.acb.com/api/matchdata/MatchShots/match-shots?matchId=105401

API ParameterPythonPatternRequiredNullableDescription
matchIdmatch_idYRequired. ACB match id (integer), one global sequence for every competition: legacy ids (seasons up to 2019-20) sit below about 20000 (12559 = the 2005-06 final); ids from 2020-21 start around 100000 (105401 = Barca 89-86 Valencia Basket, Liga 2026-27 round 3).

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription

x_basket_mFloat64Shot x in metres from the centre of the attacked basket towards midcourt, when coord_system is mm and the attempt is a field goal; null otherwise. Units and origin are inferred by the refs (arc and sideline fit), not documented by ACB.
y_basket_mFloat64Shot y in metres across the court from the basket line, negative = the shooter's left, when coord_system is mm and the attempt is a field goal; null otherwise (inferred by the refs, not documented by ACB).

score_homeInt64Home score after the attempt.
score_awayInt64Away score after the attempt.
player_idInt64ACB licence number of the shooter.
player_nameStringShooter's short name from the game's shooter list (e.g. 'T. Martin').
shirt_numberStringShooter's shirt number as a string, from the game's shooter list.
zoneStringShot zone (acb_codes.SHOT_ZONES: restricted_area, paint, mid_range_, corner_three_, wing_three_*, top_three); null on free throws; legacy zones (up to 2019-20) are unreliable.
madeBooleanTrue when the shot went in; null on some free throws.
pointsInt64Points the attempt scored (2 or 3 on made field goals); null on free throws and misses.
