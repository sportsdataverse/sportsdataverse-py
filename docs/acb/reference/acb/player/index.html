acb_player_box​

Per-player box score of a game, per period (quarter 0 = the whole game).

Endpoint URL: GET https://api2.acb.com/api/matchdata/Result/boxscores

Valid URL: https://api2.acb.com/api/matchdata/Result/boxscores?matchId=105401

API ParameterPythonPatternRequiredNullableDescription
matchIdmatch_idYRequired. ACB match id (integer), one global sequence for every competition: legacy ids (seasons up to 2019-20) sit below about 20000 (12559 = the 2005-06 final); ids from 2020-21 start around 100000 (105401 = Barca 89-86 Valencia Basket, Liga 2026-27 round 3).

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
match_idintegerACB match id (one global sequence for every competition; legacy ids are below about 20000 up to 2019-20, ids from 2020-21 start around 100000). Taken from the request when the body does not name the game.
edition_idintegerSeason id (editionId) = season START year - 1935 (91 = 2026-27). The wrappers take the END year, season.
seasonintegerSeason END year (2027 = 2026-27) = edition_id + 1936: the key the wrappers take.
team_sidecharacterSide of the game the team played: home or away (the feed lists the home team first).
team_idintegerSeason-team entry id: one club in one competition edition, NEW every season (Barca = 4467 in Liga 2026-27). Not the club: use club_id to follow a club across seasons.
club_idintegerStable ACB club id (2 = Barca, 9 = Real Madrid, 13 = Valencia Basket): the same across seasons and sponsor names, and the club_id request argument.
teamcharacterTeam name as registered for that season (sponsor names change; the club id does not).
team_abbrcharacterThree-letter team abbreviation (BAR, RMB, VBC).
quarterintegerPeriod of the row: 0 = the whole game, 1-4 quarters, 5+ overtimes.
player_idintegerACB licence number: the person id everywhere. A player's box-score player.id, his play-by-play and shot playerLicenseId and the playerLicenceId / playerLicense request params hold the same number (all 24 players of match 105401 match). 20209407 = Edy Tavares. Older licences start 2020..., recent ones 3000....
player_namecharacterDisplay (sporting) name ('Edy Tavares')
first_namecharacterLegal first name(s)
last_namecharacterLegal last name(s)
shirt_numbercharacterShirt number, a string ('' or null when unknown)
game_rolecharacterPosition or staff role, in Spanish: Base (point guard), Escolta (shooting guard), Alero (small forward), Ala-pivot (power forward), Pivot (centre); Entrenador (head coach), Segundo Entrenador / Entrenador Ayudante (assistant coach). Null or '' in many rows
on_courtlogicalTrue while the player is on court (false once the game is over).
play_timecharacterTime on court as 'mm:ss' in the row's period.
seconds_playedintegerTime on court in whole seconds (play_time parsed).
is_starterlogicalTrue when the player started the game (the API's isStarted).
pointsintegerPoints (player box-score row)
free_throws_madeintegerFree throws the player made in the row's period (a count; quarter 0 is the whole game).
free_throws_attemptedintegerFree throws the player attempted in the row's period (a count; quarter 0 is the whole game).
two_pointers_madeintegerTwo-point field goals made
two_pointers_attemptedintegerTwo-point field goals attempted
three_pointers_madeintegerThree-point field goals made
three_pointers_attemptedintegerThree-point field goals attempted
assistsintegerAssists (player box-score row)
off_reboundsintegerOffensive rebounds
def_reboundsintegerDefensive rebounds
total_reboundsintegerTotal rebounds (player box-score row)
stealsintegerSteals (player box-score row)
turnoversintegerTurnovers (player box-score row)
blocksintegerShots blocked (by this player or team)
received_blocksintegerOwn shots blocked by an opponent
dunksintegerDunks (player box-score row)
personal_foulsintegerFouls committed
fouls_drawnintegerFouls received (player box-score row)
plus_minusintegerPoint differential while on court (+/-)
ratingintegerValoracion: ACB's efficiency rating (PIR) = points + rebounds + assists + steals + blocks + fouls received - missed field goals - missed free throws - turnovers - shots blocked by an opponent - fouls committed

return_parsed=False — the raw body (dict): the route's JSON plus _request (the ids asked for, in snake_case, with season the END year).

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. The ACB has nothing for the request (an unknown id, play-by-play or shots before 2016-17, a club with no games that season); a game outside a playoff series is zero rows.
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. The fetch failed or the answer is not the one asked for (a rejected key, an error envelope or stub, a body for another season, round, club or player, a game that is not finished).
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help. A missing or non-integer id, or a season before 1984 (raised before any request), or the API's HTTP 400 / 422.
