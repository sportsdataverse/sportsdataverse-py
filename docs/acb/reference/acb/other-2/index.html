ACB — ACB API (api2.acb.com, Spain) — Other: calendar–search

acb_calendar​

Every round of a season with its games: one call lists every game id.

Endpoint URL: GET https://api2.acb.com/api/seasondata/Calendar/season-calendar

Valid URL: https://api2.acb.com/api/seasondata/Calendar/season-calendar?season=2027

API ParameterPythonPatternRequiredNullableDescription
competitionIdcompetition_idYCompetition id: 1 Liga Endesa, 2 Copa del Rey, 3 Supercopa Endesa, 10 Minicopa Endesa (youth). Omitted = the API's default competition.
seasonseasonYSeason END year (2027 = 2026-27; the first ACB season, 1983-84, is 1984). acb_runtime sends the API's editionId = season - 1936. Omitted = the current season.

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
competition_idInt64Competition id: 1 Liga Endesa, 2 Copa del Rey, 3 Supercopa Endesa, 10 Minicopa Endesa.
edition_idInt64Season id (editionId) = season START year - 1935 (91 = 2026-27). The wrappers take the END year, season.
seasonInt64Season END year (2027 = 2026-27) = edition_id + 1936: the key the wrappers take.
round_idInt64Global round id (6017 = Liga 2026-27 round 3); not the round number.
round_numberInt64Round number within its phase.
subphase_idInt64Sub-phase id of the round (playoff stages); null in the regular season.
subphase_numberInt64Sub-phase number of the round; null in the regular season.
week_idInt64Not sent by the calendar route (always null).
match_idInt64Match id. Legacy ids (seasons up to 2019-20) sit below about 20000 (12559 = 2005-06 final, 17718 = 2016-17 final); from 2020-21 they start at about 100000 (102920 in 2021-22, 105401 in 2026-27). One key space across competitions: the matchId param of every matchdata route.
home_team_idInt64Home season-team entry id (new every season; joins the body's team list).
away_team_idInt64Away season-team entry id (new every season; joins the body's team list).
home_scoreInt64Home points (null before the match)
away_scoreInt64Away points (null before the match)
startStringTip-off, ISO 8601 UTC
statusStringMatch state (x-match-statuses)
is_on_half_timeBooleanAt half time (live)
current_quarterInt64Current or last quarter (5+ = overtime); not reliable after the match (1 in the 2017 series rows)
home_club_idInt64Stable club id of the home team (looked up in the body's team list).
home_teamStringHome team name for the season (looked up in the body's team list).
home_team_abbrStringHome team three-letter abbreviation (looked up in the body's team list).
away_club_idInt64Stable club id of the away team (looked up in the body's team list).
away_teamStringAway team name for the season (looked up in the body's team list).
away_team_abbrStringAway team three-letter abbreviation (looked up in the body's team list).
ticketing_linkStringTicket shop URL; null when none.
broadcastersStringBroadcast channel names of the game joined with '; ' (the first is the primary).

return_parsed=False — the raw body (dict): the route's JSON plus _request (the ids asked for, in snake_case, with season the END year).

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. The ACB has nothing for the request (an unknown id, play-by-play or shots before 2016-17, a club with no games that season); a game outside a playoff series is zero rows.
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. The fetch failed or the answer is not the one asked for (a rejected key, an error envelope or stub, a body for another season, round, club or player, a game that is not finished).
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help. A missing or non-integer id, or a season before 1984 (raised before any request), or the API's HTTP 400 / 422.

acb_calendar(season=2027)

ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help. A missing or non-integer id, or a season before 1984 (raised before any request), or the API's HTTP 400 / 422.

Example​

acb_search(limit=5, search_term='tavares')
