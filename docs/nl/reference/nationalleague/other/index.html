nl_schedule​

Schedule and results for one season: NL plus exhibitions.

Endpoint URL: GET https://www.nationalleague.ch/api/games

Valid URL: https://www.nationalleague.ch/api/games?season=2026

API ParameterPythonPatternRequiredNullableDescription
seasonseasonYSeason END year: 2026 = 2025/26. Diffing 2026 vs 2027 changes every list, and /player/{playerId} gp (51 vs 7), so it scopes. Lists are served for 2019-2027 (the app's season picker, /api/content/metadata seasons) and patchily before: 2012 and 2017 answered, 2010/2014/2015/2016/2018 answered [] (probed 2026-10-12).

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
game_idInt64SIHF game id <season(4)><competition(4)><sequence(6)> (Int64; e.g. 20261105000325, 1105 = National League). The same id as the sihf family's game_id; its first four digits are the season END year.
home_team_short_nameStringHome team abbreviation (e.g. HCD)
home_team_nameStringHome team display name
away_team_short_nameStringAway team abbreviation
away_team_nameStringAway team display name
home_team_idInt64Home team. SIHF team id (Int64; e.g. 101151 = HC Davos). The same key space as the sihf family's team_id.
away_team_idInt64Away team. SIHF team id (Int64; e.g. 101151 = HC Davos). The same key space as the sihf family's team_id.
vimeo_video_idInt64Full-game video. Vimeo video id (Int64): vimeo.com/.
dateStringScheduled start, ISO 8601 with UTC offset
statusStringGame state: finished, canceled, beforeStartOfPlay (others appear live)
base_statusStringCoarse game state; equal to status in every sampled game
home_team_resultInt64Home team goals (final or current score; 0 before the game)
away_team_resultInt64Away team goals (final or current score; 0 before the game)
is_overtimeBooleanGame went to overtime
is_shootoutBooleanGame went to a shootout
highlight_vimeo_video_idInt64Highlights video. Vimeo video id (Int64): vimeo.com/.
has_highlightBooleanA highlight video exists
is_currentBooleanGame belongs to the current game day
is_current_for_teamBooleanGame is the team's current game (team-scoped views)
tv_partnerStringBroadcaster logo image URLs; unobserved: null, absent or empty in every sampled row
spectatorsInt64Attendance (Int64; the API sends a digit string).
has_my_sportsBooleanBroadcast on MySports
refereesStringOfficials as '# ' strings (referees and linesmen; one entry in some games)
is_exhibitionBooleanExhibition game, not NL competition (competition code other than 1105)
home_team_coachStringHome head coach name; filled in a game's overview, null in the season lists; unobserved: null, absent or empty in every sampled row
away_team_coachStringAway head coach name; filled in a game's overview, null in the season lists; unobserved: null, absent or empty in every sampled row
game_timeInt64Elapsed game minutes; 0 on every game in the season lists, 60 in a finished game's overview
show_game_timeBooleanApp flag: show gameTime
arenaStringName of the arena the game is played in

return_parsed=False — the raw JSON Dict payload, unparsed.

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. A 404, or an empty answer (no games or rows for that season, team or phase).
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. A failed fetch, an error object in a 200, a body without the ids it must carry, or an answer for another season, team, game or player.
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.
