nl_player_box​

One game's player box score: goals, assists, shots, faceoffs, ice time, goaltending.

Endpoint URL: GET https://www.nationalleague.ch/api/games/{game_id}

Valid URL: https://www.nationalleague.ch/api/games/20261105000325

API ParameterPythonPatternRequiredNullableDescription
game_idgame_idYSIHF game id, 14 digits <season(4)><competition(4)><sequence(6)> (game_id in nl_schedule; the same id as the sihf family's game_id), e.g. 20261105000325.

Returns​

return_parsed=True (default) — a tidy polars.DataFrame with the columns below; pass return_as_pandas=True for a pandas.DataFrame.

col_nametypedescription
game_idInt64SIHF game id <season(4)><competition(4)><sequence(6)> (Int64; e.g. 20261105000325, 1105 = National League). The same id as the sihf family's game_id; its first four digits are the season END year.
team_sideStringhome or away: the side of the team this row belongs to.
team_idInt64SIHF team id (Int64; e.g. 101151 = HC Davos). The same key space as the sihf family's team_id.
player_idInt64SIHF licence number (Int64; e.g. 305519 = Tobias Geisser). Joins the sihf family's player_id and every SIHF *LicenceNr.
numberStringSweater number, a string
first_nameStringFirst (given) name of the player
last_nameStringLast (family) name of the player
short_nameStringInitial and last name, e.g. 'S. Aeschlimann'
nameStringFirst and last name
positionStringgoalkeeper, defender or forwarder (sic)
fowInt64Number of faceoffs won
folInt64Number of faceoffs lost
sogInt64Number of shots on goal
shmInt64Shots that missed the net
shpInt64Shots that hit the post
shbInt64Own shots blocked by an opponent
bksInt64Opponent shots blocked

pimInt64Penalty minutes
gInt64Number of goals scored
a1Int64First (primary) assists credited
a2Int64Second (secondary) assists credited
plInt64Plus count: on ice for an even-strength or shorthanded goal for
miInt64Minus count: on ice for a goal against
mipInt64Goaltender time played, hundredths of a minute (6000 = 60:00; = seconds / 0.6)
gaInt64Goals against: number of goals conceded
svsInt64Number of saves made by the goaltender
saInt64Shots on goal against
gaaFloat64Goals-against average; 0 in every sampled row, even for goaltenders who conceded
save_percentageFloat64Save percentage, 0-100
faceoffsInt64Faceoffs taken (upstream fo: fow + fol). Not penalties.

return_parsed=False — the raw JSON Dict payload, unparsed.

Raises​

ExceptionDescription
NoDataErrorThe host answered 404 -- the requested resource does not exist. A 404, or an empty answer (no games or rows for that season, team or phase).
AssetFetchErrorThe fetch failed (a non-2xx answer or a connection failure after retries, e.g. 401/403/429/5xx, or an empty or unreadable 200 body) -- the answer is unknown, not empty. A failed fetch, an error object in a 200, a body without the ids it must carry, or an answer for another season, team, game or player.
ValueErrorThe host answered 400 / 422 -- the request is wrong; retrying cannot help.

nl_player_box(game_id=20261105000325)

nl_player_stats​

Season stats for every player, with playerId.

Endpoint URL: GET https://www.nationalleague.ch/api/player

Valid URL: https://www.nationalleague.ch/api/player?season=2026&phase=4940

API ParameterPythonPatternRequiredNullableDescription
seasonseasonYSeason END year: 2026 = 2025/26. Diffing 2026 vs 2027 changes every list, and /player/{playerId} gp (51 vs 7), so it scopes. Lists are served for 2019-2027 (the app's season picker, /api/content/metadata seasons) and patchily before: 2012 and 2017 answered, 2010/2014/2015/2016/2018 answered [] (probed 2026-10-12).
phasephaseYSIHF phase id (see x-phase-ids). Omitted = the regular season: /player?season=2026 and phase=4940 answer byte-identical bodies, phase=5297 (playoffs) a different one (max gp 19 vs 52). Phase ids change every season; whether the metadata ids apply to 2027 is unverified.
