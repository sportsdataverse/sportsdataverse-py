- NFL loaders follow nflreadpy's `seasons` contract: `seasons=None` loads the current season (it used to raise `TypeError`), `seasons=True` loads every season from the loader's first through the current one (skipping only a current season that is not published yet), and `seasons=[]` returns an empty frame without a request (it used to return every season from `load_nfl_schedule`, `load_nfl_nextgen_stats`, season-level `load_nfl_pfr_advstats` and `load_nfl_espn_qbr`, and to raise from `load_nfl_ratings_weekly` / `load_nfl_ngs`). `load_nfl_player_stats` keeps its documented default. `load_nfl_nextgen_stats` now raises `SeasonNotFoundError` for a season before 2016, like every other NFL loader.
