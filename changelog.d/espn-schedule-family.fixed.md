- **ESPN schedules:** all eight `espn_<lg>_schedule` return a zero-row frame with the documented columns on an empty slate; one malformed event no longer discards the day; `Canceled` games get null linescores like `Postponed`; NFL `*_current_rank` is a null integer (was the CFB default 99); parsing the same payload twice no longer raises.
- **ESPN schedules:** the six copies that sent `seasonType` now send `seasontype`. ESPN ignored the camelCase key, so `season_type=` with `dates=YYYY&week=N` (NFL, NHL, WNBA, NBA, MBB, WBB) never filtered; it does now, and those calls return different rows.
- **ESPN schedules:** `espn_mbb_schedule(dates=2024)` returns the whole 2023-24 season, November through the title game (one calendar request plus one request per game day, ~150 in all, sorted by date; a failed day, or one that fills its `limit`, raises `AssetFetchError`, and a day never asks for more than 1000 events because ESPN answers 25 above that); it returned Jan 1-13 2024 only. `espn_mbb_calendar` / `espn_wbb_calendar` accept `season=None` (current season) and a float `2024.0`.
