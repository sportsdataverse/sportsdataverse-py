- Release loaders classify every failure: a connection that never answers raises `AssetFetchError` (it leaked `requests.ConnectionError`); the failure probe is a one-byte ranged GET instead of a full re-download, and a reachable asset whose read failed in transit is read again. The NFL CSV loaders (`load_nfl_teams`, `load_nfl_ff_playerids`, `load_nfl_ff_rankings`) fetch through the HTTP gateway, so a 404 is `NoDataError`, a 400 `ValueError`, a rate limit is retried and then `AssetFetchError`, and a challenge page is refused (on polars 2.0 every failure was a bare `OSError`). `download()` no longer decodes an `application/octet-stream` body as JSON.
