- Release loaders classify every failure: a refused or reset connection raises `AssetFetchError` (it leaked `requests.ConnectionError`). A failed read is checked with a one-byte ranged GET instead of a full re-download; a reachable asset whose read failed in transit is read again, and a failure on that second read is classified too (404 `NoDataError`, anything else `AssetFetchError`). A body that arrived whole but does not parse is re-raised at once, without a second fetch. The NFL CSV loaders (`load_nfl_teams`, `load_nfl_ff_playerids`, `load_nfl_ff_rankings`) fetch through the HTTP gateway, so a 404 is `NoDataError`, a 400 `ValueError`, a rate limit is retried and then `AssetFetchError`, and a challenge page is refused (on polars 2.0 every failure was a bare `OSError`). `download()` no longer decodes an `application/octet-stream` body as JSON.
