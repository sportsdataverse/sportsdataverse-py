- **ESPN teams:** the eight `espn_<lg>_teams` (mbb, wbb, nba, wnba, nfl, nhl, cfb, mlb) no longer sit behind a process-lifetime `functools.lru_cache`. Passing `headers={...}` (any unhashable keyword) raised `TypeError: unhashable type` before any request; every caller got the same frame object, so one caller's edit changed the next caller's result; and the cache never expired. Each call now fetches and returns its own frame (the package response cache, `sportsdataverse.cache`, is the opt-in TTL cache). A payload without `sports[0].leagues[0].teams` returns a zero-row frame with the documented columns instead of raising `TypeError`/`IndexError`. The docstrings named a `clear_cache()` that never existed. (#888)
