- **Basketball crosswalks:** `sportsdataverse.basketball.basketball_crosswalk` adds deterministic id joins (no name matching):
  `genius_game_crosswalk` maps BNXT, CEBL, TBF, KZS and Sportality game keys to the Genius match id,
  `genius_team_crosswalk` maps the Sportality team uuid to the Genius team id, `ibba_segev_game_crosswalk` exposes
  `segev_game_id`, and `pleague_team_crosswalk` maps the P. LEAGUE+ `team_id` to the Preciser team uuid.
