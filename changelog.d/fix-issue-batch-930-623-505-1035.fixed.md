- **Football sources:** a CBS, Fox, NCAA or Yahoo game id missing from an id-map row (NaN or `pandas.NA`) falls
  through to the next source instead of fetching game "nan". (#1042)
- **CFB box score:** a player ESPN spells two ways in one game ("Noah Kim" / "N. Kim") is one passer, rusher or
  receiver row, with one xQBR, as the NFL box already does. (#1042)
- **CFB play-by-play:** feeds that number every overtime 5 count timeouts per overtime period (from drive pairs),
  so a team's OT3 timeout no longer reads as already spent. (#1042)
- **Basketball schedules:** `load_{nba,wnba,mbb,wbb}_schedule` describe `home_score`, `away_score` and the
  `status_type_*` columns as ESPN's values passed through unchanged, not as play-time scores. (#1042)
