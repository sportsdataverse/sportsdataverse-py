- **NBA / WNBA neutral sites:** `nba_neutral_site_games()` reads a bundled, sourced list of games abroad and NBA
  Cup knockout games in Las Vegas; with a 2020-bubble date rule it marks the neutral games ESPN's flag misses. (#1136)
- **NBA / WNBA team ratings:** team-season rates, team strength, the season sim, rated priors and game flow drop
  the home term for those games, which count as neither home nor away. (#1136)
