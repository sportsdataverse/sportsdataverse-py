- **Basketball:** the minted per-competition game functions now refuse a game of another competition with `AssetFetchError`. Genius (`esake_pbp` and the rest) reads the game's LiveStats `/u/` shell, one cached request per game, and applies the entry's label rule to its competition name; when that request fails twice, or the shell names no competition, the call raises `AssetFetchError` saying the scope check could not run rather than returning the game unchecked. FIBA checks that a `comp=` override is an edition of the bound family (a competition GDAP gives no family is refused with that reason). The minted game functions need `season` or `comp`, and their docs say so. The per-process listing cache keeps at most 1,024 entries (least recently used evicted), so a backfill does not grow it without bound. The parameterised `genius_*` / `fiba_gamepage_*` / `atrium_*` wrappers are unchanged. (#864)
