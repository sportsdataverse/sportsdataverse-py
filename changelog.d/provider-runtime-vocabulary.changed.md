- **Runtimes:** The Odds API raises `AssetFetchError` on a dead connection (not `ConnectionError`) or a scalar 2xx body; the Data API id-map lookup raises on a non-2xx (its error body is no longer the row), so dispatch falls back; `pff_api_*` returns `{}` on a 204/205 and raises `NoDataError` on an injected 404; LEGACY `pff_*` raises on a JSON array instead of returning `{}`;
  a malformed `year` / `sport_slug` in the deprecated `on3_*_rankings` shims raises `ValueError` instead of returning `{}`; with the opt-in cache on, statcast / torvik (and every content-type-branching getter) return the same JSON on a cache hit as on the first call; `pff_*` and the 247Sports getters honour `SDV_PY_HTTP_TIMEOUT`;
  the On3, The Odds API and statcast player parsers return zero rows for an empty record, a wrong-typed body or an error envelope. (#TBD)
